PhysV2A: Reachability-Gated and Semantic-Mask-Constrained Feasibility Completion for Video-to-Robot Manipulation

arXiv: 2607.09365 作者: Chenguang Yang Team 日期: 2026-07-10

📝 详细解读

研究背景与动机

当前，基于视频的人类演示、生成视频或RGB-D观测为机器人操作提供了以物体为中心的运动先验。然而，这些视觉先验通常是本体无关的，无法直接被特定机器人执行。现有视频条件化操作方法和RGB-D 6自由度抓取生成方法虽能提供任务意图和局部几何可信的抓取，但其输出的抓取置信度是局部度量，且未考虑机器人本体的可达性、逆运动学连续性及可操作性等约束。具体而言，一个在点云中局部可信的抓取姿态，在与视频恢复的物体运动刚性耦合后，可能诱导出机器人无法到达或条件恶劣的末端执行器轨迹。

本文针对上述痛点，提出了轨迹条件化的抓取可行性新视角。核心思路是：将抓取可行性评估与完整的下游TCP轨迹耦合，通过分层可达性门控筛选剔除不可行候选，并利用语义掩码约束的优化在保证任务关键运动成分的前提下，对轨迹进行可操作性 refininement，从而实现从视频到机器人操作的可行轨迹生成。

方法详解

PhysV2A框架的核心是将视频恢复的物体6D轨迹和RGB-D生成的6自由度抓取候选，转换为机器人可执行的轨迹。其流程包含三个关键组件：(1) 构建轨迹条件化的抓取假设；(2) 分层可达性门控选择；(3) 语义掩码约束的可操作性优化。

图2：PhysV2A整体框架。输入为视频恢复的物体轨迹和RGB-D抓取候选。首先，为每个抓取候选构建TCP轨迹假设。其次，通过机器人中心的分层可达性筛选（硬约束）和执行适宜性排序（软约束）选择可达轨迹。接着，利用VLM和规则生成阶段性语义掩码。最后，通过冗余优先和语义掩码约束的可操作性优化对选定轨迹进行修正。

1. 轨迹条件化抓取可行性： 对于每个抓取候选位姿 ( G_i ) 和恢复的物体轨迹 ( \mathcal{T}{obj} )，假设物体被抓取后与末端执行器刚性连接，通过公式 ( T{tcp,i}^{t}=T_{obj}^{t}(T_{obj}^{0})^{-1}G_{i} ) 生成该抓取诱导的完整TCP轨迹 ( \mathcal{T}_{tcp}^{(i)} )。从而将一个物体运动先验扩展为多个抓取-轨迹假设，抓取可行性由它诱导的完整TCP轨迹来评估。

2. 分层可达性门控选择： 该模块分为两步。第一步为硬可行性筛选：依据定义的可达可行集 ( \mathcal{F}{reach} )，对每个候选轨迹进行一系列机器人中心的约束检查，包括工作空间支持、基于离线训练的QGMM（四元数高斯混合模型）的概率可达性先验、逐点及全轨迹的逆运动学一致性、关节限位、关节空间连续性、以及基于缩放雅可比矩阵最小奇异值和条件数的奇异性安全检查。违反任何硬约束的候选将被直接剔除。第二步为执行适宜性排序：对通过筛选的候选轨迹，计算一个复合评分 ( S_i )（公式20），由局部抓取置信度、QGMM支持度、IK一致性分数、关节限位裕度、连续性惩罚和可操作性条件等归一化项加权求和得到（权重固定为: α=0.20，β=0.20，γ=0.20，δ=0.15，η=0.10，ρ=0.15）。最终选择评分最高的轨迹 ( \mathcal{T}{tcp}^{*} ) 进行优化。

3. 语义掩码约束的可操作性优化： 首先，利用视觉语言模型（VLM）根据任务指令、关键帧和轨迹统计数据生成一个阶段性语义掩码 ( \mathbf{S}^{p} )，用于标识各任务阶段（如离开、传送、目标抵达）下各笛卡尔分量（Tx, Ty, Tz, Rx, Ry, Rz）的任务关键性，其值为预定义的离散等级 {1.0, 0.8, 0.5, 0.3, 0.1}，值越大表示约束越强。该掩码经规则验证后，扩展为逐帧掩码 ( \mathbf{S}^{t} \），并定义了允许的笛卡尔扰动上界 ( |\Delta\xi_{k}^{t}| \leq b_{k}^{max}(1-s_{k}^{t}) )（公式13）。优化过程采用保守的两层策略：先固定TCP轨迹 ( \mathcal{T}_{tcp}^{*} )，仅利用7自由度机械臂的冗余性在关节空间搜索以改善可操作性（基于SPD几何的仿射不变黎曼度量）。若冗余优化不足，则启动语义掩码约束的笛卡尔松弛，在掩码允许的扰动范围内对TCP位姿进行采样和调整，最终目标是使轨迹的可操作性椭球（由 ( \mathbf{M}t = J_s(q_t)J_s(q_t)^T ) 定义）逼近一个由可行且条件良好的关节构型构成的目标椭球集 ( {\mathbf{M}{c,t}} )。

实验与结果

实验设置： 在RM75 7自由度机械臂（配备平行夹爪和Intel RealSense RGB-D相机）上，进行了四项桌面操作任务的实物实验：书籍上架、方块放入碗中、圆孔插入、纸盒放入托盘。每个任务进行20次独立试验，共80次试验/方法。使用GraspGen生成Top-50抓取候选作为输入。

对比基线： 与同平台的代表性视频先验和纯IK方法进行对比，包括Flow-prior（基于流的方法）、Rigid-video（刚性视频）、Video-action（视频动作）、Generated-flow（生成流）以及Full-Traj. IK（全轨迹IK）。

图3：不同方法在四项任务上的成功率对比。PhysV2A在80次试验中取得71次成功，成功率达88.75%，较Full-Traj. IK基线提升了25个百分点。

图4：PhysV2A在四项任务上的机器人执行示例图，展示了各任务的不同执行阶段。

关键实验结果： PhysV2A在80次试验中总体成功率为88.75%（71/80），显著优于所有基线方法。其中，在最具挑战性的“圆孔插入”任务上，成功率较最佳视频先验基线提升了35个百分点。

图5：消融实验展示了各核心组件的贡献。移除轨迹条件化可行性评估（w/o traj-cond）或分层可达性选择（w/o hierarchical）均导致成功率显著下降；移除语义掩码约束（w/o S-Mask）虽对成功率影响较小，但会导致更大的任务无关轨迹偏差。

图6：语义掩码约束优化的效果分析。左图展示了VLM生成的阶段性语义掩码示例。右图显示，相比于无掩码约束的优化，S-Mask约束的优化在有效提升可操作性（降低条件数κ）的同时，将任务关键运动成分的偏差严格限制在较小范围内。

图7：失败案例归类分析。PhysV2A的主要失败原因来自于上游视觉模块的物体姿态跟踪误差，而非其自身的运动学可行性处理流程。

消融实验总结：

  • 轨迹条件化可行性评估和分层可达性门控选择是保证高成功率的关键，移除任一组件都会导致成功率和可操作性的急剧下降。
  • 语义掩码约束虽然不是成功率的主因，但它对于限制任务无关的轨迹偏差至关重要，确保了优化过程不扭曲任务意图。

总结与启发

核心贡献：

  1. 提出了轨迹条件化的抓取可行性新表述，将RGB-D抓取候选通过其诱导的完整TCP轨迹进行评估，克服了局部评估的局限性。
  2. 设计了分层可达性门控选择策略，结合硬性机器人约束筛选和软性执行适宜性排序，有效过滤不可行轨迹并优选高质量候选。
  3. 开发了语义掩码约束的可操作性优化模块，利用VLM生成的语义掩码引导优化过程，在提升运动学质量的同时严格保护任务关键运动成分。

论文提到的局限性：

  1. 工作聚焦于运动学可行性和可操作性安全，未考虑完整的碰撞感知规划、接触丰富的动力学或闭环力控制。
  2. 语义掩码的阶段划分和离散值等级是针对实验中的桌面操作任务设计的，并非通用分割规则。

对后续研究的启示：

  1. 将可行性评估从局部几何提升到完整轨迹层面，为视频到机器人的转换提供了更鲁棒的评估范式。
  2. 结合高层语义（VLM）与底层运动学约束进行轨迹优化的思路，可在保证任务语义的同时提升执行质量，这一框架可扩展至更复杂的任务和场景。

💡 一句话总结

本文解决视频到机器人操作中，视频衍生的6D物体运动因不考虑机器人具体形态而无法直接执行的问题。提出PhysV2A框架，其关键技术包括可达性门控选择和语义掩码约束的可行性补全：前者将抓取与轨迹耦合后进行运动学筛选与排序；后者利用VLM辅助的语义掩码识别关键运动组件，并通过优化松弛实现可操作性精细化。真实机器人实验表明，该方法提高了四个桌面操作任务的成功率，减少了运动学可行性失败，并生成条件更好、偏差有界的轨迹。
