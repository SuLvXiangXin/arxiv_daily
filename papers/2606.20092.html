EventVLA: Event-Driven Visual Evidence Memory for Long-Horizon Vision-Language-Action Policies

arXiv: 2606.20092 作者: Tai Wang Team 日期: 2026-06-18

📝 详细解读

研究背景与动机

当前，视觉-语言-动作模型已成为通用化、细粒度机器人操作的强大基础。然而，这些策略大多基于严格的马尔可夫假设，即所有任务相关信息在整个过程中始终可见。这导致它们在处理长视野任务时面临根本性挑战，例如当关键视觉线索（如被移动物体的原始位置）在执行过程中变得不可见或被遮挡时，策略会失败。为解决这一非马尔可夫问题，现有的记忆增强VLA方法可归纳为三大范式：1）双系统方法，分离认知与控制系统，但存在延迟高和错误传播问题；2）循环架构，将历史压缩为隐藏状态，导致信息瓶颈并丢失视觉细节；3）记忆缓冲区，保留历史帧但盲目积累大量冗余帧，缺乏选择性机制。核心痛点在于：在不超出计算限制的前提下，VLA应该在何时、保存何种视觉证据才能最大化执行成功率。

本文提出EventVLA，其核心思路是：将基于规则的基础视觉锚点与一个数据驱动、具有前瞻性的动态关键帧证据记忆模块相结合，稀疏地、前瞻性地捕获和存储任务关键的视觉事件，以解决非马尔可夫长视野操作中的记忆瓶颈问题。

方法详解

EventVLA是一个端到端框架，其核心是维护一个稀疏的视觉证据内存，该内存用于辅助动作生成。

整体框架中，VLA策略在每个时间步t，动作生成不仅依赖于当前观测o_t和语言指令l，还依赖于上一时间步存储的稀疏视觉证据内存M_t-1，即 a_t = π(o_t, M_t-1, l)。内存M_t由两部分无缝结合：基础视觉锚点A_t和事件关键帧E_t，即 M_t = A_t ∪ E_t。在执行时，当前观测o_t、锚点A_t和事件帧E_t-1被拼接成一个时序序列，送入VLM的视觉编码器进行处理。

基础视觉锚点A_t是一个确定性的规则基准，旨在捕获永久场景布局和即时时间上下文，定义为：A_t = {o_0} ∪ {o_t-K, …, o_t-1}。其中，初始帧o_0作为永久空间锚点，保留了物体位移前的原始场景排布；短期历史窗口（大小为K）则提供关键的运动和任务进展线索。

然而，在复杂交互过程中，不可预测的、瞬态出现的证据（例如揭开不透明盖子时短暂暴露的物体颜色）是基础锚点无法捕获的。为此，EventVLA引入了动态关键帧证据记忆模块。这是一个轻量级的并行预测头，与主要动作头一起工作，直接从前一层的自回归transformer的隐藏状态h_t中预测未来一个执行块（horizon H）内各步骤是关键帧的概率：𝐩̂_t = σ(KEM_mlp(h_t)) = [p̂_t^1, p̂_t^2, …, p̂_t^H]^T ∈ [0, 1]^H。这种分块预测赋予VLA策略前瞻性，使其能够主动规划整个即将到来的执行块内的“记忆写入计划”。

图1：EventVLA框架。框架维护一个由基础视觉锚点和交互驱动的事件关键帧组成的稀疏视觉证据内存，并使用KEM模块前瞻性地将任务关键的未来关键观测提交到内存中。

当预测概率超过一个阈值（p̂_t^i ≥ τ_commit）时，EventVLA会触发一次稀疏的内存写入事件，将t+i时刻的原始图像动态存入事件缓冲区E_t。事件缓冲区E_t有最大容量N_max，采用先进先出的淘汰策略管理。通过这种方式，KEM模块能够主动捕获并存储交互驱动的瞬态事件。

在训练上，为了避免高昂的手动标注成本，论文利用离线Qwen3-VL自动化流水线从示教数据中提取真实关键帧时间戳，并使用时间平滑的软标签进行监督。模型通过联合优化标准的动作生成损失L_action和KEM损失L_kem进行端到端训练：L = L_action + λL_kem。

实验与结果

实验使用了多个基准测试：RMBench（评估传统记忆需求任务）、新提出的RoboTwin-MeM（诊断非马尔可夫场景）以及RoboTwin2.0（评估马尔可夫任务）。实验平台涉及仿真（RoboTwin 2.0, SAPIEN）和真实世界（ARX ACONE双臂机器人）。论文对比了三大类基线：1）非记忆型VLA：如π0.5、DP、ACT、X-VLA、QwenOFT；2）双系统记忆VLA：如MemER、Mem-0；3）端到端记忆VLA：如基于OpenVLA和QwenOFT的MemoryVLA。

在RMBench上，由于任务主要依赖静态空间布局，仅使用基础视觉锚点的EventVLA（VA only）就达到了67.8%的平均成功率，超过所有基线，证明了锚点的有效性。

图2：RoboTwin-MeM基准测试中的8个评估任务概览。每个任务的复杂度由n参数化，n表示必须记忆的瞬态、交互驱动的关键帧数量，范围从1到5。任务关键的中间事件用蓝色边框高亮。

在专门诊断非马尔可夫能力的RoboTwin-MeM上，实验结果差异显著。如表2所示，仅依赖基础锚点（VA only）的版本成功率仅为18.0%，而完整EventVLA（VA+KEM）则达到了75.2%的平均成功率，远超所有基线。这强有力地证明了KEM模块对于需要保留瞬态中间记忆的复杂长视野任务的不可或缺性。

消融实验进一步验证了EventVLA各组件的必要性：移除NMS后处理或限制缓冲区容量会导致性能大幅下降至53.4%和32.0%；用隐式潜在内存库替换显式图像拼接会引入严重信息瓶颈，性能骤降至24.9%；使用生硬的二元标签代替平滑软标签，性能降至48.8%；缩短执行块大小（前瞻窗口）会严重破坏KEM的事件调度能力，性能降至31.1%和13.6%。

在RoboTwin2.0的马尔可夫任务上，EventVLA（83.8% Easy, 81.6% Hard）相比其基础模型QwenOFT（80.0% Easy, 78.0% Hard）性能略有提升，证明其内存机制不会损害基础反应式控制能力。

图3：ARX ACONE双臂机器人上的真实世界实验设置和结果。评估了四个记忆密集型操作任务：Find Block Easy、Find Block Hard、Pick-X-Times和Pick in Order。图展示了EventVLA相比反应式策略π0.5和记忆增强基线πMEM的成功率优势。

在真实世界双臂操作评估中，EventVLA在四个任务（Find Block Easy/Hard, Pick-X-Times, Pick in Order）上取得了显著优势（90%， 60%， 90%， 75%），远超反应式基线π0.5（0-10%）和记忆基线πMEM（0-50%），验证了其在物理环境中捕获和保留关键瞬态视觉线索的有效性。

总结与启发

本文的核心贡献有两点：1）提出了EventVLA框架，通过将基础视觉锚点与前の瞻性驱动的动态关键帧证据内存（KEM）模块相结合，实现了对稀疏、任务关键视觉证据的高效捕获与利用，解决了长视野操作中的记忆问题。2）提出了RoboTwin-MeM诊断基准，该基准明确隔离和参数化了需要记忆瞬态中间视觉证据的非马尔可夫任务，为评估VLA策略的中间状态记忆能力提供了严格平台。

论文自身提到的局限性在于，其事件缓冲区容量有限，在事件密度极高的超长视野任务中可能面临缓冲区饱和和早期关键证据被淘汰的风险。

本工作对后续研究的启示在于：证明了稀疏、事件驱动的视觉记忆是解决长视野非马尔可夫操作问题的有效途径，且这种记忆机制可以与端到端VLA策略无缝集成。未来的工作可以探索分层记忆结构或压缩表示来处理更长时间尺度和更高密度的事件序列。

💡 一句话总结

本文针对长时程机器人操作任务中，因视觉线索被遮挡导致标准VLA策略失效的“非马尔可夫”记忆瓶颈问题，提出了EventVLA框架。其核心技术是**动态关键帧证据记忆模块**，该模块通过直接预测未来关键帧概率，自主选择并稀疏存储任务关键的视觉证据。在包含17个仿真任务和4个真实世界双手任务的评估中，EventVLA相比现有记忆增强VLA方法，取得了**平均成功率提升40%**的显著性能优势。
