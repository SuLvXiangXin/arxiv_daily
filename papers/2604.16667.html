Emergency Stopping for Liquid-manipulating Robots

arXiv: 2604.16667 作者: Ville Kyrki Team 日期: 2026-04-17

📝 详细解读

研究背景与动机

机器人操作开放液体容器具有挑战性，因为液体对容器加速度和急动度高度敏感。尽管无溢出液体操作已被广泛研究，但在意外危险下需要紧急停止的情况却很少被关注，而突然刹车可能导致危险的液体溅出。现有方法主要依赖于简化的机械晃动模型或专注于最小化引起晃动的力，但均未考虑执行时可能出现的意外碰撞危险，这些危险需要机器人快速停止以确保安全。本文针对在紧急制动时如何兼顾快速停止与防止液体溢出的具体痛点，提出将紧急停止视为一个最优控制问题。核心思路是：在模型预测控制框架下求解该问题，生成时间最优且无溢出的停止轨迹，并将其作为一个即插即用的安全层，集成在现有的无晃动运动规划方法之上。

方法详解

本文提出的紧急停止系统整体框架基于模型预测控制。当紧急停止被触发时，系统以20Hz的频率反复求解一个有限时域的最优控制问题，生成任务空间（笛卡尔空间）的最优加速度指令。随后，通过另一个小规模的二次规划问题，利用解析加速度控制方法将任务空间指令转换为满足关节运动学限值的关节空间指令，并由一个高频（如1000Hz）的实时控制环路执行。

核心模块包括状态空间建模、基于二次规划的优化问题构建，以及解析加速度控制。

  1. 状态空间模型：系统状态包含13个变量：末端执行器的3维线速度、球形摆模型的2个倾斜角及其角速度、容器姿态的3个欧拉角及其角速度。控制输入为容器的6维笛卡尔加速度。系统离散化的状态方程如论文中式(9)所示，其中状态转移矩阵 (A_k) 和控制矩阵 (B_k) 是关键。为了在实时计算中处理非线性，论文对球形摆动力学方程进行了特殊线性化，保留了垂直加速度 ( \ddot{z} ) 与摆角 ( \theta, \phi ) 之间的双线性耦合项（式3, 4），并在每个优化时域内围绕上一轮求解得到的名义轨迹进行线性化。
  2. QP问题构建：目标函数（式16）旨在最小化累积的末端执行器速度（以实现快速停止），并包含一个很小的急动度惩罚项用于平滑。防溢出约束作为软约束引入，通过松弛变量 ( \delta_{\theta,k}, \delta_{\phi,k} ) 和高昂的惩罚权重 ( c_3, c_4 ) ( ( c_1 < c_2 \ll c_3 = c_4 ) ) 来确保执行。约束条件包括系统动力学（式17）、防溢出约束（式18, 19，即摆角与容器倾斜角之差不超过允许的最大晃动角）、以及笛卡尔空间的速度和加速度限值（式20, 21）。
  3. 解析加速度控制：为了将任务空间解 ( \mathbf{u} ) 转换为关节空间指令 ( \mathbf{q}, \mathbf{\dot{q}}, \mathbf{\ddot{q}} ) 并满足关节位置、速度、加速度限值，论文构建了另一个QP问题（式23-29）。该问题在满足机器人运动学关系（式26）的前提下，最小化关节指令及松弛变量的二次成本。

与现有方法相比，创新点体现在：1) 首次将液体操作中的紧急停止问题形式化为一个同时优化停止时间和防溢出的最优控制问题；2) 提出了一种保留关键非线性耦合项的线性化策略，使模型能处理6维空间运动，而非仅限于平面运动；3) 整个方法被设计为一个可集成于现有无晃动运动规划器之上的安全层，实现了对突发危险的即时反应。

实验与结果

实验在仿真环境和真实的7自由度Franka Emika Panda机器人上进行。使用了装有水的圆柱形容器（内径80mm，水位高100mm，对应摆长21mm）。对比的基线方法仅最小化累积速度并施加相同的急动度惩罚，但不包含晃动建模或防溢出约束。

关键实验结果：

  1. 仿真参数分析：如图1所示，停止时间在摆长较短且允许晃动角较小时最长。当允许晃动角增大时，短摆长容器的停止速度更快。防溢出约束的违反程度很小，最大平均违反为0.29度，峰值0.81度。

    图2：停止时间随摆长和允许最大晃动角变化的热力图。显示了参数之间的权衡关系。

  2. 模型误差鲁棒性：如图2所示，当摆长模型存在误差时，最大晃动违反随误差增大而稳步增加。即使模型误差达到+50%（即摆长估计偏长25mm），最大违反为2.03度，表明方法对模型误差具有一定鲁棒性。

    图3：模型误差（摆长估计错误）导致的绝对和相对晃动约束违反情况。方法对适度建模误差具有鲁棒性。

  3. 真实世界验证：使用Lissajous轨迹进行测试，在高速段触发紧急停止。如表I所示，本文方法将最大晃动控制在5.3度（允许5度），仅轻微超出0.3度，停止时间为0.87秒。而基线方法虽然停止更快（0.73秒），但产生了22.3度的剧烈晃动，远超安全限值。

    图5：基线方法在真实实验中的最大晃动。测量值为16.4mm（22.3度），严重违反约束。

  4. 速度曲线：图6和图7分别展示了本文方法和基线方法在紧急停止期间的速度曲线。基线方法由于无约束，减速更激进。本文方法的速度曲线与仿真基本吻合，但实际中因存在微小速度振荡而略欠激进。

    图6：本文方法在仿真和真实世界中的紧急停止速度曲线。红色竖线表示紧急停止开始时刻。

    图7：基线方法的紧急停止速度曲线。停止时间更短，但导致剧烈晃动。

  5. 模型误差的实体验证：在真实系统中故意将摆长低估和高估50%。低估时（图8），控制器因模型对加速度更敏感而采取过度平滑的制动，晃动极小（1.8度），但停止时间延长至0.99秒。高估时（图9），控制器过于激进，导致晃动超出限制达8.1度（62%违反）。

    图8：摆长低估50%时的速度曲线对比。制动过于平滑，晃动被过度抑制。

    图9：摆长高估50%时的速度曲线对比。制动过于激进，导致晃动约束被违反。

消融实验总结：通过对比基线方法（仅最小化速度+急动度惩罚）凸显了引入晃动动力学模型和防溢出约束的必要性。基线方法证明了仅靠平滑（急动度惩罚）无法防止溢出。模型误差实验则分析了关键参数（摆长）不准确时对性能的影响。

总结与启发

本文的核心贡献在于：1) 首次形式化并解决了液体操作机器人的紧急停止问题，在快速制动与防溢出之间取得了平衡；2) 提出了一种基于MPC的实时优化框架，该框架可作为即插即用的安全层集成到现有无晃动运动规划器中；3) 通过详尽的仿真和真实机器人实验验证了方法的有效性、鲁棒性，并揭示了与基线方法的显著性能差异。

论文提到的局限性包括：方法的鲁棒性依赖于液体动力学模型的准确性，尽管实验显示对适度误差（如摆长误差）具有鲁棒性，但严重的模型失配仍可能导致约束违反。此外，仿真与真实实验之间存在一定差距（如速度振荡的影响），表明在更复杂的真实动力学面前模型仍有改进空间。

这项工作对后续研究的启示包括：将所提出的安全层与更广泛的危险检测和反应系统集成；探索使用学习或自适应方法来在线估计或调整液体模型参数以提高鲁棒性；以及将该框架扩展到更复杂的场景，如非刚性容器或多相流体。

💡 一句话总结

本文解决了机器人操纵开放液体容器时，因意外危险需紧急停止却易导致液体溅出的核心问题。提出一种紧急停止系统，将问题建模为最优控制问题，在模型预测控制（MPC）框架中实时求解，生成时间最优且无溅出的停止轨迹。该方法作为即插即用的安全层，可叠加于现有无溅运动规划方法之上，并考虑非线性液体动力学。通过仿真和7-DoF Franka Emika Panda机器人实验验证，该方法实现了快速紧急停止且无液体溅出。
