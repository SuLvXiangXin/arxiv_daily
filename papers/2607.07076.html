PriGo: Test-Time Primitive Guidance to Diffusion and Flow Policies for Adaptive Robotic Manipulation

arXiv: 2607.07076 作者: Liming Chen Team 日期: 2026-07-08

📝 详细解读

研究背景与动机

模仿学习已成为机器人操作的主导范式，尤其是扩散模型和流匹配策略，能够直接从示教中生成复杂的视觉运动行为。然而，尽管性能强劲，这些策略在跨任务和环境的泛化上常常失败。关键原因在于现有策略倾向于模仿表面的动作关联，而非底层操作意图。受人类行为组合结构的启发，本文提出了PriGo，一个用于鲁棒机器人操作的原语引导的推理时自适应框架。PriGo的核心思路是：在不重新训练的前提下，通过一个轻量级原语预测模块和可微分的指导机制，在推理时引导扩散或流策略生成的动作，使其符合结构化的操作原语，从而提升模型的鲁棒性、长时程执行能力和泛化能力。

方法详解

PriGo框架包含两个核心组件：一个从观测中预测原语分布的轻量级原语分类器PANet，以及一个在推理时约束动作生成的可微分原语指导机制。该框架可以无缝集成到预训练的扩散或流策略中。

图2：PriGo框架概览。给定视觉观测和语言指令，原语分类器PANet预测概率化的操作原语。在推理时，预训练策略生成的动作被转换为软原语分布，并通过可微分原语指导与预测的原语对齐。基于梯度的细化操作将动作引导至语义一致的轨迹，而无需重新训练骨干策略。

1. 原语表示与分类
PriGo引入了一个紧凑的8类操作原语集合作为结构化动作先验：𝒴 = {“idle”, “grasp”, “release”, “push”, “pull”, “rotation”, “push+rotation”, “pull+rotation”}。为了自动生成训练标签，论文定义了原语动作硬分类函数 Φ(𝐚ᵏ)，该函数基于相邻帧动作在平移量 ‖𝐱ᵏ‖、旋转量 ‖𝐫ᵏ‖ 和夹爪宽度变化 |wᵏ - wᵏ⁻¹| 上是否超过预设阈值（τ_trans, τ_rot, τ_w）以及平移方向（𝐱₁ᵏ 的正负）来决定当前动作所属的原语类别。

基于此，训练一个原语分类器 PANet：𝐲̂ᵏ = PANet(𝐎ᵏ)。它采用DINOv2作为视觉编码器，T5作为文本编码器，后接多模态融合模块和MLP分类头。重要的是，PANet预测的是概率化的原语分布，而非硬标签，这提高了原语间模糊过渡时的鲁棒性，并自然支持多原语指导。

2. 可微分原语指导机制
为实现可微指导，定义了由生成动作诱导的软原语分布。给定一个可微分的评分函数向量 𝐟ᵏ（其分量由动作的平移、旋转、夹爪宽度等特征线性组合而成），通过温度缩放softmax得到软分类概率分布：𝐩ᵏ = softmax(𝐟(𝐚ᵏ)/τ)。

原语指导的损失函数定义为预测分布与动作诱导分布之间的交叉熵：
ℒ_PG(𝐚ᵏ, 𝐎ᵏ) = -(1/B) * Σ H(PANet(𝐎ᵏ), 𝐩ᵏ)。
这种概率化形式支持平滑的原语间过渡（例如从“push”切换到“rotation”），减少了突变的行为修正，提高了轨迹一致性。

3. 与扩散策略集成
扩散策略通过T步迭代去噪从随机噪声 𝐚_Tᵏ 生成动作 𝐚_0ᵏ。PriGo将原语指导融入去噪过程。在每一步，先进行常规的去噪得到中间动作 𝐚̃ᵏ_{t-1}，然后通过预定义的反向扩散计划估计一个“干净”动作 𝐚̂ᵏ_0，最后用原语指导损失相对于该干净动作的梯度来修正中间动作：
𝐚ᵏ_{t-1} = 𝐚̃ᵏ_{t-1} - η ∇_𝐚 ℒ_PG(𝐚̂ᵏ_0, 𝐎ᵏ)。
这约束了逆扩散过程的更新方向，确保与预测原语的一致性。

4. 与流策略集成
流策略通过积分速度场从噪声 𝐚_0 = 𝐳 生成动作 𝐚_1。在推理时，PriGo在积分步骤中引入指导。每一步，先根据速度场更新得到 𝐚̃ᵏ_{t+δ}，并估计最终动作 𝐚̂ᵏ_1，然后用原语指导梯度进行修正：
𝐚ᵏ_{t+δ} = 𝐚̃ᵏ_{t+δ} - η ∇_𝐚 ℒ_PG(𝐚̂ᵏ_1, 𝐎ᵏ)。
这等价于定义了一个受引导的速度场 𝐯_θ^guided = 𝐯_θ - (η/δ) ∇_𝐚 ℒ_PG(𝐚̂ᵏ_1, 𝐎ᵏ)。

创新点：与需要重新训练或仅将原语作为条件输入的方法不同，PriGo是推理时的、插件式的框架；其指导机制是可微分的，允许基于梯度的精细调整；并且支持概率多原语引导，能处理复杂的原语组合与过渡。

实验与结果

评测基准与基线：在模拟环境中，使用了LIBERO、SIMPLER、CALVIN三个基准。集成了多种预训练策略进行测试，包括流策略 π_0、SmolVLA，以及扩散策略DP、CogACT、3DDA。对比了以上策略的原版及其与PriGo结合的版本（PriGo-FP 和 PriGo-DP）。在SIMPLER上还与RT-2-X、Octo-Base、OpenVLA等VLA模型对比。在CALVIN上与DTP、DP3、3DDA、ADPro等扩散策略对比。

PANet分析：

图3：左图为PANet在LIBERO上的混淆矩阵，分类准确率达94.0%，错误主要发生在语义相邻的原语之间（如push+rotation和push）。右图显示PriGo对自动标注阈值 τ_trans, τ_rot, τ_w 的变化不敏感，在较大范围内性能稳定。

模拟实验关键结果：

  • LIBERO：在空间变化、物体变化、目标变化和长时程四个设置上，PriGo为所有骨干策略带来了3-5个百分点的平均成功率提升（见表1）。例如，CogACT从87.8%提升至92.3%，轻量级DP从72.1%提升至75.6%。
  • SIMPLER：在Visual Matching和Variant Aggregation两种设置下，PriGo-DP（CogACT+PG）均表现最佳，相比原版CogACT平均分别提升5%和7%（见表2）。
  • CALVIN：在零样本长时程任务评估中，PriGo-DP（3DDA+PG）取得了98.1%的单任务完成率和4.18的平均正确轨迹长度，显著优于其他扩散策略（见表3）。

实机实验与定性结果：
在Franka Panda机器人上进行了三个连续餐桌布置任务测试。仅用不超过20个示教样本训练，PriGo-DP取得了81%的平均成功率，相较于原始CogACT提升了26个百分点。

消融实验：
论文指出，PriGo以即插即用的方式运作，这一特性已通过上述集成实验得到充分验证。消融研究表明，原语指导机制是性能提升的关键。在“Bring back a set of tableware to the basket”任务中，性能相对较低，这揭示了当前方法在处理某些特定任务序列时的局限性。

总结与启发

核心贡献：

  1. 提出了 PriGo，一个为机器人操作策略设计的即插即用、原语引导的推理时自适应框架。
  2. 引入了可微分原语指导机制，能在不重新训练的情况下，约束扩散和流策略的生成过程，使其输出结构化的操作行为。
  3. 设计了轻量级原语分类框架（PANet），具有稳定的跨任务原语表示和概率化多原语指导能力。

局限性：论文在实验部分指出，在“Bring back a set of tableware to the basket”任务上性能相对较低。此外，对于 π_0 和 SmolVLA 这类已具有强大泛化能力的大规模基础模型，PriGo带来的性能提升幅度相对较小。

启示：

  1. 结构化动作先验的有效性：为连续动作空间注入离散的、语义化的原语结构，能有效提升策略的鲁棒性和泛化能力，这为模仿学习提供了新思路。
  2. 推理时适应的潜力：在不改动预训练模型参数的情况下，仅通过推理时引入梯度引导即可显著改善策略表现，为模型部署和终身学习提供了高效、灵活的方案。
  3. 组合性与泛化：通过有限的基本原语组合应对复杂长时程任务，验证了组合性对于机器人智能的重要性。

💡 一句话总结

本文针对扩散与流策略在机器人模仿学习中泛化能力不足、易受环境变化影响的核心问题，提出测试时原语引导框架PriGo。该方法通过轻量级PANet模块从观测推断原语分布，并设计可微分引导机制在推理阶段动态修正生成的动作轨迹，确保语义一致性，无需重新训练即可集成于现有策略。实验在LIBERO、CALVIN等多个数据集及真实任务中表明，PriGo显著提升了策略的鲁棒性、长时执行成功率和跨任务泛化能力。
