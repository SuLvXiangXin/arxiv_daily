CoPark: Learning Reactive Parking via Self-Play

arXiv: 2606.04149 作者: Abhinav Valada Team 日期: 2026-06-02

📝 详细解读

研究背景与动机

在自动驾驶领域，自博弈强化学习（Self-play RL）在开放道路驾驶中取得了显著进展，这些方法依赖于强烈的车道先验和仅向前运动的运动学，且不要求亚米级的终端精度。然而，同时要求高精度操纵、严格空间约束和低速多智能体交互的任务，如反应式停车（Reactive Parking），尚未得到充分解决。反应式停车要求多辆车从随机初始位姿出发，在全程保持对邻近车辆反应能力的同时，以亚米级精度到达指定车位。这带来了一个根本性矛盾：高精度停车倾向于遵循固定的几何计划（承诺），而交互反应则要求在其它车辆侵入时立即偏离计划（灵活）。现有的模仿学习或纯奖励优化的策略往往顾此失彼：从稀缺的交互数据中难以学习鲁棒的交互行为，而纯策略学习要达到停车级精度则非常困难且不稳定。

本文针对这一“精度”与“反应性”难以在单一策略中共存的痛点，提出了CoPark方法。其核心思路是：通过一个残差策略架构，将离线计算的几何计划作为固定先验注入策略，以提供精度保证；同时，利用一个基于伙伴威胁信号进行调制的、通道非对称的先验释放机制，允许策略在纵向通道上灵活反应以进行让行，而在横向通道上则锚定先验以保持车位对齐，从而协调两者矛盾。

方法详解

CoPark的整体框架包含四个关键组件：离线运动学先验、带先验注入的残差策略、基于伙伴威胁的反应式让行以及闭环终端精炼层。所有组件在具有场景密度课程的多智能体自博弈环境下联合训练。

图2：CoPark架构总览。(a) 离线规划先验：为每个（场景，智能体）预计算的Hybrid A*路径和Stanley跟踪器提供几何参考。(b) 先验注入：一个基于ego、伙伴、道路、奖励条件等模块的残差执行器，将logits添加到受阶段门控的Stanley先验logits上。(c) 反应式让行：伙伴威胁信号调制模仿奖励，并非对称地释放纵向先验，同时锚定横向通道。(d) 终端精炼：残差执行器在计划完成后继续行动，在指向车位坐标系的精炼奖励下工作。(e) 自博弈策略优化：多智能体轨迹在稀疏到稠密的场景密度课程下，为带V-trace的PPO提供数据。

1. 离线运动学先验：为每个任务实例（停车场布局、车辆i）预计算一个固定的运动学“教师”。使用Hybrid A*搜索（仅静态碰撞检查）生成从初始状态到准备位姿的导航路径，并采样为一系列子目标。同时，生成从准备位姿到目标车位的操纵轨迹 τ_i。该轨迹由一个Stanley跟踪器读取，产生目标控制命令，作为后续的先验。

2. 残差策略与先验注入：一个共享参数的分类策略 π_θ 负责所有阶段的决策。仅在停车操纵阶段，离线先验被注入策略。具体而言，Stanley控制器输出的命令被编码为加速和转向通道上的高斯log先验，然后加到策略的logits上：
log π_θ(a|s) ∝ z_θ(s,a) + 1[ϕ_i,t = Maneuver] (α^acc(s) log p_prior^acc(a) + α^steer(s) log p_prior^steer(a))
其中，z_θ(s,a) 是有界的残差logits头，α^acc(s) 和 α^steer(s) 是通道依赖的依赖标量，源自一个学习的基础值 α(s)。

3. 基于伙伴威胁的反应式让行：这是协调精度与反应性的核心机制。

  • 伙伴威胁信号：通过公式 threat_i = Σ_j [-ḋ_ij]_+ exp(-d_ij/d_decay) 计算，聚合了K个最近邻居的接近速率和距离信息，形成一个连续的威胁度量。该信号被平滑映射为交互强度 ρ(s) ∈ [0,1]。
  • 威胁调制的模仿奖励：Stanley命令也作为行为克隆奖励，但其权重随 ρ(s) 连续放松：r_imit = α_imit (1 - ρ(s)) w_trust(s) exp(-‖u_i,t - û_i,t‖_2 / σ_imit)。其中信任权重 w_trust(s) 综合了横向跟踪误差、静态障碍物距离和计划进度，确保模仿奖励不会惩罚合理的安全偏离。
  • 非对称通道先验调制：依赖标量 α^c(s) 根据 ρ(s) 按通道以不同速率收缩：α^c(s) = α(s) (1 - κ^c ρ(s))，其中 κ^acc ≫ κ^steer。这使得纵向先验在交互强烈时放松，将控制权交给残差策略以进行刹车、保持或倒车等让行操作；而横向先验则保持较强锚定，以维持车位对齐。论文指出，通道不对称性 κ^acc - κ^steer 是关键的设计选择。

4. 闭环终端精炼层：由于动作网格离散化和让行引起的漂移，单次执行计划后很难直接满足成功容差。因此，策略 π_θ 在计划完成后继续行动，此时每步奖励切换为精炼奖励 r_ref。该奖励包含一个指向车位的、平滑饱和的梯度项和一个在容差范围内保持静止的奖励项，引导策略微调最终位姿直至满足连续多步的成功条件或耗尽预算。

5. 自博弈策略优化：采用基于GigaFlow食谱的多智能体自博弈训练，使用PPO with V-trace算法。训练时，所有智能体均由同一策略 π_θ 控制，形成一个自博弈过程。部署时，该策略是自我中心的，可应对任意不共享该策略的伙伴。

实验与结果

基准与数据集：作者构建了一个新的反应式停车基准，将Dragon Lake Parking (DLP) 和 DeepScenario Open 3D (DSC3D) 数据集集成到PufferDrive模拟器中。评估采用零样本方式，即策略仅在自定义的6个停车场布局上训练，然后在DLP和DSC3D上测试。测试时，ego车辆由待评估策略控制，非ego伙伴有两种脚本模式：反应模式（使用IDM模型沿记录路线行驶，会对ego做出反应）和非反应模式（严格回放记录轨迹）。

基线方法：对比了七种方法，涵盖三类：经典规划器（Reeds-Shepp曲线、Hybrid A*、多智能体模型预测控制MA-MPC）、交互感知停车RL方法（HOPE）、大规模RL范式（GigaFlow、CaRL）以及模仿学习规划器（Diffusion Planner，注：该方法直接在DLP/DSC3D演示数据上训练，非零样本）。

关键实验结果：
在反应式和非反应式伙伴两种模式下，CoPark在两个数据集上的成功率（SR）均显著领先。具体而言，在DLP数据集反应模式下成功率达84.7%，非反应模式下达79.7%；在DSC3D数据集反应模式下成功率达75.8%，非反应模式下达69.8%。同时，碰撞率（Coll）维持在3-6%的低水平，且脱离率（Off，指驶出可行驶区域）为0%。相比之下，大规模RL方法（GigaFlow, CaRL）虽碰撞率也较低，但成功率远低于CoPark；经典规划器和HOPE等方法则碰撞率或脱离率过高。Diffusion Planner成功率尚可，但因是在测试数据上训练，非零样本可比。

图3：CoPark策略涌现出的多智能体交互行为示例，包括倒车让行、操纵中让行、狭窄通道通行和排队。

图4：消融研究结果。从左至右分别移除了：反应式让行（固定先验）、通道不对称性（各向同性释放）、所有先验（纯残差策略）、终端精炼层。结果显示，反应式让行和通道不对称性对成功率和碰撞率有最关键的影响。

消融实验总结：
论文进行了系统的消融实验，验证了各个组件的贡献：

  1. 移除反应式让行（固定先验）：碰撞率急剧上升，成功率下降，证明动态调制先验对安全交互的必要性。
  2. 移除通道不对称性（各向同性释放）：性能大幅下降，甚至不如纯残差策略，验证了“纵向放松以让行，横向锚定以保精度”设计的核心作用。
  3. 移除所有先验（纯残差策略）：成功率极低，证实了离线先验对于达成高精度终端的必要性。
  4. 移除终端精炼层：成功率显著下降，说明该层对于弥补离散化和交互造成的终端误差至关重要。

图5：训练过程中，在训练集和验证集上的成功率随环境步数的变化曲线，展示了方法的收敛性。

图6：不同方法在DLP反应模式下的七个评估指标分布（小提琴图）。CoPark在成功率（SR）上分布最优且均值最高，在碰撞率（Coll）和脱离率（Off）上分布最集中且均值最低。

总结与启发

核心贡献：

  1. 问题定义：形式化了“反应式停车”这一闭环多智能体任务，它联合要求停车级终端精度、全过程交互感知以及在操纵过程中的主动反应能力，这是先前方法未能共同解决的组合。
  2. 方法提出：提出了CoPark方法，其核心机制是一个基于伙伴威胁调制的、通道非对称的离线运动学先验释放机制，并结合了一个用于终端精度微调的闭环精炼层。
  3. 基准构建：引入了首个用于闭环、反应式评估的多智能体停车基准，整合了DLP和DSC3D数据集到PufferDrive模拟器中。

局限性：论文自身提到，当前方法依赖于为每个实例预计算的离线计划。虽然该计划计算成本低廉，但如何将其扩展到完全未知的、需要在线规划的环境，仍是一个未解决的问题。

对后续研究的启示：

  1. 结构化先验释放：CoPark展示了一种新的范式，即根据任务的不同通道（如纵向/横向）对精度的各向异性容忍度，来结构化地释放先验控制权。这一原则可推广到其他需要平衡精确跟踪与灵活反应的任务中。
  2. 自博弈学习复杂交互：研究表明，在缺乏密集交互数据的情况下，通过精心设计奖励结构和课程学习，自博弈能够有效地涌现出复杂的多智能体协作行为（如倒车让行、排队），这为学习其他密集交互的低速机动任务提供了参考。
  3. 零样本泛化：方法在完全未见过的真实世界停车场布局（DLP/DSC3D）上取得了良好的零样本性能，证明了通过多样化仿真训练实现现实泛化的潜力。

💡 一句话总结

本文解决反应式自主停车中高精度目标与安全交互的冲突问题。提出CoPark方法，基于自玩强化学习和残差策略架构：预计算离线计划提供几何先验，残差头学习反应式修正；关键设计为威胁调制的通道不对称先验释放，纵向通道移交残差头以实现让行，横向通道锚定参考以保持亚米级精度。实验在多个停车场基准上，CoPark实现70-85%成功率，碰撞率仅3-6%，显著优于传统方法、模仿学习与大规模RL基线，并涌现出反向让行、窄通道通过等交互行为。
