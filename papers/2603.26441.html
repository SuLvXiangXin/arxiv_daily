120 Minutes and a Laptop: Minimalist Image-goal Navigation via Unsupervised Exploration and Offline RL

arXiv: 2603.26441 作者: Steven Morad Team 日期: 2026-03-27

📝 详细解读

研究背景与动机

当前图像目标视觉导航的主流方法依赖于大规模数据集、大量预训练和显著的计算资源，例如GNM、ViNT和NoMaD等导航基础模型或视觉-语言-动作模型。尽管这些模型在零样本泛化上表现出色，但将其部署到特定的、未建图的真实物理环境时，仍面临两大实际挑战：效率和平台特异性。具体而言，为弥合本体差异和视觉域偏移，通常需要进行领域自适应，这需要特定的轨迹格式和大量计算资源，使得快速部署变得困难且昂贵。

本文针对在特定目标环境中实现高效、低成本部署的痛点，提出了一个新视角：放弃对大规模预训练的依赖，转而追求纯粹的、高效的领域内学习。其核心思路是，将图像目标导航重新表述为一个离线目标条件强化学习问题，通过无监督数据收集与** hindsight goal relabeling 和离线策略学习**相结合，仅利用在目标环境中自主收集的少量数据，在消费级笔记本电脑上快速训练出一个可部署的轻量级策略。

方法详解

MINav 是一个高效、全自动的端到端图像目标导航技能学习流程。其整体框架不假设底层控制器、机器人执行器或相机细节，实现了高效的数据收集、整理和策略训练，最终策略可在同一环境中无需校准直接部署。

图3：MINav 流程总览。从目标环境中的自主探索开始，使用提出的粉红均匀噪声模型收集多样轨迹，使用冻结的 DINOv3 提取视觉表示，构建目标空间，并通过 hindsight goal relabeling 和 TD3+BC 离线训练导航策略。

1. 自主数据集收集（粉红均匀噪声）
为在有限的真实世界交互预算下最大化数据集覆盖范围，采用粉红噪声作为动作生成的基础过程，因其时间相关性在随机性和一致性之间提供了比白噪声更好的平衡。标准粉红噪声由高斯分布生成，导致机器人很少采样到其控制范围边界（如最大速度）附近的动作，限制了动作空间的覆盖。为解决此问题，MINav 提出粉红均匀噪声：对粉红噪声序列的每个高斯分布样本应用概率积分变换（使用标准正态分布的累积分布函数Φ），将其转换为均匀分布，同时保留原始信号的时间依赖性。变换后的信号被线性缩放到动作范围：a_t = a_min + (a_max - a_min) · Φ(x_t/σ)。这确保了动作空间的均匀边际覆盖，对于缓解离线RL中的外推误差至关重要。

2. 视觉表示与目标空间构建
为降低计算成本，采用冻结的 DINOv3 作为视觉骨干网络，提取观测图像的归一化特征 o'_t = φ(o_t)。由于探索策略是随机的，收集的数据集缺乏明确的导航目标。并非所有未来观测都适合作为目标，例如机器人非常靠近障碍物（如墙壁）时捕获的图像结构信息不足。为此，MINav 定义了基于 DINOv3 的空间标准差指标来过滤无效目标。对于输入图像，DINOv3 从其最后一层隐藏层生成一个 28×49 的补丁嵌入网格。计算中心裁剪区域内嵌入的 SSD，记为 σ_spa(o)。低 SSD 表示视觉同质、结构内容有限的观测，将其从有效目标空间中排除。全局有效目标集 𝒢 定义为：𝒢 = {φ(o) | o ∈ 𝒟, σ_spa(o) > δ_SSD}，其中 δ_SSD = 0.02。

3. 状态、目标与奖励设计

  • 状态表示：为在部分可观测性下近似马尔可夫性质，将 RL 状态 s_t 定义为连续四个观测的视觉特征拼接：s_t = [o'_{t-3}, o'_{t-2}, o'_{t-1}, o'_t]，以提供时序上下文并隐含捕获机器人的速度和加速度信息。
  • Hindsight Goal Relabeling：为提供密集且有意义的监督，采用 hindsight relabeling 策略。对于从数据集中采样的转移 (s_t, a_t, s_{t+1})，通过两种状态分布的混合动态采样 hindsight goal g：
    • 几何未来采样：给定当前时间步 t，从几何分布 P(K=k) = p^{k-1}(1-p)（k≥1）中采样偏移量 k，并设置 hindsight goal 为 g = o'_{min(t+k, T)}。
    • 全局均匀采样：从全局有效目标集 𝒢 中均匀采样一个有效目标。
      实践中，使用 (0.5, 0.5) 的混合分布进行评论家训练，仅使用均匀采样进行演员训练。
  • 目标条件奖励：通过计算堆叠状态 s_t 中最近视觉表示与目标 g 之间的平均余弦相似度来评估任务成功。一旦 S(s_t, g) 超过预设阈值 δ_done = 0.8，智能体将获得稀疏奖励 R(s_t, g) = 1，否则为 0，并设置终止标志 d=1。

4. 离线策略学习与模型选择

  • 策略优化：使用基于 TD3+BC 的简约离线 RL 算法优化导航策略。评论家网络通过最小化时序差分目标进行训练。演员目标则是最大化 Q 值并最小化行为克隆惩罚：J(π_φ) = E[Q_θ1(s_t, â_t, g) - λ||â_t - a_t||^2]，其中 â_t = π_φ(s_t, g)，λ = 0.001。
  • 离线模型选择：由于策略完全离线训练，需要在不进行额外交互的情况下选择最佳策略检查点。MINav 采用拟合 Q 评估作为离线验证指标。FQE 训练一个独立的评估 Q 网络 Q_ω^{π_φ}，通过最小化 TD 误差来估计执行策略的期望回报，并使用估计的策略值对检查点进行排名，选择最终部署模型。

实验与结果

实验在 MuJoCo 模拟和真实世界环境中评估 MINav。真实世界评估使用 Unitree Go2 四足机器人，在三个难度递增的室内场景进行：简单空房间、标准办公室和复杂大房间。对比基线包括 Random、NoMaD、ViNT 和 GNM。

关键实验结果：

  1. 探索效率与数据集质量：在模拟中，粉红均匀噪声策略在归一化状态熵、动作熵和状态-动作联合熵上均优于粉红高斯噪声、OU噪声和白噪声基线（图6）。下游导航性能评估显示，在相同数据预算下，使用粉红均匀噪声数据训练的策略成功率始终最高（图7a）。例如，仅用1小时粉红均匀数据训练的智能体，其成功率与使用3小时粉红高斯数据训练的相当。MINav 表现出明显的正向扩展趋势：随着数据预算从1小时增加到3小时，下游成功率稳步提升。
  2. 离线模型选择有效性：FQE 分数与地面真实成功率之间存在强线性相关性，斯皮尔曼等级相关系数为 0.91（图7b），表明 FQE 是真实策略成功率的可靠代理，可支持无需在线交互的模型选择。
  3. 真实世界视觉导航性能：如表1所示，在简单场景中，使用2小时数据训练的 MINav（DINOv3-ViT-S）取得了 95% 的成功率，远高于 NoMaD (18%)、ViNT (8%) 和 GNM (9%)。在标准和复杂场景中，MINav 也显著优于所有基线。同时，MINav 的模型参数量（2M）和训练成本（150 TFLOPs-hours）远低于基线方法（>5000 TFLOPs-hours）。
  4. 可扩展性与鲁棒性：MINav 的性能随数据集大小增加而提升（从1小时到2小时）。此外，方法无需修改即可适配于四足机器人和轮式机器人两种不同平台，并在存在动态人类干扰的环境中保持鲁棒性。

图7：(a) 使用不同探索策略收集的数据集训练的离线策略的成功率。(b) FQE 分数与地面真实成功率之间的相关性，表明 FQE 是离线检查点选择的可靠代理。

图8：真实世界评估环境。考虑三个难度递增的室内环境：(a) 简单，(b) 标准，(c) 复杂。

总结与启发

核心贡献：

  1. 提出了一个高效、全自动的端到端流程（MINav），能够在消费级笔记本电脑上，利用不到120分钟自主收集的真实世界数据，训练并部署一个鲁棒的图像目标导航策略。
  2. 证明了离线目标条件强化学习结合无监督探索和** hindsight goal relabeling **，是实现高效、纯粹领域内视觉导航学习的可行途径。
  3. 该方法展示了良好的可扩展性（性能随数据增加而提升）和跨平台鲁棒性，且无需依赖大规模导航预训练或人类演示。

局限性：
论文提到，该方法依赖于 DINOv3 的泛化能力来提供视觉表示。此外，稀疏奖励信号在更复杂的场景中可能限制策略学习。

启示：
这项工作挑战了当前依赖大规模预训练的导航范式，为快速机器人策略原型设计和部署提供了一条低计算成本的替代路径。它启示后续研究可以探索更高效的视觉表示学习方法、设计更稠密的奖励函数以处理更复杂的任务，以及将这种轻量级、快速自适应的框架扩展到更长期的规划或操作任务中。

💡 一句话总结

本文针对图像目标视觉导航依赖大规模数据集与计算资源、部署效率低的问题，提出MINav方法。该方法将导航任务建模为离线目标条件强化学习，核心结合无监督探索自主收集数据、后视目标重标记技术及离线策略学习，实现高效轻量训练。实验表明，该方法仅用120分钟在笔记本电脑上即可完成从数据收集到策略部署的全流程，在仿真与真实环境中显著提升探索效率，优于零样本导航基线，且性能随数据集规模扩大而提升。
