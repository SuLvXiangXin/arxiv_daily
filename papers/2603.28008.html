Energy-Aware Imitation Learning for Steering Prediction Using Events and Frames

arXiv: 2603.28008 作者: Alois Knoll Team 日期: 2026-03-30

📝 详细解读

研究背景与动机

在自动驾驶的转向预测任务中，端到端学习通过从视觉观察到运动估计的直接映射取得了显著进展。目前主流方法是使用基于帧的相机作为单一模态输入，但其在高速运动、低光照和过度曝光等挑战性条件下性能会显著下降。事件相机作为一种新兴的仿生视觉传感器，通过检测像素级亮度变化输出异步事件流，具有低延迟、高动态范围和高时间分辨率等优势，能够有效补充帧相机在动态信息和结构信息捕捉上的不足。

当前融合事件与帧数据的方法主要依赖于简单的特征拼接或复杂的注意力机制。特征拼接方法无法充分利用两种模态的互补特性；而基于自注意力或交叉注意力的融合模块虽然能提升性能，但结构复杂，未能有效解决实际应用中对效率与性能权衡的关键需求。

本文针对现有融合方法在效率与性能平衡上的局限性，提出了一种新的能量感知视角。核心思路是设计一个基于能量函数的跨模态融合模块（ECFM），通过计算3D权重动态地、高效地融合事件与帧特征，并引入一个能量感知解码器来建模预测不确定性，从而生成更可靠、更安全的转向预测。

方法详解

整体框架由一个双流骨干网络、多个能量驱动的跨模态融合模块（ECFM）以及一个能量感知解码器构成。输入为同步的帧图像和事件流（事件被预处理为2D直方图），输出为预测的转向角。

图2：提出的模型架构。包含三个主要部分：双流骨干网络（顶部为基于帧的ResNet，底部为基于事件的ResNet）、多个ECFM模块（插入在不同层级之间）以及能量感知解码器。

双流骨干网络：采用两个并行的ResNet（如ResNet-50）分别处理帧和事件数据。每个ResNet包含五个层级（Layer0至Layer4），特征图分辨率逐层降低。在每个层级的输出后，都插入一个ECFM模块进行跨模态特征融合。

能量驱动的跨模态融合模块（ECFM）：该模块是本文的核心创新，旨在以极低的可学习参数量实现高效融合。给定来自帧流和事件流的输入特征 (F_f) 和 (F_e)，ECFM的核心是利用能量函数生成3D权重图。

图3：提出的ECFM架构。基于能量函数生成3D权重。融合后的特征 (F_f^{fused}) 和 (F_e^{fused}) 被拼接并通过一个 (Conv_{1\times1}) 层产生最终输出 (F_o)。该卷积层是ECFM中唯一的可学习部分。

首先，假设单个通道内的所有像素服从相同分布，计算该通道所有像素特征的均值 (\mu) 和方差 (\sigma^2)。对于像素特征 (n)，其最小能量 (e_n) 的计算公式为：
[ e_{n}=\frac{4(\sigma^{2}+\lambda)}{(n-\mu)^{2}+2\sigma^{2}+2\lambda} ]
其中 (\lambda) 为系数因子。能量 (e_n) 越低，表示该像素特征与其周围特征的区分度越高，重要性越大。因此，像素特征的重要性可由 (1/e_n) 表示。对帧特征 (F_f) 和事件特征 (F_e) 分别计算能量图 (\mathbf{E_f}) 和 (\mathbf{E_e})，并通过取倒数得到初始3D权重 (W_f = 1/\mathbf{E_f})， (W_e = 1/\mathbf{E_e})。

接着，对权重应用 Sigmoid 函数进行激活，得到 (A_f = \mathrm{Sigmoid}(W_f)) 和 (A_e = \mathrm{Sigmoid}(W_e))。激活后的权重分别与原始输入特征相乘，得到增强后的特征 (F_f^a = A_f \otimes F_f) 和 (F_e^a = A_e \otimes F_e)。

为了促进跨模态信息交互，将两个模态的激活权重相加并通过 Softmax 归一化，得到跨模态激活向量 (A^{cross} = \mathrm{Softmax}(A_f + A_e))。该向量用于加权两个模态的原始特征，得到跨模态加权特征 (F_f^{cross} = A^{cross} \otimes F_f) 和 (F_e^{cross} = A^{cross} \otimes F_e)。

最后，将增强特征与跨模态加权特征相加，得到每个模态的融合后特征：(F_f^{fused} = F_f^{cross} + F_f^a)， (F_e^{fused} = F_e^{cross} + F_e^a)。将 (F_f^{fused}) 和 (F_e^{fused}) 拼接，并通过一个唯一的可学习层—— (Conv_{1\times1})，生成该ECFM模块的最终输出特征 (F_o)。

能量感知解码器：解码器用于从融合后的多层次特征中预测转向角。其结构轻量，包含三个卷积块（每个块含卷积、批归一化、ReLU激活），并在第二和第三块中加入Dropout以防止过拟合，最后接两个全连接层输出预测值。本文的关键创新是在解码器中引入了一个方差估计分支，用于建模预测的不确定性。该分支输出预测分布的方差 (\Sigma(x_n, \theta))，与均值 (\mu(x_n, \theta)) 共同构成一个多元高斯分布。

为了训练方差估计分支，本文提出了能量感知损失（Energy-aware loss）。该损失基于能量距离，用于衡量预测分布与真实值分布之间的差异。对于每个样本，从预测分布 (\mathcal{N}(\mu(x_n, \theta), \Sigma(x_n, \theta))) 中采样 (M) 个点 (z_{n,i})，其能量损失 (L_E) 的蒙特卡洛近似为：
[ L_E = \frac{1}{N}\sum_{n=1}^{N}\left(\frac{1}{M}\sum_{i=1}^{M}||z_{n,i}-z_n|| - \frac{1}{2(M-1)}\sum_{i=1}^{M-1}||z_{n,i}-z_{n,i+1}||\right) ]
其中 (z_n) 是真实转向角。总损失函数为 Smooth L1 损失与能量损失 (L_E) 的加权和。这种非局部性的评分规则鼓励模型将概率质量集中在真实值附近，即使不精确位于该点，从而学习到更高质量的预测分布，增强了安全性和鲁棒性。

实验与结果

数据集与评估指标：实验在两个公开的真实世界数据集上进行：DDD20（包含约51小时、4000公里的城市和高速公路驾驶数据）和DRFuser（包含城市环境白天和夜晚的数据）。评估指标采用均方根误差（RMSE）和平均绝对误差（MAE），并同时考量模型参数量、GFLOPs和FPS以评估效率。

对比方法：与多种先进的（SOTA）方法进行了对比，包括：仅使用帧的方法（Frame-only）、仅使用事件的方法（Event-only）、早期融合方法（Early Fusion）、EyEF、CAFR、DRFuser以及EFNet。

图1：在DDD20和DRFuser数据集上的性能对比。提出的方法在RMSE和MAE指标上均优于EyEF、CAFR、DRFuser和EFNet等现有方法。

关键定量结果：在DDD20数据集上，本文方法的RMSE和MAE分别达到 0.0541 和 0.0378，显著优于所有对比方法（例如，比次优的EFNet在RMSE上相对提升约7%）。在DRFuser数据集上，本文方法的RMSE和MAE分别为 0.0628 和 0.0445，同样取得最佳性能。效率方面，本文方法在保持高精度的同时，参数量和计算量（GFLOPs）与基于注意力的复杂融合方法（如DRFuser）相比具有优势，实现了精度与效率的良好平衡。

消融实验：

  1. ECFM有效性：将ECFM替换为简单的拼接（Concat）或相加（Add）操作，性能显著下降（例如在DDD20上RMSE从0.0541分别升至0.0553和0.0556），证明了ECFM设计的优越性。
  2. 能量感知解码器有效性：移除方差估计分支及能量损失（仅用Smooth L1损失），性能下降（RMSE从0.0541升至0.0546），证明了建模不确定性的价值。
  3. 融合位置分析：实验表明，在ResNet的所有四个阶段（Layer1-4）都插入ECFM模块能获得最佳性能，缺少任何一层都会导致精度损失。
  4. 能量函数分析：将ECFM中的能量函数替换为SE或CBAM等通道注意力机制，性能均不及原版，验证了基于能量函数的3D权重生成机制更适合本任务。

图11：在DDD20数据集上的定性结果对比。本文方法（Ours）的预测曲线（红色）与真实值（黑色）最为接近，尤其在转向变化剧烈（如第1400和3800帧附近）时，比EyEF、CAFR等方法更准确、平滑。

图14：在DRFuser数据集上的定性结果对比。在复杂的城市驾驶场景中，本文方法的预测曲线（红色）同样展现出与真实值（黑色）更高的贴合度，波动更小。

总结与启发

本文的核心贡献在于：1）提出了一个新颖的能量感知模仿学习框架，通过有效融合事件与帧数据来提升转向预测的鲁棒性和准确性；2）设计了能量驱动的跨模态融合模块（ECFM），利用能量函数动态生成3D融合权重，以极少的可学习参数实现了高效的特征互补融合；3）引入了能量感知解码器及对应的能量损失函数，通过建模预测不确定性来提升预测分布的质量和系统安全性。

论文自身提到的局限性主要在于：实验主要在公开数据集上进行，未来需要在更复杂、多变的真实驾驶环境中进行进一步验证，以评估其泛化能力和极端条件下的可靠性。

本工作对后续研究的启示包括：1）能量函数为多模态融合提供了一种轻量且高效的新思路，可扩展至其他需要动态特征加权或模态选择的视觉任务；2）将不确定性估计与模仿学习结合，是提升自动驾驶决策安全性的一个有前景的方向；3）事件相机与帧相机的互补性融合策略，为在高速、高动态范围或照明条件恶劣的场景下构建更稳健的感知系统提供了可行方案。

💡 一句话总结

本文针对自动驾驶中仅依赖帧摄像头在高速运动、光照变化等挑战性条件下转向预测不准确的问题，提出一种能量感知模仿学习框架。该框架融合事件摄像头与帧摄像头数据，关键技术包括能量驱动的跨模态融合模块（ECFM）和能量感知解码器，以高效整合多模态信息并提升预测可靠性。在DDD20和DRFuser两个真实数据集上的实验表明，该方法优于现有最先进方法，显著提升了预测性能。
