Memory Retrieval in Visuomotor Policies for Long-Horizon Robot Control

arXiv: 2606.25136 作者: Roberto Martín-Martín Team 日期: 2026-06-23

📝 详细解读

研究背景与动机

在家庭等部分可观测环境中工作的通用机器人需要记忆来保障自主性，它们必须回忆过去多样化的信息以完成各种任务。当前主流方法包括基于人工设计和启发式的记忆表示或检索规则，但这些方法依赖于任务特定的假设，泛化能力有限。使用注意力机制在长上下文中进行记忆检索的Transformer架构提供了有前景的替代方案，因为它从数据中学习检索。然而，直接将长上下文Transformer架构融入离线模仿学习会带来两个关键挑战：（1）策略可能学习到过去信息与预测动作之间的虚假相关性；（2）由于预测不准确及其与环境的复合交互，记忆中的误差会随时间累积，导致模型漂移和长时程控制中的级联故障。

本文针对这两个具体痛点，提出了HALO方法，其核心思路是：通过从视觉语言模型蒸馏任务相关的先验知识来引导记忆检索，减少虚假相关性；并通过Top-k稀疏注意力限制检索范围，减轻误差累积的影响，从而实现更可靠的长时程控制。

方法详解

图3：HALO概述。该方法学习一个视觉运动策略，该策略从过去的观察和动作中检索信息以预测底层机器人动作（中间部分），并通过视频问答（VQA）任务借用视觉语言模型的先验知识来引导检索任务相关信息（左侧），同时使用稀疏注意力减少模型漂移（右侧）。

HALO的整体框架旨在学习一个在部分可观测条件下进行长时程模仿学习的策略πθ(at | τt, l)。其输入是到当前时间t为止的交互历史τt（包含观测ot和动作at）以及自然语言任务指令l，输出是当前的低级动作at。模型架构包含三个主要部分：（i）模态特定的编码器（观测编码器gθ_obs和动作编码器gθ_act），用于将异构输入映射到公共潜在空间；（ii）策略主干fθ，负责在编码后的历史记忆ℳt上进行记忆检索和处理；（iii）任务特定的预测头，包括动作预测头hθ_act和文本预测头hθ_text。

图4：视频问答数据生成流程概述。图像首先通过接地视觉模型转换为文本，轨迹被总结为包含子任务和对应帧号的信息。大型语言模型根据这些总结和任务描述生成任务相关的问答对，随后进行正确性和相关性验证，过滤掉约20%的数据。

HALO的核心模块体现在两个关键的创新设计上：

  1. 通过视频问答（VQA）蒸馏视觉语言模型（VLM）先验：该模块旨在解决虚假相关性问题。具体做法是，首先通过一个多阶段管道（轨迹文本摘要 -> 问答合成 -> 自动过滤）从专家演示轨迹中自动生成任务相关的、依赖记忆的问答对(u, v)。这些问题是关于历史信息的（例如物体位置、事件顺序），要求策略必须检索特定的历史片段才能正确回答。策略被共同训练以完成两个目标：模仿专家动作（损失函数ℒ_IL）和回答关于历史观测的VQA问题（损失函数ℒ_VQA）。最终的总损失为ℒ(θ) = ℒ_IL(θ) + λℒ_VQA(θ)。VQA监督将VLM中关于“什么信息是任务相关的”先验知识蒸馏到策略中，直接指导其检索机制，而模仿学习目标则确保检索到的信息能够支撑具体的动作预测。

  2. 使用Top-k注意力稀疏化减少模型漂移：该模块旨在解决闭环执行中误差累积的问题。在标准的注意力机制中，查询qt会与记忆中所有元素的键ki计算相似度并进行加权聚合。HALO对此进行了稀疏化限制：只选择与当前查询最相关的k个记忆元素（ℐ_k = TopK({si}, k)），并仅在这k个元素上计算注意力权重（公式6），其余元素的权重为零。这样，策略在每一步决策时仅依赖于一小部分最相关的历史信息，从而限制了预测噪声和累积误差通过记忆进行传播和放大，有助于维持长时程执行的稳定性。训练时采用直通估计器处理Top-K操作的非可微性。

与现有方法相比，HALO的创新点在于：（1）不是简单地利用VLM生成文本摘要，而是通过共同训练的VQA目标直接监督记忆检索过程，将任务相关性先验与动作预测基础相结合；（2）引入了可学习的、端到端的Top-k稀疏检索机制，而非依赖人工规则或固定表示进行信息筛选，以应对长时程闭环控制中的误差累积挑战。

实验与结果

论文在ReMemBench仿真基准（包含4个需要不同类型记忆的子任务）以及5个真实世界机器人任务（涉及固定基座和移动机械臂两个平台）上进行了评估。

图5：真实世界任务可视化。在四个固定和移动操作任务中评估HALO，包括一个具有强部分可观测性的人机协作任务，智能体需要从记忆中检索不同类型的信息。

对比的基线方法包括：标准Transformer、SAM2Act++（基于物体中心表示）、ReMemBer（选择性存储规则）、人工设计特征以及仅使用VLM先验的策略。

图7：仿真基准结果。HALO在需要空间、关系、数值和事件时间信息的多种任务上平均成功率最高（41%），显著优于其他基线方法。

关键实验结果：在ReMemBench上，HALO取得了41%的平均成功率，显著优于标准Transformer（22%）、基于人工规则的方法（ReMemBer, 18%）和任务特定特征（20%）。仅使用VLM先验（通过VQA）的策略成功率仅为18%，这凸显了将先验知识与动作预测基础相结合的重要性。在真实世界任务中，HALO也表现出色，平均成功率达63%。

图8：不同记忆检索机制的消融研究。完整的HALO（VQA + Top-K）性能最佳，去除任一组件性能都会下降，证明了每个组件的重要性。

消融实验总结了每个组件的贡献：移除VQA监督（仅IL + Top-K），性能下降7%；移除Top-K稀疏注意力（仅IL + VQA），性能下降9%；两者都移除（标准Transformer）则性能最差。这证实了VQA引导和稀疏注意力对于提升长时程控制性能都是至关重要的。

图10：不同稀疏度k对8分钟长时程检索性能的影响。较小的k（更稀疏的注意力）在长序列上能保持较高的检索质量，而较大的k（更密集）则会导致性能下降，表明限制检索范围有助于减轻长时程累积误差的影响。

总结与启发

本文的核心贡献有两点：1）提出了一种通过共同训练视频问答（VQA）任务来蒸馏视觉语言模型先验的方法，以引导策略记忆检索关注任务相关信息，减少虚假相关性；2）引入了可学习的Top-k稀疏注意力机制，通过限制每一步检索的信息量来减轻长时程闭环执行中的误差累积和模型漂移，增强了鲁棒性。

论文自身提到的局限性在于：生成VQA数据时采用的轨迹到文本的总结过程可能会丢失对低级控制至关重要的细粒度信息。

本工作对后续研究的启示在于：将大规模模型的知识先验与特定领域（如机器人控制）的 grounding 信号相结合，并针对序列决策中的长期依赖和误差传播问题设计专门的架构约束（如稀疏性），是提升智能体在复杂、部分可观测环境中长期性能的有效途径。

💡 一句话总结

本文针对通用机器人在部分可观测环境中执行长时程任务时，记忆检索机制泛化性不足、易受虚假相关和误差累积影响的核心问题，提出HALO视觉运动策略。该方法结合视觉语言模型先验生成记忆依赖问答对，通过联合训练抑制虚假相关；并采用稀疏注意力限制检索范围，以减少闭环控制中的误差累积。实验表明，HALO能引导策略从长达八分钟的过去经验中检索任务相关信息，提升了长时程控制的可靠性。
