TacCoRL: Integrating Tactile Feedback into VLA via Simulation

arXiv: 2606.11743 作者: Chenfanfu Jiang Team 日期: 2026-06-10

📝 详细解读

研究背景与动机

当前，视觉-语言-动作模型的广泛预训练为其在机器人操作任务中提供了强大的视觉表征、语言理解和动作先验。然而，在诸如装配、插入等接触密集型的精细操作任务中，视觉观测常常无法可靠地获取局部接触状态，例如物体是否对齐、接触发生的位置或压力分布。虽然近期工作致力于通过构建大规模触觉数据集、训练触觉-语言-动作模型或在推理时引入触觉引导来增强触觉能力，但本文关注一个不同的切入点：如何在不依赖大规模触觉预训练或从头训练触觉策略的前提下，将触觉反馈高效地整合到现有的VLA骨干网络中。

仅使用真实演示数据来注入触觉感知存在显著局限性：数据收集成本高昂、数据偏向于成功的常规行为，而最能体现触觉反馈价值的“接近失败”状态（如轻微错位、接触错误表面等）在数据中占比极少；直接在硬件上探索这些状态则存在传感器损坏风险且重置成本高。因此，本文的核心思路是利用一个与现实对齐的模拟器作为安全、可重置、可验证的闭环触觉学习环境，通过模拟-真实协同训练与模拟器强化学习相结合的方式，将触觉反馈注入预训练的VLA策略，并学习接触读数应如何调节动作响应，特别是在那些演示数据中稀缺的关键状态下。

方法详解

TacCoRL框架旨在通过一个两阶段的模拟到真实管道，使预训练的VLA模型适应并融合触觉反馈。整体流程包括：1) 混合模拟与真实数据的协同训练，为策略提供触觉调节的动作先验；2) 利用稀疏奖励的强化学习在模拟环境中细化策略，同时使用真实数据监督作为锚点防止策略漂移。

图2：TacCoRL整体流程。(A) 数据收集：收集真实演示和模拟遥操作数据，并利用MimicGen扩充模拟数据。(B) 模拟-真实协同训练：触觉信息被编码并通过接触感知的门控机制，同时调制视觉语言模型的上下文和动作专家。(C) 后续训练：在模拟环境中进行交互式回合收集以改进策略的闭环任务性能，同时使用真实数据的监督损失约束更新，避免偏离真实机器人数据分布。

模拟环境对齐：为使模拟环境能有效支持策略学习，该方法对齐了模拟与现实设置中面向策略的接口：1) 场景配置与视觉任务上下文；2) 控制器响应（通过系统辨识匹配关节的增益和前馈扭矩）；3) 触觉统计特性（校准触觉信号，匹配接触发生、位置、大小和时变特性）。图4展示了控制器响应校准前后与真实轨迹的对比，以及校准后模拟与真实接触回合的归一化触觉读数分布对齐情况。

图4：控制器与触觉对齐。(A) 在控制器系统辨识前后，对 withheld 的J4关节进行目标轨迹回放，对比真实与模拟响应。(B) 触觉校准后，从匹配的接触回合中得到的归一化触觉读数直方图对比。

触觉增强的VLA策略：策略基于π-0.5风格的VLA模型构建。基础的VLA将语言、图像和本体感知 token 化为 Z_t_base。触觉接口新增一个触觉编码器 E_τ，它将最近L步的历史触觉窗口 h^τ_t 编码为 M 个隐藏维度为 d 的触觉 token Z^τ_t。受OpenTouch启发，历史窗口能捕捉接触加载、释放和演变的动态过程。一个二元的接触门控 c_t 被引入，用于在读数仅为背景噪声时抑制触觉 token 的影响。门控后的触觉 token Z̃^τ_t 通过两条路径融入模型：1) 通过交叉注意力更新视觉/语言/本体上下文 Z̄_t_base；2) 作为 conditioning token 直接提供给动作专家。这种设计确保了在无接触时保持预训练VLA行为，而在接触发生时允许触觉证据重塑动作块。

模拟-真实协同训练：此阶段通过混合监督学习来“热启动”策略，使其初步建立触觉观测与专家动作块之间的关联。损失函数是模拟数据集 D_sim 和真实数据集 D_real 上标准条件流匹配损失的加权和，权重系数 α 控制模拟数据的相对贡献。模拟数据通过人类遥操作演示并结合MimicGen进行数据扩增得到。协同训练提供了触觉调节的动作先验，并为后续稀疏奖励的强化学习提供了可行的初始化。

带有真实数据锚点的后续训练：在协同训练之后，使用近端策略优化在模拟环境中进行强化学习，以任务级的稀疏成功/失败谓词作为奖励，优化策略的闭环接触行为。为防止策略过度适应模拟器特性而发生“漂移”，在RL优化目标中同时加入了一项基于真实演示数据的流匹配监督损失，由权重 β 控制。最终，策略在训练后抛弃评论家、奖励和特权状态，直接部署到真实机器人上。

实验与结果

实验在四个双手接触密集型任务上进行：试管插入、拼图、装配任务#1和装配任务#2。实验平台使用双手机器人，并在真实与模拟间对齐了相机、动作和触觉接口。对于每个任务，收集50条真实演示和20条模拟遥操轨迹，并使用MimicGen将模拟数据扩增至200条。

图3：四个接触密集型双手任务的真实与校准后模拟工作空间设置。累积的物体放置指示了用于域随机化和评估的位姿范围。

模拟器内结果：表1显示，直接从基础VLA模型进行强化学习在所有任务上均告失败（成功率0.0%）。模拟-真实协同训练为策略提供了强初始化，使后续模拟器RL成为可能。在协同训练后添加探索噪声的情况下，视觉-触觉策略的初始平均成功率（29.3%）高于纯视觉策略（22.5%）。经过RL后，视觉-触觉策略在模拟器中的平均成功率达到了78.5%，显著高于纯视觉策略的60.5%。图6进一步表明，在所有任务上，融合触觉的策略在RL训练过程中始终获得更高的成功率。

图6：在模拟器强化学习过程中，视觉-触觉策略在所有任务上一致地比纯视觉策略获得更高的成功率。

真实世界评估：表2对比了不同训练阶段策略在真实机器人上的表现。仅使用真实数据微调、模拟-真实协同训练、以及结合了RL的后续训练，三种设置下视觉-触觉策略的平均成功率分别为33.8%、43.8%和72.5%，均优于对应的纯视觉策略（21.3%、30.0%和50.0%）。这表明性能增益不仅来自模拟器RL，更源于触觉传感的引入。

图5：经过后续训练的视觉-触觉VLA策略在四个接触密集型双手任务上的代表性真实机器人执行结果。

消融实验：以装配任务#2为例，图7探究了协同训练权重 α 和真实数据锚点权重 β 的影响。结果显示，α=0.5（平衡的模拟/真实数据混合）比 α=0.95（高权重模拟数据）或 α=0（仅真实数据）能带来更好的模拟成功率与真实部署成功率。在 α=0.5 时，引入适度的真实数据锚点（β=0.1或1.0）能将真实部署成功率从45%提升至80%，同时模拟成功率也超过92%，说明锚点能有效防止策略漂移又不失RL的优化能力。而过强的锚点（β=5.0）则会抑制RL优化，降低性能。

图7：在装配任务#2上消融协同训练比例α和真实锚点权重β。展示了模拟成功率（左）、真实数据锚点损失（中）和真实世界部署成功率（右）的变化。

总结与启发

本文的核心贡献在于：1) 提出了一种触觉调节接口，使预训练VLA策略能够适应触觉输入，无需大规模触觉预训练或从头训练；2) 设计了一个模拟到真实的后续训练流程，结合模拟-真实协同训练与模拟器强化学习，并以真实数据为锚点，学习可迁移的接触引导动作细化；3) 在四个双手接触密集型任务上验证了方法的有效性，最终策略在真实机器人上取得了72.5%的平均成功率，显著优于纯视觉和仅模仿学习的基线。

论文也指出了自身的局限性：1) 仍需要少量真实的触觉演示数据作为锚点；2) 搭建任务级别的数字孪生模拟环境仍需人工努力；3) 当前框架聚焦于刚性或近刚性物体的接触密集型操作，对于高度可变形物体或流体的接触模拟尚不完善。

这项工作为将触觉反馈整合到VLA模型中提供了一条切实可行的路径，其利用对齐的模拟器进行安全、系统的接触交互学习，并通过锚定机制保证策略真实性的思路，对如何在数据稀缺、风险高的接触场景中提升机器人策略的鲁棒性具有启发意义。未来工作可探索结合触觉表征学习与更先进的触觉模拟来进一步减少对真实触觉数据的需求。

💡 一句话总结

该论文针对视觉-语言-动作（VLA）模型在接触密集型操作任务中，因视觉观察缺失局部接触状态而导致性能不足的问题，提出TacCoRL框架。方法核心是通过真实对齐的模拟环境进行仿真-真实协同训练，并利用基于仿真的强化学习优化策略，让策略学会根据触觉读数在接近失败的状态下调制动作，无需大规模触觉预训练。实验表明，该方法在四个双手接触密集型任务上，将平均成功率从基线50.0%提升至72.5%。
