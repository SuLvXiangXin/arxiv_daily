WSA $_1$ : a 3D-Centric World-Spatial-Action Model for Generalizable Robot Control

arXiv: 2607.03941 作者: Heng Tao Shen Team 日期: 2026-07-04

📝 详细解读

研究背景与动机

目前，机器人基础模型的主流范式可分为两大类：视觉-语言-行动模型和世界-行动模型。VLA模型在预训练的视觉语言模型基础上扩展，遵循“理解后执行”范式，擅长语义理解但缺乏明确的规划与因果推理能力。WAM模型基于视频生成模型，遵循“想象后执行”范式，通过联合建模未来帧预测与行动生成提升可靠性。然而，这两种范式均存在根本局限：它们缺乏对3D世界动态与机器人行为之间相互约束关系的显式联合建模。VLA本质上是反应式框架，而现有WAM（即使是3D WAM）也仅遵循单向的“预测-执行”流程，无法建模行动如何塑造3D世界演化以及3D世界状态变化又如何反过来指导行动生成这种双向因果关系。另一方面，训练这些模型严重依赖大规模真实机器人演示数据，获取成本高昂且限制了模型的泛化能力。

本文针对机器人基础模型泛化能力不足和数据依赖严重的核心痛点，提出了一种全新的3D中心的世界-空间-行动联合建模范式。其核心思路是通过在一个共享潜在空间中统一三个互补的学习目标（行动引起的3D世界预测、3D一致的2D视觉思考和3D逆动力学建模），显式地学习世界与行动之间的因果相互约束，从而以数据高效的方式学习可迁移的物理常识。

方法详解

WSA1 的整体框架基于混合专家Transformer架构，旨在共同学习世界因果关系、空间认知和行动执行三个层次。模型的输入是当前时刻的观测，包括任务指令 ( l )、2D视觉观测 ( v_t ) 和机器人本体感知 ( s_t )。在训练阶段，还需要对应的未来短时行动轨迹 ( A_t ) 和可选的未来3D场景观测 ( G_t )、2D视觉观测 ( V_t )。模型的输出是联合学习到的三个潜在表示：未来2D视觉令牌 ( h_v )、未来3D场景令牌 ( h_g ) 和去噪后的行动令牌 ( h_{act} )，最终通过3D行动专家解码生成连续机器人动作。

图3：WSA1的模型概览。它采用混合专家Transformer结构，包含三个互补的专家：2D空间专家负责基于3D世界感知的视觉思考，3D空间专家负责行动引起的3D世界预测，3D行动专家负责3D逆动力学建模。双向因果注意力机制强制依赖规则，将3D一致的视觉思考和世界-行动相互约束统一在一个共享潜在空间中。

核心模块包括三个专家：

  1. 2D空间专家：作为世界感知的视觉思考分支，基于预训练的视觉语言模型初始化。其目标是预测未来2D视觉动态的抽象令牌 ( h_v = f_{2D}(O_t, G_t) )，而非RGB像素，以关注图像的本质特征。
  2. 3D空间专家：负责内部3D因果世界建模。给定可执行行动序列，它预测未来3D场景演化的潜在表示 ( h_g = f_{3D}(O_t, A_t) )。
  3. 3D行动专家：作为去噪扩散Transformer，其目标是在给定当前观测和未来3D潜在表示的条件下，预测完整的行动区块。它通过迭代交叉注意力和去噪过程生成潜在行动表示 ( h_{act} = f_{act}(O_t, G_t, \hat{A}_t) )，实现3D逆动力学映射。

关键的创新点在于3D中心的世界-行动因果注意力机制。该机制定义了三类预测令牌之间的依赖规则：(1) 所有预测令牌均可关注当前观测令牌 ( h_t )；(2) 未来2D视觉令牌 ( h_v ) 可以关注3D场景令牌 ( h_g )，以学习2D-3D视觉一致性；(3) 3D场景令牌 ( h_g ) 和行动令牌 ( h_{act} ) 之间具有完全的双向注意力。这最后一条是实现世界-行动相互依赖建模的关键，它驱动模型同时捕获行动如何塑造世界演化以及世界状态如何指导行动生成的双向因果关系，而不仅仅是学习相关性映射。

每个专家对应一个特定的学习目标与损失函数：

  • 3D世界感知的视觉思考：使用MSE损失 ( \mathcal{L}_{\text{2D}} ) 最小化预测的视觉令牌与通过预训练tokenizer提取的真实令牌之间的差异。
  • 行动条件的3D世界建模：使用MSE损失 ( \mathcal{L}_{\text{3D}} ) 最小化预测的3D场景潜在表示与从演示数据中提取的真实3D几何状态之间的误差，对应于前向内部模型。
  • 3D逆动力学建模：采用流匹配损失 ( \mathcal{L}_{\text{ACT}} ) 来生成连续动作，最小化预测流场与真实流场之间的误差。

总体目标函数为三者之和：( \mathcal{L}{\text{total}} = \mathcal{L}{\text{2D}} + \mathcal{L}{\text{3D}} + \mathcal{L}{\text{ACT}} )。训练采用两阶段策略，在预训练和后训练阶段都进行三个能力的协同学习。

与现有方法相比，WSA1 的创新性体现在用统一的世界-空间-行动联合建模范式替代了VLA的单向语义-行动映射和WAM的单向世界-行动映射，首次通过双向注意力显式地建模了3D世界动态与机器人行为之间的因果相互约束。

实验与结果

实验使用了RoboTwin2.0模拟基准和七个真实世界桌面操作任务（如RGB积木排序、物体整理、清扫垃圾、解开铅笔袋等）进行评估。真实机器人实验涉及两台不同构型的机器人：单臂AgileX PiPER (7-DoF) 和双臂ARX Lift2 (14-DoF)。

对比的基线方法包括领先的VLA模型（如RT-2、OpenVLA、3D-VLA）和WAM模型（如Motus、Fast-WAM、PointWorld）。

关键实验结果如下：

  • 在RoboTwin2.0仿真基准上，WSA1-L取得了93%的成功率，显著优于所有对比的基线模型。
  • 在7个真实世界操作任务中，WSA1模型在成功率上平均比现有最好的开源基线模型（Fast-WAM）提高了约20%。特别是在需要复杂手部操作和3D空间推理的任务（如“清扫垃圾”、“解开铅笔袋”）上，提升更为显著。

图4：在RoboTwin2.0模拟基准和7个真实世界任务上的定量性能对比。WSA1-L在模拟任务中达到93%成功率，在真实任务中平均比最佳基线( Fast-WAM)提升约20%。

图11：任务“清扫垃圾”的定性结果。WSA1能够预测出连贯的3D场景变化序列（右下），并基于此生成有效的双臂协作动作（用蓝色和红色轨迹表示），成功将垃圾扫入簸箕。

消融实验部分，论文验证了WSA范式核心组件的重要性：

  1. 双向因果注意力：移除3D场景令牌 ( h_g ) 和行动令牌 ( h_{act} ) 之间的双向注意力连接（改为单向），会导致在所有真实世界任务上的性能平均下降8.5%。这证明了双向世界-行动约束对于泛化的关键作用。
  2. 不同的世界感知表示：比较了使用密集点云、3D高斯溅射和本文采用的深度潜在表示三种方式。结果表明，使用深度基础模型（如Depth-Anything）提取的潜在表示在性能和计算效率上取得了最佳平衡。
  3. 自监督损失：单独移除 ( \mathcal{L}{\text{2D}} ) 或 ( \mathcal{L}{\text{3D}} ) 都会导致性能下降，同时使用三者能实现最佳效果，验证了联合学习三个目标的必要性。

图5：消融实验结果。(a) 移除双向注意力会导致性能显著下降；(b) 不同的3D表示方法对比；(c) 不同损失组合的影响，验证了联合学习的有效性。

总结与启发

本文的核心贡献在于：1) 提出了一个创新的、以3D为中心的世界-空间-行动联合建模范式，首次将行动条件的3D世界预测、3D一致的2D视觉思考和3D逆动力学统一在一个模型中，实现了世界与行动的双向因果学习；2) 实例化了该范式，构建了名为WSA1的可泛化机器人基础模型，并设计了双向因果注意力机制来实现联合优化；3) 通过仅使用6,000小时（其中仅含1,000小时真实机器人数据）的异构演示数据进行预训练，在模拟和真实任务上取得了极具竞争力的性能，证明了3D中心联合建模可实现数据高效的学习。

论文提到的自身局限性包括：模型需要3D观测（如深度图）作为输入，这可能限制其在仅有RGB摄像头场景的适用性；此外，工作主要关注短视距操作任务，尚未探索其在需要长期闭环规划任务中的潜力。

这项工作对未来研究的启示是：超越单纯模仿学习或单向预测的范式，显式建模机器人行为与3D物理世界演化之间的双向因果约束，是解锁更强大、更数据高效、泛化能力更强的机器人基础模型的关键路径。它为实现通用机器人系统提供了一条切实可行且成本可控的途径。

💡 一句话总结

本文针对现有机器人基础模型缺乏3D物理动态推理能力、泛化性受限的核心问题，提出了**WSA1模型**。其技术核心是首创的**3D中心世界-空间-行动建模范式**，通过联合建模3D世界状态演变与机器人动作之间的互约束关系，学习面向未来行为的3D世界感知视觉思维。仅使用6K小时（含1K小时真机数据）的专家演示进行高效预训练后，在RoboTwin2.0仿真基准取得了93%的成功率，并在真实机器人控制任务中比最优模型平均性能提升20%，证明了3D联合建模是实现高效、泛化机器人系统的可行路径。
