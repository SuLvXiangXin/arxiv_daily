Freeform Preference Learning for Robotic Manipulation

arXiv: 2606.32027 作者: Chelsea Finn Team 日期: 2026-06-30

📝 详细解读

研究背景与动机

机器人自主策略改进的核心瓶颈在于奖励设计，特别是在长视界操作任务中。目前主流方法存在关键局限：基于二元成功标签的方法信号过于稀疏，为强化学习算法带来巨大负担，难以扩展到复杂任务或纳入任务完成度之外的行为约束；基于成形标量奖励的方法虽提供了更密集的信号，但仍聚焦于任务进度指标，忽略了任务执行方式的重要标准；而基于二元偏好学习的方法虽然能提供更密集的奖励信号，但要求标注者将多维度的判断标准（如速度、安全性、放置质量）压缩成一个单一的、含混“整体偏好”标签，在长视界任务中导致偏好难以提供且监督信号模糊不清。

本文针对二元偏好学习将多维判断压缩成单一信号的具体痛点，提出了允许标注者使用自然语言自由定义偏好轴并进行多维度比较的新视角。核心思路是：先收集标注者沿自定义自然语言轴（如“速度”、“安全性”）的成对轨迹偏好，以此训练一个语言条件化的多轴奖励模型；然后利用该模型训练一个可以同时优化所有这些人类指定维度的奖励条件化策略。

方法详解

Freeform Preference Learning（FPL）方法的核心框架是一个迭代的训练过程：从初始的离线数据集中收集自由形式的偏好标注，训练语言条件化的奖励模型，再使用该模型训练多轴奖励条件化策略，随后使用新策略收集数据并迭代更新。整个过程旨在学习一个既能捕捉多维行为属性又能在测试时被引导的策略。

核心模块一：基于自由形式人类反馈的奖励模型学习。传统方法要求标注者对两条轨迹给出一个整体质量的二元偏好，而FPL允许标注者为每对比较的轨迹定义K_ij个自然语言轴（如“摆放的正式程度”、“速度”、“安全性”），并沿每个轴l_k提供二元偏好y_k。奖励模型r_ϕ接收一条轨迹τ和一个自然语言轴标签l_k，输出一个标量分数。其训练目标是对经典Bradley-Terry模型的扩展，最小化以下负对数似然损失函数：

L_FPL-Reward(ϕ) = -E_[...][ Σ_(k=1)^(K_ij) log σ( (2y_k - 1)( r_ϕ(τ_i|l_k) - r_ϕ(τ_j|l_k) ) ) ]

为了捕捉轨迹级别的偏好和时序依赖，该轨迹级奖励被定义为所有观测前缀分数的累加和：r_ϕ(τ, l_k) = Σ_(i=1)^(T) g_ϕ(o_(1:i), l_k)，其中g_ϕ是一个多模态Transformer，用于评估给定轴下的观测片段。这与为单一“整体质量”轴训练独立奖励模型或为预定义轴集合训练多个独立模型的方法不同，FPL利用预训练视觉-语言模型的表征能力，学习一个单一、可泛化到相似语义描述（如“快”、“高效”）的语言条件化模型。

图2：FPL方法整体框架。左侧展示了如何从自由形式偏好中学习多维度奖励函数，该函数基于自然语言偏好轴为完整轨迹评分。右侧展示了利用该奖励函数的多维度性，FPL学习出一个能在文本形式的多轴上条件化奖励的行为策略，在测试时可通过改变条件奖励引导其产生高奖励行为。

核心模块二：基于多维度奖励函数的策略提取。为避免将所有轴折叠为单一标量奖励可能导致奖励黑客问题，并保留组合泛化和测试时可引导性的潜力，FPL训练一个直接条件化于自然语言奖励轴及其对应得分的策略。具体地，从奖励模型训练数据集中选取或总结出K_π个代表性轴L = {l_k}，策略π_θ在状态s_t下的目标是在给定所有轴描述l_k及其对当前轨迹的预测奖励r_ϕ(τ|l_k)的情况下，最大化采取动作a_t的对数概率。其损失函数为：

L_FPL-Policy(θ) = -E_[τ_i ∼ D][ Σ_(t=1)^(T_i) log π_θ( a_i^t | s_i^t, l_1, r_ϕ(τ_i|l_1) ... l_K_π, r_ϕ(τ_i|l_K_π) ) ]

这种方法可以作为离线或在线强化学习使用。在在线设置中，算法迭代进行：收集最新策略的交互数据，对新数据征集偏好标注，更新奖励模型和策略。偏好轴的内容可能随着策略能力提升而演变，形成从关注任务初期阶段或粗略行为属性到关注后期阶段和精细细节的课程。测试时，通过对用于条件化的目标奖励值进行标准化，以便在分布内轻松查询策略，实现行为引导。

实验与结果

实验在四个真实世界操作任务（将立方体放入目标碗、折叠短裤、摆盘吐司、布置餐桌）和两个模拟任务（物体重排、双模态方块及其反转版本）上进行。真实世界任务使用DROID设置和Franka机器人。

图3：真实世界任务上的基线性能对比。FPL在所有任务上学习到的策略性能都更高，平均比次优基线提高了38个百分点。二元偏好信号过于模糊，难以学习高性能策略；稀疏的成功信号太弱，无法为成功解决任务提供必要的监督。

对比的基线方法包括：单一偏好学习（标准二元整体偏好学习）、优势条件化、加权回归（使用FPL奖励模型但用各轴奖励平均值进行加权回归策略提取）、过滤BC（在离线数据和成功策略数据上训练）、以及BC（纯粹的模仿学习）。在表1中，FPL在模拟任务上也全面超越了所有基线。

图4：每个基线和每个桩（左/右）的成功时间。尽管演示数据中没有包含右侧桩上的快速数据（仅有左侧桩的快速数据），FPL在右侧桩上实现了快速轨迹，表现出行为的组合性，而基线方法则没有。

FPL表现出行为的组合泛化能力。在双模态方块任务中，离线数据集只包含右侧桩上的慢速轨迹和左侧桩上的快、慢速轨迹。FPL成功学会了在右侧桩上执行更快的放置行为，其吞吐量达到了1.19 ± 0.01，超越了演示数据，而单一偏好基线仅为0.73 ± 0.05。这归因于多维奖励学习与奖励条件化策略提取的结合。

图5：每个点代表方块（立方体）的最终位置，颜色对应目标碗的颜色。通过FPL，我们可以在测试时通过提示优化不同的奖励来引导策略，而基线方法无法做到。

FPL展现出测试时可引导性。在双模态方块（反转）任务中，使用同一训练好的策略，仅通过改变奖励条件化（将目标从左桩改为右桩），FPL在反转任务上实现了1.24 ± 0.01的高吞吐量，而其他方法（如加权回归：0.09 ± 0.06）无法做到。这得益于在多维奖励上进行奖励条件化策略提取。

图6：在“布置餐桌”任务上的定性奖励分析。比较FPL学习的自由形式偏好奖励（左）和二元偏好奖励（右）在一个代表轨迹上的表现。FPL的轴条件化奖励在对应的子任务事件附近具有时间局部性，而二元偏好奖励则将行为压缩为单一分数，并在轨迹末尾产生一个大的尖峰，尽管当时并未完成主要子任务。

FPL在没有显式子任务分割的情况下，为长视界任务学习到了更密集的奖励信号。如图6所示，在“布置餐桌”任务的一个轨迹上，FPL学习到的奖励（如“盘子摆放”、“杯子摆放”）在相应子任务完成时出现峰值，提供了清晰、局部的进度信号；而二元偏好学习得到的单一奖励则在整个轨迹上模糊不清，且在未完成重大子任务的末尾产生误导性的大幅度峰值。

总结与启发

本文的核心贡献在于：1. 提出了自由形式偏好学习框架，通过语言条件化的多轴奖励模型，解决了传统二元偏好学习中监督信号模糊的问题。2. 展示了由此框架训练的策略在多个真实与模拟任务中显著优于传统方法（平均提升38%），并且具备了行为组合泛化能力和测试时可引导性。3. 验证了该方法能在无显式分割的情况下，为长视界任务学习到具有时间局部性的密集奖励信号。

论文自身提到的局限性在于：该方法依赖于人类标注者提供自由形式的偏好，其质量和广度会影响奖励模型的泛化能力；同时，奖励模型需要在训练分布之外对新的自然语言轴描述进行泛化。

这项工作对后续研究的启示在于：将人类反馈从单一的二元信号解放到多维、自然的描述，能极大地提升机器人学习的效果和灵活性。它提示未来在人与机器人的交互中，可以更多地利用自然语言的丰富性和结构性，来定义复杂的任务目标和行为标准，实现更符合人类意图、更灵活可调的机器人策略。

💡 一句话总结

本文针对机器人操作任务中奖励设计瓶颈，尤其是长周期任务中稀疏奖励信号不足和二元偏好模糊的问题，提出自由形式偏好学习（FPL）方法。该方法允许标注者定义自然语言偏好轴（如速度、安全性），并沿各轴提供成对偏好，通过学习语言条件化奖励模型，训练策略优化多维度行为。在四个真实世界和两个模拟长周期操作任务中，FPL比稀疏奖励和二元偏好方法性能提升38个百分点。
