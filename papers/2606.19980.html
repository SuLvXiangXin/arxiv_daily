ENPIRE: Agentic Robot Policy Self-Improvement in the Real World

arXiv: 2606.19980 作者: Guanya Shi Team 日期: 2026-06-18

📝 详细解读

研究背景与动机

实现灵巧的机器人操作高度依赖人类监督和算法工程，这是实现通用物理智能的主要瓶颈。虽然新兴的编码智能体能够生成代码来自动化算法搜索，但其成功目前主要局限于数字环境。本文认为，自动化机器人研究所缺失的抽象概念是一个针对真实世界的、可重复的策略改进反馈循环：重置场景、执行策略、验证结果、并优化下一次迭代。

针对这一痛点，本文提出了ENPIRE框架。其核心思路是一个两阶段方法：先通过人类指导的自动研究来构建具备自动反馈和验证功能的环境接口，随后完全基于真实世界的反馈进行在线自主自动研究，以持续改进策略。

方法详解

ENPIRE是一个智能体现控框架，它将真实世界的技能获取分解为两个自动研究过程，对应于其四个核心模块：

  1. 环境 (EN) 模块：负责安全约束、自动任务验证和自动重置。
  2. 策略改进 (PI) 模块：编码智能体在其中生成见解、提出假设并直接修改训练代码。
  3. Rollout (R) 模块：将构建的环境API封装为类Gym接口，用于策略评估，接收传感器输入并输出动作指令。
  4. 进化 (E) 模块：在多机器人集群中实现去中心化协作，智能体通过Git共享、挑选和合并成功的训练方案。

第一阶段：基于人类反馈的环境构建
此阶段的目标是构建一个结构化的、智能体友好的物理环境交互接口，一次性人力成本将在后续阶段被分摊。

  • 硬安全约束：限制机器人的构型空间和运动学行为到安全操作范围，一旦违反则触发任务失败和自动重置。
  • 自动验证：编码智能体被要求通过过程工具调用合成一个二元奖励函数，以区分任务成功与失败。给定少量成功和失败演示视频及本体感觉记录，智能体优化预测精度和处理延迟（例如，将Zip-tie插入任务的推理延迟优化到150毫秒以内）。

图1：为Zip-tie插入任务设计奖励函数。通过对图像进行裁剪和分割，检测Zip-tie捆扎带是否穿过头部。为了减少误报，智能体考虑了多个相机视角。

  • 自动重置：任务完成后，智能体执行一系列工具调用将环境恢复到初始状态。对于接触丰富的任务，采用类似CaP-X的模块化操作技能，将机器人直接重置到最具挑战性阶段的起始点（如插入销钉、安装GPU或抓取剪刀的精确开始位置），从而让学习系统聚焦于这些精度瓶颈。

第二阶段：基于真实世界反馈的自动策略改进
环境API构建完毕后，编码智能体获得一个支持基础端到端策略训练的代码库的写入权限，目标是通过自主实验最大化任务成功率。在PI模块中，智能体查阅文献、提出假设并修改训练代码。智能体调用环境API来记录机器人轨迹、视频和奖励信号，并通过检查这些统计信息来指导持续改进。

  • 多智能体扩展加速：通过部署N个智能体到N个物理机器人上异步测试N个假设，可以显著加速自动研究。每个智能体从相同的基准策略训练代码库分支，并通过Git进行自主协作。智能体会自发地挑选、复制或合并同伴的成功训练方案。

图2：ENPIRE方法整体框架概述。它展示了从任务描述开始，通过环境构建（EN）和自动策略改进（PIRE）两个阶段，使编码智能体能够进行物理自动研究。

创新点：与现有工作（如主要在仿真中迭代或需要在部署前停止修订的方法）相比，ENPIRE的核心创新在于直接在真实硬件上闭合“提出假设-实验验证”的循环，将真实世界策略学习转化为一个可由智能体管理的可控优化过程。系统支持多种策略学习范式，包括启发式学习、工具调用、行为克隆以及离线/在线强化学习。

实验与结果

实验设置：

  • 任务：Push-T（非抓取对齐）、Pin Insertion（4mm间隙销钉插入）、GPU-insertion、Ziptie-cutting。
  • 平台：双灵巧手6自由度YAM机器人。
  • 评价指标：在给定固定重试次数（8次）的一次Rollout中完成任务的概率。这种度量方式同时捕捉了一次性精度和面对环境不确定性的情境性恢复能力。
  • 对比的编码智能体：Codex (GPT-5.5 xhigh)、Claude Code (Opus 4.7 High)、Kimi Code (Kimi K2.6 thinking)。

关键实验结果：

  1. 启发式学习：在仿真Push-T环境中，Claude Code和Codex在约2小时内达到95%成功率，而Kimi Code耗时加倍。
  2. 基于梯度的策略改进：在真实的Pin Insertion任务中，编码智能体测试了行为克隆（BC）、带在线数据聚合的迭代BC、以及带BC正则项的在线/离线/离线到在线RL等多种方法，成功将策略优化至接近100%的成功率。

图3：在PushT和Pin Insertion任务上，顶级编码智能体（Codex, Claude Code, Kimi Code）通过ENPIRE自动提升策略成功率。增加机器人-智能体工作者数量能减少达到相同性能所需的墙上时钟时间，体现了可扩展性。

  1. 机器人集群上的策略学习扩展：

    • Push-T：将智能体-机器人对数从1增加到8，达到归一化1.0分数所需时间从约5小时减少到2小时。
    • Pin Insertion：从1增加到8个智能体，达到接近完美成功率的时间从超过1.5小时缩短到约40分钟。
    • 这表明ENPIRE能够通过分布式假设选择，将额外的机器人资源转化为更快的策略改进。

  2. 仿真实验验证：在RoboCasa365模拟器基准测试中，ENPIRE超越了端到端VLA（GR00T）以及无需自动研究的零样本智能体工具使用（CaP-X）。

  3. 资源利用率量化：研究提出了两个效率指标。

    • **平均机器人利用率 (MRU)**：机器人在研究中处于主动执行实验状态的时间比例。
    • **平均令牌利用率 (MTU)**：整个自动研究过程中，集群平均每分钟消耗的令牌数。
    • 实验发现，随着集群规模扩大（从1到8个智能体），MRU下降（因智能体需花更多时间汇总同伴分支），而GPU活跃利用率上升。令牌消耗与时间成本存在权衡：更大集群能更快达到成功，但需要不成比例更高的令牌预算。

图4：量化智能体资源利用率。随着智能体团队规模从1扩大到8，GPU利用率和令牌消耗增加，但每个机器人的利用率（MRU）下降。令牌与成功率之比反映了资源效率。

总结与启发

核心贡献：

  1. 形式化问题并提出两阶段框架：首次形式化了灵巧操作的“物理自动研究”问题，并提出“先构建自动化环境接口，后进行全自动策略改进”的解决路径。
  2. 实现ENPIRE系统：开发了一个具体的智能体现控框架，使编码智能体能够开发可重用工具、构建奖励与重置机制，并在无需人工干预的情况下在真实机器人上优化学习算法。
  3. 验证有效性与可扩展性：在多个高精度任务上证明ENPIRE可将成功率提升至接近100%，并展示了其策略改进速度可随机器人集群规模扩展而加快。

局限性（论文自身指出）：

  • 资源利用不足：编码智能体在阅读日志、编写代码、调试或等待大语言模型响应时，无法充分利用机器人资源。随着集群扩大，智能体活动组成变化导致MRU下降。
  • 令牌成本超线性增长：集群规模增大时，令牌使用量的增长速度快于理想的线性趋势。达到成功所需的令牌预算增加速度远快于墙上时间的减少速度，这意味着用令牌效率换取更快的策略改进。

对后续研究的启示：
ENPIRE展示了将真实机器人硬件作为“实验媒介”进行自动迭代优化的可行性，为大规模、自动化地推进真实世界机器人技术的“机器人科学家”范式铺平了道路。未来研究需关注如何进一步优化智能体的资源调度与协同效率，降低物理自动研究的token成本，并探索将积累的知识和经验更有效地迁移到新任务中。

💡 一句话总结

本文针对编码智能体在真实物理世界中缺乏自动化策略改进循环的问题，提出了ENPIRE框架。该框架通过四个核心模块——负责环境重置与验证的EN、策略改进的PI、并行策略评估的R以及进化分析的E——构建了自动化物理反馈循环，使得编码智能体能自主管理和优化训练过程及其算法代码，可调用多种学习范式。基于此，前沿编码智能体在PushT、整理针盒等灵巧操作任务上成功将策略成功率提升至99%，并提出了MRU与MTU效率指标，验证了面向真实世界的机器人自主学习具有可行性与可扩展性。
