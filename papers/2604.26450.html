Reactive Motion Generation via Phase-varying Neural Potential Functions

arXiv: 2604.26450 作者: Yasemin Bekiroglu Team 日期: 2026-04-29

📝 详细解读

研究背景与动机

基于示教学习（LfD）的动态系统（DS）方法能够从少量演示中学习稳定、连续的运动策略。一阶动态系统对许多点对点和周期性任务有效，但前提是每个状态都有唯一的定义速度。对于存在轨迹交叉（例如画“8”字）的任务，通常需要扩展方法，如引入二阶动力学或相位变量。然而，二阶模型通过引入速度来消除运动方向歧义，这使得其在交叉点附近对扰动敏感，并且当几乎相同的位置-速度对对应不同的后续运动时，这种消歧义可能失败。相比之下，基于相位的方法依赖于开环的时间或相位变量，这限制了其在受到扰动后的恢复能力。本文提出了相位变化神经势函数（PNPF）框架，其核心思路是：通过一个直接从状态进展估计的闭环相位变量来调节势函数，从而在保持动态系统反应性的同时，实现对具有交叉点轨迹的有效建模。

方法详解

PNPF的整体框架旨在从演示中学习一个标量势函数 φ(x|s)，其中 x 是状态（构型空间或任务空间），s 是闭环相位变量。系统的控制策略遵循该势函数的负梯度：ẋ = -∇ₓφ(x|s)。该方法结合了两个能量函数：1) 名义能量 φ_nominal，编码期望的任务行为，并随任务进展单调递减；2) 安全能量 φ_safety，将系统吸引到从演示数据中估计出的安全集 C 内。相位变量 s 直接由名义能量定义（s = φ_nominal(x)），从而实现了对任务进展的闭环、状态依赖的估计，而非依赖开环时间。

整体pipeline包含三个核心模块：轨迹合成、能量函数建模和相位变化势函数设计。

图2：PNPF的模型架构。(A) 展示了PNPF φ(x|s)的构建过程。(B)和(C)展示了用于轨迹生成和能量函数估计的神经网络架构。

1. 轨迹合成与安全集估计
首先，使用一个基于超网络的解码器网络作为生成模型，从演示轨迹中合成大量新轨迹。这些生成的轨迹用于估计名义轨迹 x(t)（选择与所有演示轨迹动态时间规整距离之和最小的生成轨迹）和安全集 C*。安全集被定义为状态空间中包含演示数据的一个区域，通过估计其有符号距离函数（SDF）来表征：C = {x | SDF(x) ≤ 0}。SDF通过从生成轨迹中采样的内部点集 X_in 和从外部空间采样的外部点集 X_out 进行计算，确保了数据驱动的边界定义。

2. 能量函数建模

  • **安全能量 φ_safety(x)**：基于估计的SDF构建，φ_safety(x) = relu(λ_safety(SDF(x)))。该函数在安全集C内部为零，在外部为正，其梯度引导系统回到安全集。
  • **名义能量 φ_nominal(x)**：基于名义轨迹的剩余弧长定义。对于名义轨迹上的点，其值为从该点到终点的路径长度。对于非轨迹点，通过投影到最近的名义轨迹点来计算。该函数沿名义轨迹单调递减至零。

3. 相位变化势函数设计
基本的势函数 φ(x) = φ_nominal(x) + k_safety * φ_safety(x) 无法处理同一状态在不同时刻被访问的情况（因为每个状态对应单一标量值）。为解决此问题，PNPF引入了相位条件。相位变量 s = φ_nominal(x) 被用作条件变量。名义能量和安全能量都被重新定义为依赖于相位的函数：φ_nominal(x|s) 和 φ_safety(x|s)。具体地，对于给定的相位 s_k，仅使用位于该相位附近窗口（s_k : s_k + s_w）内的数据来估计 SDF(x|s_k) 和 φ_safety(x|s_k)，并使用名义轨迹片段 x*(s_k - s_w : s_k + s_w) 来估计 φ_nominal(x|s_k)。最终的相位变化势函数为：
φ(x|s) = φ_nominal(x|s) + k_safety * Λ_safety(s) * φ_safety(x|s)
其中 Λ_safety(s) 是一个随s减小而增加的权重项，用于在任务后期加强安全收敛。

图3：生成的轨迹（覆盖安全集）和对应的势函数 φ(x)。绿色为训练演示，红色实线为名义轨迹，虚线为其外推。φ_nominal 引导机器人遵循名义行为，而 φ_safety 在机器人离开安全集时将其拉回。

图4：φ_safety(x|s)、φ_nominal(x|s) 以及不同s值下的 φ(x|s) 示例可视化。相位s归一化到[0,1]。该图展示了PNPF模型如何在相似状态下（相同x）通过不同的相位s输出不同的速度（势函数梯度）。

4. 控制与相位更新
给定当前状态x和相位s，控制律和相位更新规则为：
ẋ = -α ∇ₓφ(x|s), s ← φ_nominal(x‘|s)
其中α > 0 是控制增益，x‘是应用控制后的新状态。相位s的更新是闭环的，直接依赖于新的状态，这赋予了系统抗干扰能力。

5. 平滑势函数与神经网络实现
φ_nominal(x|s) 和 φ_safety(x|s) 使用神经场（坐标网络）建模。为确保势函数梯度（即向量场）平滑以实现稳定的实时控制，网络采用了一种特殊设计：一个超网络以位置编码后的相位变量s为输入，生成一个主MLP的权重；该主MLP则以非位置编码的状态变量x为输入。这利用了标准ReLU MLP在直接处理坐标时的光谱偏置特性，有助于产生在状态空间x中平滑的能量场。

与现有方法相比的创新点：

  1. 闭环相位变量：相位s直接从状态通过名义能量估计，而非依赖开环时间，结合了基于相位的方法的表达能力和基于状态的DS的反应性。
  2. 数据驱动的安全集：通过生成模型学习安全区域边界，提供了一个柔性的恢复区域，优于基于线性超平面的粗糙安全约束方法。
  3. 模块化势函数设计：将任务驱动（名义能量）和安全约束（安全能量）分离，便于集成额外项（如避障势场）。

实验与结果

实验设置：方法在2D手写轨迹（LASA数据集）和6D真实机器人操作任务（使用Franka Emika Panda机器人）上进行了评估。对比的基线方法包括：SEDS（一阶DS）、CDS（二阶DS）、LPV-DS、NC-CLF-CBF（结合了势函数和控制屏障函数）以及CNMP（一种条件神经运动基元方法）。

图5：在具有交叉点的复杂2D轨迹（“秃鹰”形状）上的定性对比。PNPF（右）成功生成了正确的交叉运动，而SEDS、CDS和LPV-DS（左、中）在交叉点附近均产生了扭曲或错误的轨迹。

图6：在“8字形”和“S形”周期性任务中施加空间扰动后的恢复轨迹。PNPF（红色）能够平滑地恢复到期望的周期性运动，而CNMP（蓝色）由于依赖开环相位，在扰动后无法重新同步，产生了持续偏移。

关键定量结果：

  1. 轨迹误差：在LASA数据集上，PNPF在具有交叉点的轨迹上达到了最低的平均动态时间规整（DTW）误差（0.012±0.002），显著优于SEDS（0.031±0.008）、CDS（0.023±0.005）和LPV-DS（0.021±0.004）。
  2. 扰动恢复：在“打结”和“擦拭”两个6D机器人任务中，评估了受外力扰动后的任务完成率。PNPF在打结任务中达到100%成功率，在擦拭任务中为93%，综合表现最佳。CDS在交叉点附近对速度扰动敏感，成功率较低（打结83%，擦拭80%）；CNMP因开环相位，在持续扰动下成功率最低（打结67%，擦拭60%）。
  3. 消融实验：
    • 移除安全能量（仅 φ_nominal）：当初始状态或扰动使系统偏离演示区域时，无法恢复，导致任务失败。
    • 移除相位条件（使用 φ(x)）：无法处理状态重复访问的任务（如画“8”字），在交叉点停滞。
    • 使用位置编码处理状态x：导致势函数梯度不平滑，机器人运动出现抖动，控制性能下降。
      这些实验验证了安全能量、相位条件和网络平滑性设计各自的关键作用。

总结与启发

核心贡献：

  1. 提出了相位变化神经势函数（PNPF），一个新型LfD框架，通过闭环相位变量调节势函数，统一了点对点、周期性以及6D运动生成任务，并在存在轨迹交叉和外部扰动的情况下表现出优越的鲁棒性。
  2. 引入了数据驱动的安全能量项，定义了一个从演示中学习到的柔性安全集，确保机器人在受扰动后能可靠地回到可行的运动区域。
  3. 设计了一种神经场架构，通过超网络条件化和非位置编码的状态输入，确保学习到的势函数具有平滑梯度，适合实时反应控制。

局限性：

  1. 理论稳定性分析基于“演示局部一致”的假设，即名义能量和安全能量的梯度不会剧烈冲突。这实质上限制了方法适用于单模态任务，即每个相位下运动方向大致一致的任务。
  2. 方法性能依赖于轨迹生成模型的质量，需要足够的演示数据以覆盖任务变化并准确估计安全集边界。

研究启示：

  1. 闭环相位估计为解决“反应性”与“复杂轨迹建模能力”之间的矛盾提供了新思路，可扩展至其他需要时序依赖的机器人学习问题。
  2. 模块化的能量函数设计具有很强的可扩展性，如文中所示可方便地融入避障势场。未来可探索集成更复杂的约束（如动态障碍物、关节极限）。
  3. 将安全集学习与更复杂的生成模型（如扩散模型）结合，可能能够处理多模态演示或更复杂的安全区域几何形状。

💡 一句话总结

这篇论文解决了机器人从演示中学习（LfD）生成运动时，在轨迹交叉点（如画“8”字）附近对扰动敏感、难以稳定恢复的问题。传统方法依赖时间或速度变量来区分方向，但鲁棒性不足。 作者提出了**相位可变神经势函数（PNPF）**这一关键技术。其核心要点是：**直接从状态进展中估计一个相位变量**（而非依赖开环时间），并用该变量来调节一个神经势函数，从而生成局部向量场以实现反应式控制。 实验表明，PNPF能有效泛化于点对点、周期性和6D运动任务，在处理交叉轨迹时超越了现有基线方法，并在实时机器人操作中对外部扰动表现出鲁棒性能。
