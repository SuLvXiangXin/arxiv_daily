PhyRoGen: Synthetic Generation of Physical Robot Manipulation Puzzles Using Procedural Content Generation

arXiv: 2606.06569 作者: Marc Toussaint Team 日期: 2026-06-04

📝 详细解读

研究背景与动机

机器人学习与任务运动规划算法的发展严重依赖大规模、多样化的数据集。目前，用于机器人操作的主流数据集生成方法（如 ProcTHOR、MotionBenchMaker）主要关注生成交互式物理场景或通用的运动规划问题，它们通常不生成具有连锁物体依赖关系的谜题。所谓连锁依赖，是指一个被关节连接的物体（例如门）必须先被操作，才能移动另一个被其阻挡的物体（例如后面的滑块）。这类“物理操作谜题”对需要物理探索和因果推理的任务与运动规划算法至关重要，但手动创建此类谜题数据集耗时、繁琐且难以保证多样性。

本文针对自动生成具有连锁依赖关系的物理操作谜题这一具体痛点，提出利用程序化内容生成技术来自动化数据集创建。其核心思路是：设计一个通用的、基于运动链的生成框架，通过算法迭代地构建物体间的依赖关系，并确保生成的每个谜题不仅是唯一且可解的，而且最终能被真实机器人操纵。

方法详解

PhyRoGen 框架包含三个核心部分：运动链生成器的定义、通用的制作算法以及六个具体的生成器实例。

图1：系统总览。左侧展示了谜题生成模块（PhyRoGen），通过程序化内容生成创造谜题；右侧展示了谜题基准测试与操作模块，用于验证谜题的可解性和机器人的可操作性。

1. 整体框架与制作算法
PhyRoGen 制作算法是框架的核心，它作为一个迭代过程，输入包括物体集合、关节类型集合、变换集合、所需物体数量 N 以及随机种子 Seed，输出是代表一个物理谜题的运动学链 K。算法流程（对应原文 Algorithm 1）如下：

  • 初始化一个空运动链 K。
  • 进行 N 次迭代，每次迭代向链中添加一个新物体。
  • 在每次迭代中，算法基于当前种子随机选择一个物体 (obj)、关节 (jnt) 和变换 (tf)，尝试扩展当前运动链，形成一个临时链 Kt。
  • 随后进行两次关键验证：首先，锁定新加入物体的关节，检查谜题是否在物体处于默认位置时就可解（使用 RRT-Connect 规划器进行测试）。如果是，则拒绝此方案，因为该物体未形成有效依赖，是多余的。其次，释放该关节，检查移动该物体后谜题是否可解。如果不可解，同样拒绝此方案。
  • 只有通过两次验证的扩展才会被采纳，更新到主运动链 K 中。
  • 最终，算法返回构建好的运动链 K。对于生成的每个谜题，其目标被定义为移动第一个连杆：对于棱柱关节，目标是移动到其极限的另一端；对于旋转关节，目标是旋转90度；对于 SE(2) 关节，目标是在谜题包围盒外的一个随机位置。

2. 六个具体生成器
基于上述通用制作算法，论文通过定义不同的输入元组（物体、关节、变换序列），具体化了六种运动链生成器（见原文 Table I）。这六种生成器旨在产生不同风格的操作谜题：

  • Simple Slider：使用 T 形滑块和棱柱关节，生成简单的滑块谜题。
  • Continuous Space：使用立方体和旋转关节，变换在连续空间采样。
  • Grid World：使用立方体、旋转或棱柱关节，变换限制在90度增量。
  • Lockbox Random：交替使用立方体和圆盘作为物体，以及棱柱和旋转关节，模拟开锁盒类谜题。
  • Move N Times：使用立方体、门（Door(N)，需要操作 N 次）、走廊等物体和 SE(2)、棱柱关节，生成需要多次重新抓握的迷宫类谜题。
  • Rooms：使用房间和门房间物体，生成逃生房间类谜题。

图2：使用 Table I 中配置为前四个种子生成的谜题环境可视化。展示了六个生成器各自的前四个变体，共计24个独特的谜题。

3. 创新点
与现有生成方法（如 ProcTHOR、MotionBenchMaker）相比，PhyRoGen 的创新性具体体现在：

  • 针对性：专门针对并成功生成了具有连锁物体依赖关系的物理操作谜题，这是此前PCG方法未重点关注的。
  • 质量保证：通过算法中的双重验证步骤，确保每个生成的谜题既非平凡（存在依赖），又是可解的，从源头上保证了生成数据的有效性。
  • 灵活性与多样性：通过定义不同的输入元组，一个通用框架可以派生出多种特定类型的谜题生成器，并能通过改变种子无限生成新实例。

实验与结果

1. 实验设置

  • 生成：使用六种生成器，每种生成4个不同种子的谜题，共计24个独特谜题。在 Blender 中结合 Phobos 插件实现并导出为 URDF 格式。
  • 基准测试/求解：在 Robowflex 和 OMPL 框架内，使用四种基于采样的运动规划算法对24个谜题进行求解测试：LA-RRT、RRT、LBT-RRT 和 BIT。每个规划器在每个谜题上重复运行100次，不同谜题类型设置了不同的时间限制（20秒到600秒）。
  • 操作验证：在 PyBullet 仿真中，使用一个具有移动底座和7自由度机械臂的 KUKA LBR iiwa 机器人来执行由基准测试找到的最佳解决方案。执行过程涉及运动规划、逆运动学求解、基于雅可比矩阵的物体路径跟踪以及处理奇点时的重新抓握策略。

2. 关键实验结果

  • 生成性能：24个谜题的生成时间在4秒（Simple Sliders）到83秒（Continuous Space）之间，证明了框架的效率。

  • 可解性基准测试：

    图3：六种生成器（各四个变体）的基准测试结果汇总图。该图展示了不同规划器在不同谜题上的性能对比。

    • 成功率：LA-RRT 在23/24个场景中达到100%成功率，仅在 Lockbox Random 1 上为95%。BIT* 在所有24个场景中达到100%成功率。LBT-RRT 和 RRT* 分别只在7个和6个场景中达到100%成功率。
    • 最优性：在所有24个场景中，专门为最小化操作动作数设计的 LA-RRT consistently 获得了最低的成本（即最少的操作步骤）。

  • 可操作验证：

    图4：所有六种环境（共24个谜题）的操作任务可视化。每个谜题展示四个连续帧，显示机器人（KUKA移动操纵器）将绿色目标物体移动到透明绿色目标位置的过程，期间需要移开阻挡的红色物体。
    所有24个生成的谜题均成功被模拟的移动操纵器机器人操作并解决。完整的规划与执行时间在4秒（Simple Sliders 1）到51秒（Move N Times 4）之间，验证了生成谜题的物理可实现性。

3. 消融实验与组件贡献
论文虽未进行传统意义上的“消融实验”，但算法设计中内含了关键组件的有效性验证：

  • 双重验证机制：算法中的两次验证（默认状态不可解、活动状态可解）直接确保了每个新增物体都贡献了有效的连锁依赖，且最终谜题可解。这是生成高质量谜题的核心保障。
  • 生成器配置多样性：通过展示六种不同输入配置（Table I）能产生风格迥异的谜题（图2），证明了核心框架的通用性和灵活性，是其作为“框架”而非单一生成器的价值体现。

总结与启发

1. 核心贡献

  • 提出了 PhyRoGen 框架：首个利用PCG专门生成具有连锁物体依赖关系的物理机器人操作谜题的通用框架。
  • 实现了 六种具体生成器 并生成了24个独特的可解、可操作谜题数据集，为机器人学习与TAMP研究提供了新的基准测试资源。
  • 完成了从生成、求解到物理操纵的完整流程验证，证实了该方法在仿真中端到端的可行性。

2. 论文自述的局限性

  • 窄通道问题：当前方法难以生成包含物体间狭窄通道的谜题，因为这会挑战采样规划器的效率。
  • 依赖结构简单：目前仅生成顺序（链式）依赖，而现实谜题常包含树状依赖（多个物体独立阻挡一个共同目标）。
  • 离线和静态生成：当前框架用于离线路数据集生成，而非根据机器人学习进度在线动态调整难度的环境。
  • 缺乏系统对比：评估侧重于验证可解性和可操作性，尚未与其他生成框架进行系统比较或对人工标注基准进行消融研究。
  • 仿真局限：所有实验均在仿真中进行，尚未迁移到真实物理机器人进行验证。

3. 对后续研究的启示

  • 为基于学习的任务与运动规划提供了近乎无限的、高质量的合成训练数据来源。
  • 框架的模块化设计（可配置的物体、关节、变换序列）启发了后续研究者设计新的生成器以创造更复杂或特定领域的谜题。
  • 指出的局限性为未来工作指明了方向，例如：开发能处理树状依赖的回溯算法；将生成与在线学习结合以实现课程学习；结合优化与采样规划器以处理窄通道；以及最终进行真实世界的验证。

💡 一句话总结

本文针对机器人操作物理拼图任务中，大规模、多样化训练数据集生成耗时且繁琐的核心问题，提出了PhyRoGen框架。该框架利用程序化内容生成（PCG）技术，通过通用生成器算法，自动合成了具有连锁物体依赖关系（即物体操作存在先后顺序）的物理拼图。基于该框架生成了24个具体的物理拼图，实验表明，所有拼图均可通过基于采样的规划算法在1至300秒内求解，并在物理仿真中验证了其可由真实机器人成功操作，证明了生成拼图的可行性与有效性。
