RopeDreamer: A Kinematic Recurrent State Space Model for Dynamics of Flexible Deformable Linear Objects

arXiv: 2604.28161 作者: Paula Dornhofer Paro Costa Team 日期: 2026-04-30

📝 详细解读

研究背景与动机

柔性线性物体（如绳索、电缆）的机器人操作是一个基本挑战，因其具有高维、非线性动力学特性，且在接触丰富的任务中难以保持拓扑完整性。当前数据驱动方法主要利用循环神经网络和图神经网络进行动力学建模，但常面临自交叉和非物理形变（如缠绕、链节拉伸）的问题。这些方法在长程时间依赖上存在过平滑和过挤压的缺陷，且基于段的编码器缺乏内在物理约束。

本文针对现有方法在长时程预测中物理一致性差、易产生非物理形变的核心痛点，提出了一种结合了结构化运动学先验与世界模型的新视角。其核心思路是：通过四元数运动学链表示将DLO状态约束在物理有效的流形上以保持链长恒定，并利用循环状态空间模型在潜在空间中解耦确定性与随机性动态，从而实现鲁棒、长期的DLO状态预测。

方法详解

整体框架是一个基于循环状态空间模型的潜在动力学学习框架。输入为当前DLO状态 $s_t$ 和机器人操作动作 $u_t$，以及历史状态。模型首先将状态编码为潜在表示，通过RSSM单元更新确定性状态 $h_t$ 并计算先验 $z_t$ 与后验 $z_t$ 分布，最后通过双解码器分别重建当前状态和预测未来状态。

图3：DLO操作的世界模型架构。当前DLO状态和操作动作首先输入各自的编码器生成潜在嵌入。这些表示与先前的确定性和随机性状态一起传递给循环状态空间模型单元，以更新当前确定性记忆 $h_t$ 并计算先验 $z_t$ 和后验 $z_t$ 分布。在双解码器设置中，后验和确定性状态被重建解码器用于重建当前观测以实现空间锚定；同时，先验通过后续RSSM步骤链接以预测未来潜在变量，预测解码器使用这些变量来预测下一个物理绳索状态。虚线表示仅在训练阶段使用的路径和组件。

核心模块包括：

  1. 四元数运动学链表示：作为预处理，将DLO状态 $s_t$（一系列三维坐标点）转换为混合表示。第一个段由其位置 $p^0 \in \mathbb{R}^3$ 表示，后续所有段的构型由单位四元数 $q^i \in \mathbb{H}$ 定义，表示链节 $i-1$ 与链节 $i$ 之间的相对旋转。假设固定链长，任何段的位置 $p^i$ 可通过正向运动学重建。该公式将状态空间约束在有效流形上，从根本上防止模型预测非物理拉伸。
  2. 基于RSSM的潜在动力学学习：模型将输入通过编码器投影到嵌入，然后通过RSSM将模型动态分解为确定性组件 $h_t$（由门控循环单元维护）和随机性组件 $z_t$。具体组件包括：
    • 动作编码器：$a_t = f_{\phi}(u_t)$，使用可学习的嵌入层处理DLO链节索引，并使用单独的MLP处理链节位移，使模型能学习绳索不同段的特定物理动力学。
    • 循环模型：$h_t = f_{\phi}(h_{t-1}, z_{t-1}, a_{t-1})$
    • 状态编码器：$e_t = f_{\phi}(s_t)$
    • 后验：$z_t \sim q_{\phi}(z_t \mid h_t, e_t)$
    • 先验：$\hat{z}t \sim p{\phi}(\hat{z}_t \mid h_t)$
    • 重建解码器：$\hat{s}t^{\text{recon}} \sim p{\phi}(\hat{s}_t \mid h_t, z_t)$
    • 预测解码器：$\hat{s}{t+1}^{\text{pred}} \sim p{\phi}(\hat{s}{t+1} \mid h{t+1}, \hat{z}_{t+1})$
  3. 双解码器策略：将解码任务拆分为重建解码器和预测解码器。重建解码器类似于传统的自监督自动编码器，将潜在表示锚定在当前状态的几何和位置上；预测解码器则基于先验“梦想”步骤明确预测下一个状态 $s_{t+1}$。分离这两个任务可防止重建损失主导预测动力学，使模型能学习一个针对长时程DLO形变预测优化的转移空间。
  4. 优化与损失函数：采用基于证据下界的复合损失函数：$\mathcal{L}{total} = \mathcal{L}{recon} + \mathcal{L}{pred} + \beta\mathcal{L}{KL}$。其中，$\mathcal{L}{recon}$ 惩罚从后验潜在分布恢复当前状态 $s_t$ 的误差；$\mathcal{L}{pred}$ 通过预测后续状态强制转移动力学与DLO的物理演化一致；$\mathcal{L}_{KL}$ 最小化后验与先验之间的KL散度，确保潜在空间在模型“梦想”未来轨迹时保持稳定和可预测。

与现有方法相比，创新点体现在：1) 将RSSM框架适配于高分段DLO动力学，实现无需真值校正的稳定开环预测；2) 引入四元数状态表示，强制保持链长恒定，在涉及自交叉的复杂操作中提供更优的拓扑一致性；3) 采用双解码器架构，解耦状态重建与未来状态预测，优化潜在空间用于多步预测。

实验与结果

实验在一个大规模模拟数据集上进行，该数据集包含10,000条DLO轨迹，每条轨迹固定为100步，共100万次状态转移。DLO被建模为由70个胶囊体组成的链，使用MuJoCo 3.3.7模拟。对比的基线方法是当前最先进的GA-Net以及IN-BiLSTM。模型评估指标为预测段位置与真实位置之间的均方根误差。

图4：RopeDreamer变体与基线变体在50步开环预测中RMSE发展的比较。越低越好。(a) 与GA-Net对比，(b) 与IN-BiLSTM对比。

关键定量结果：在50步的开环预测任务中，最佳基线（GA-Net S）的RMSE从第1步到第10步增加了15.68mm，到第50步达到64.94mm。相比之下，本文的最佳模型（Large）在第10步仅增加5.44mm，第50步增加19.05mm，实现了40.52%的预测误差降低。同时，本文模型的推理时间减少了31.17%。分析表明，基线方法在短期局部重建上更精确，但长期稳定性差，误差增长迅速；而本文模型虽因信息瓶颈初始误差较高，但误差增长稳定，标准偏差在所有时间步上都保持稳定，表明RSSM框架有效内化了长期动态。

图5：在涉及自交叉的复杂操作序列上的定性预测结果。顶部：真实模拟状态序列。中间：GA-Net的预测。底部：RopeDreamer的预测。红色箭头指示抓取点和位移方向。本文的模型在长期预测中保持了更准确的拓扑结构。

图6：在多次交叉场景下的拓扑保持能力定性比较。从左到右：初始状态，执行两次交叉操作后的状态，以及两个基线模型和RopeDreamer的预测。本文的模型成功保持了交叉的拓扑结构，而基线模型（GA-Net和IN-BiLSTM）的预测则出现了断裂或错误的拓扑。

图7：消融研究结果，比较了完整模型与以下变体：1) 仅使用确定性GRU（无潜在变量），2) 使用单一解码器，3) 使用标准笛卡尔坐标表示（而非四元数）。完整模型在所有预测步长上均表现最佳。

消融实验总结了每个组件的贡献：移除随机潜在变量（仅用确定性GRU）会导致性能下降，尤其是在长期预测中。使用单一解码器（而非双解码器）会损害预测性能，因为重建任务主导了优化。使用标准笛卡尔坐标表示（而非四元数）会导致明显的链节拉伸和非物理变形，验证了运动学表示在保持物理有效性方面的关键作用。

总结与启发

本文的核心贡献在于：1) 将RSSM框架成功适配于高分段DLO的动力学建模，实现了稳定的长时程开环预测；2) 提出了四元数运动学链状态表示，通过设计强制保持了链长恒定，显著提升了在自交叉等复杂操作中的拓扑一致性；3) 设计了双解码器架构，有效解耦了状态重建与未来预测任务，使潜在空间专注于学习动力学演化。

论文自身提到的局限性在于，该方法依赖于准确的DLO状态估计（如通过TrackDLO等算法），在现实世界中可能受到感知噪声的影响。此外，当前工作主要在仿真环境中验证。

本文对后续研究的启示包括：将结构化运动学先验与数据驱动的世界模型相结合，是解决复杂物理系统长期预测问题的一个有前景的方向；双任务学习（重建与预测）策略有助于学习更鲁棒和泛化性更强的表示；模块化设计（将动力学模型与状态估计解耦）使得该方法能够与不断发展的感知方法兼容，具有较好的可扩展性。

💡 一句话总结

本文针对可变形线性物体（DLOs）机器人操作中高维非线性动力学和拓扑完整性保持的挑战，提出RopeDreamer模型。该模型结合循环状态空间模型与四元数运动链表示，将DLO编码为相对旋转序列以保持链接长度恒定，并采用双解码器架构解耦状态重建与预测。实验表明，在50步开环预测中，误差比基线降低40.52%，推理时间减少31.17%，且在多重交叉场景中拓扑一致性更优。
