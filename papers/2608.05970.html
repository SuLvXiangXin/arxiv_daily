SkillMemo: Expert-guided Skill Memory Framework for Compositional Embodied Manipulation

arXiv: 2608.05970 作者: Jiwen Lu Team 日期: 2026-08-06

📝 详细解读

研究背景与动机

目前，机器人具身操作领域的主流方法是扩散策略和视觉语言动作模型。然而，这些模型的潜力从根本上受到大规模具身轨迹数据稀缺的限制，导致在分布外场景中组合泛化能力不足，且难以捕获可重用的技能结构。现有基于记忆增强的方法，如MemoryVLA和HAMLET，缺乏显式记忆行为显著技能级特征的机制，导致历史经验复用效率低下，在面对物体、容器和指令的新组合时泛化能力下降。

本文针对上述数据稀缺与组合泛化不足的痛点，提出了从“技能”这一新视角出发，构建一个动态、可检索的技能记忆库。核心思路是隐式地将长视距演示轨迹分解为潜在的原子技能，并将技能级特征整合到一个动态情景记忆库中，以解决组合性任务。

方法详解

SkillMemo框架的核心目标是将长轨迹隐式分解为技能，并构建一个技能级别的记忆库以促进组合泛化。整体流程分为两个核心模块：专家引导的轨迹分割和技能级记忆架构。

图2：SkillMemo框架总览。专家引导的轨迹分割模块通过混合专家路由隐式地从演示中提取潜在的原子技能。技能级记忆架构结构性地存储并动态修剪这些学习到的门控权重分布，实现对已学习技能的上下文感知检索，从而在未见过的任务上实现鲁棒的组合泛化。

专家引导的轨迹分割：为解决传统VLA模型使用单一网络学习整个行为轨迹导致的泛化能力差的问题，该模块旨在结构性地将整个轨迹分解为一系列潜在的原子技能。不同于依赖显式分割（易丢失技能边界），该方法采用基于混合专家架构的隐式技能划分。具体而言，给定t时刻的中间特征表示(h_t)，MoE层的输出由N个专家网络({E_1, ..., E_N})和一个门控网络(G)计算：(y_t = \sum_{i=1}^{N} g_i(h_t) \cdot E_i(h_t))。直观上，每个专家捕获一个重复出现的局部运动基元，而门控网络(g)通过随时间调制专家的激活度来隐式定义时间分割边界。为鼓励专家间形成互补的技能 specialization 并促进 emergent 技能组合，模型采用基于部分信息分解理论的协同信息损失进行正则化：(\mathcal{L}_{\text{PID}} = -[I({A,B};G) - I(A;G) - I(B;G)])。最小化该损失鼓励专家们的联合表示包含比单个专家表示之和更多的任务相关信息，从而驱动每个专家专注于互补技能，促进学习到 distinct 且 non-overlapping 的技能基元。

技能级记忆架构：为使智能体具备经验推理能力，本模块负责存储、检索和组合先前学习的技能基元。

  • 记忆存储：记忆库(\mathcal{M})组织为键值对集合。记忆键是对每个由分割模块发现的原子技能段(s_k)，通过对其时间特征(h_t)进行平均池化得到的紧凑质心特征：(\mathbf{k}m = \frac{1}{L} \sum{t \in \tau_m} h_t)。记忆值存储了再现技能所需的功能性知识，即该技能段内所有时间步的完整门控权重序列(\mathbf{v}m = {g(h_t)}{t \in \tau_m})。最终记忆库为(\mathcal{M} = { (\mathbf{k}_m, \mathbf{v}m) }{m=1}^{M})。
  • 记忆检索：在推理时，计算当前状态特征(q_t)与所有记忆键(\mathbf{k}m)的余弦相似度，检索出 top-N 个最相关的记忆条目。在通过可靠性检查（平均相似度与阈值(\delta)比较）后，通过加权平均融合 retrieved 的门控权重与模型当前预测的门控权重来 refined 动作预测：(g'(q_t) = \lambda g(q_t) + (1-\lambda) \frac{1}{N} \sum{n=1}^{N} \mathbf{v}_n[t'])。
  • 记忆更新：为适应终身学习场景，设计了基于使用追踪的动态内存更新机制。当记忆库达到容量上限(M_{\text{max}})时，根据（1）最久未被访问、（2）从未被成功使用、（3）检索可靠性低的优先级准则修剪 obsolete 的记忆条目，以平衡 memory diversity 和 quality。

与现有方法相比，创新点在于：1）将MoE-based隐式技能发现与动态情景记忆库相耦合；2）结构化地存储和检索细粒度的技能级行为模式（门控分布），而非非结构化或整体视觉语义表示。

图3：门控系数随时间的可视化。门控系数动态变化，并在关键动作阶段（如抓碗或开炉灶）表现出显著的峰值，这表明EGTS模块成功驱动了各个专家隐式地专注于 distinct 且有语义意义的运动基元。

实验与结果

数据集与实验平台：实验在仿真和真实世界两个环境中进行。仿真基准包括：LIBERO（用于VLA骨干）、Push-T、UR3 Block Push 和 Franka Kitchen（用于DP骨干）。真实世界实验使用UR5e机械臂进行操作。

对比方法：与多种先进的基准方法进行了对比。对于DP骨干，对比了 Diffusion Policy、Sparse Diffusion Policy、Consistency Policy、IMLE Policy 和 STEP。对于VLA骨干，在LIBERO基准上对比了 OpenVLA、TriVLA、CogACT、(\pi_0)、MemoryVLA、UniAct、UniVLA 和 (\pi_{0.5})。

关键实验结果：

  1. 消融实验：如表1所示，在DP和UniAct骨干上，逐步添加专家引导轨迹分割模块和技能级记忆架构均能带来性能提升。在UniAct上，两者结合使Goal、Spatial、Object任务成功率分别从68.7%、72.1%、75.7%提升至73.4%、80.2%、79.8%。

    表1：组件消融研究。逐项添加EGTS和SLMA均能提升DP和UniAct模型在各自任务集上的成功率。

  2. 专家数量影响：如表2所示，专家数量N从1增加到5时，模型性能（成功率）和推理时间均稳步提升；超过5后，性能增益边际递减而推理时间显著增加，因此默认选定N=5。

    表2：专家数量对UniAct成功率和推理时间的影响。N=5在性能和效率间达到较好平衡。

  3. 仿真基准性能：
    • DP骨干：如表3所示，SkillMemo在所有三个模拟基准上均超越基线方法，取得了64.6%的平均成功率，超过DP 3.4%，超过IMLE Policy 1.8%。

      表3：在模拟基准上与最先进的扩散策略基线对比成功率。SkillMemo在所有任务上取得最佳平均性能。

    • VLA骨干：如表5所示，SkillMemo consistently 增强了包括 UniAct、UniVLA 和 (\pi_{0.5}) 在内的各种规模VLA骨干的性能。特别是在强大的 (\pi_{0.5}) 骨架上，SkillMemo将其平均成功率从96.8%提升至98.0%，实现了1.2%的提升，并超越了MemoryVLA（96.5%）。

      表5：在LIBERO基准上的成功率对比。SkillMemo 持续提升各类VLA骨干模型的性能，(\pi_{0.5})-SkillMemo 达到 98.0% 的平均成功率。

总结与启发

核心贡献：1）提出了一个耦合MoE-based隐式技能发现与动态技能记忆库的SkillMemo框架，用于解决具身操作中的组合泛化问题；2）设计了专家引导轨迹分割模块和技能级情景记忆架构，实现了技能的分解、结构化存储、上下文感知检索与融合；3）通过在仿真和真实世界的大量实验，验证了该框架能持续提升不同骨干模型的性能，并在零样本组合泛化上展现出显著优势。

局限性：论文自身提到，记忆库具有有限容量（(M_{\text{max}})），在终身学习场景中需要动态修剪以容纳新经验，这可能造成部分旧知识的遗忘。

后续研究启示：SkillMemo 验证了“技能”作为记忆和泛化单元的有效性。这启发后续研究可探索更高效的技能表示与检索机制、技能的可解释性分析，以及如何将该框架与更广泛的终身学习、元学习和多任务学习范式相结合。同时，如何定义和评估“技能”的边界与质量，也是一个值得深入探讨的方向。

💡 一句话总结

本论文针对具身操作中因轨迹数据稀缺导致模型组合泛化能力不足的核心问题，提出了SkillMemo框架。该框架基于混合专家架构隐式分割轨迹为技能原语，并设计技能级情景记忆库存储紧凑技能表示。推理时通过检索与融合技能先验优化动作预测。实验表明，该框架显著增强了扩散策略和视觉-语言-动作骨干模型的性能，在未见任务配置上实现了最优结果并展现出强大的组合泛化能力。
