ARP: Enhancing Quantized Skill Abstractions via Visual Alignment and Iterative Refinement for Robotic Manipulation

arXiv: 2606.22480 作者: Jin Wang Team 日期: 2026-06-21

📝 详细解读

研究背景与动机

当前面向长周期机器人操作的模仿学习方法中，技能学习是一种主流范式，它旨在将复杂行为分解为可重用的技能单元。现有方法主要分为两类：一类是从观测和语言中学习技能表示（如 VLAs），但这类方法容易使技能编码与特定场景外观过拟合，模糊了可重用的动作基元；另一类是仅从连续动作序列中通过离散化（如 VQ-VAE）提取技能，虽然能得到紧凑的动作基元，但这些技能符号与视觉语义脱离，导致在视觉和语言变化下产生目标歧义，并且离散化过程不可避免地会丢失精细的几何细节，在长周期执行中累积误差。本文针对这两个具体痛点——语义歧义和量化精度损失，提出了一个新的视角：在保持动作量化技能紧凑性和可重用性的基础上，通过视觉对齐增强其语义感知能力，并通过轻量级迭代精炼恢复执行精度。其核心思路是：在第一阶段通过对比学习将视觉嵌入与预量化的动作潜在表示对齐，以改善语义技能选择；在第二阶段通过一个两步迭代残差头对离散解码的动作进行细粒度修正。

图1: ARP 概览。左侧：先前的离散技能策略受限于语义歧义和量化误差。右侧：ARP 通过将视觉嵌入与预量化的动作潜在表示对齐以实现语义感知的符号选择，并应用迭代残差精炼以实现精确执行。

方法详解

ARP 是一个两阶段的离散技能框架，旨在通过视觉-动作对齐和迭代精炼来增强量化技能。

图2: ARP 框架。第一阶段通过重构以及动作潜在表示与视觉嵌入的对比对齐来学习离散动作技能。第二阶段训练一个自回归技能先验，将预测的符号解码为动作，并通过迭代残差头对其进行精炼以实现精确执行。

整体流程：首先，在第一阶段，使用一个因果自编码器将连续动作序列压缩为离散技能符号，并引入视觉-动作对齐目标，在共享潜在空间中建立视觉与动作的联系。随后，在第二阶段，冻结第一阶段编码器，训练一个以状态历史和任务描述为条件的自回归Transformer作为技能先验，用于预测技能符号序列；接着，使用第一阶段的解码器将符号反量化为基础动作，最后通过迭代残差头进行两步精炼，输出最终的高精度连续动作。

核心模块一：动作分词器与视觉-动作对齐。动作分词器沿用因果自编码器设计，编码器使用因果一维卷积和掩码自注意力，解码器接收离散符号重建动作。离散化瓶颈采用有限标量量化，它通过将连续潜在表示投影到低维空间并进行有界取整操作来生成离散符号，避免了传统VQ的码本崩溃问题。视觉-动作对齐是关键创新：为避免在解码器中引入观测依赖导致的过拟合，ARP保持了状态无关的解码器。为了弥补由此带来的语义缺失，它使用一个对称的InfoNCE对比损失，将预量化（FSQ之前）的动作潜在表示与从观测中提取的视觉嵌入在共享空间中对齐。具体地，通过两个投影头将动作潜在表示（带梯度停止）和视觉嵌入映射到共享空间，计算对比损失。该对齐使视觉语义能够引导离散技能符号的选择，同时保留了动作基元的可重用性。第一阶段的总损失为L1重建损失与对齐损失的加权和。

核心模块二：迭代残差头。该模块旨在纠正量化误差。给定从预测符号解码的基础动作 a_base 和真实动作 a_gt，目标残差为 Δa = a_gt - a_base。IRH 是一个条件网络 R_ω(x, ρ, C_t)，其中 x 是残差种子，ρ 是精炼步数。训练时，采用一个受「最小迭代计算结合训练时随机性」启发的两步骤方案：第一步以零向量为种子预测残差，第二步以第一步的预测残差加上一个带噪声扰动的目标残差为种子再次预测。损失为两步预测与目标残差的加权L2损失。推理时，IRH 执行两次前向传播：Δâ_0 = R_ω(0, 0, C_t), Δâ_1 = R_ω(Δâ_0, ρ_fix, C_t)，最终动作为 a_final = a_base + Δâ_1。该设计以极小的开销（仅两步）实现了有效的精度修正。

创新点：1）在经典的两阶段离散技能框架内，通过视觉-动作对比对齐，在不引入观测依赖过拟合的前提下，解决了纯粹动作量化带来的语义歧义问题；2）提出轻量级迭代残差头，以前馈式两步骤精炼替代计算密集的扩散或流匹配模型，以高效方式弥补了离散化带来的精度损失，平衡了性能与推理效率。

实验与结果

实验平台与基准：在仿真实验中使用了Meta-World（50个单任务操作）和LIBERO（5个套件共130个多任务操作）两大基准。真实机器人实验在Kuavo 4 Pro人形机器人平台上进行。

对比基线：包括连续动作方法（如 Diffusion Policy, ACT）、离散/自回归技能方法（如 VQ-BeT、QueST）以及加速生成框架（如 Consistency Policy, FlowPolicy）和视觉-语言-动作模型（如 OpenVLA, SpatialVLA）。

图3: Meta-World 和 LIBERO 的任务示例可视化。

关键实验结果：
在LIBERO多任务评估中（表I），ARP取得了 89.6% 的整体平均成功率，优于所有基线。尤其在需要语言条件目标选择的LIBERO-Object（92.8%，比QueST高+12.1%）和考验长周期组合的LIBERO-Long（83.6%，比QueST高+13.6%）上优势明显。
在Meta-World单任务评估中（表II），ARP取得了 73.8% 的平均成功率，比最强基线MGP高 **+10.1%**。在精度要求高的“难”和“极难”任务上，分别达到 **65.8%**（对比MGP +21.8%）和 **67.9%**（对比MGP +14.1%）。

图4: 精炼策略和残差头设计的对比。该图展示了不同精炼方法在LIBERO-Long和Meta-World(Hard)任务上的性能（成功率）。结果表明，提出的两步迭代残差头（IRH）在性能和效率上取得了最佳平衡，优于单步MLP、扩散或流匹配等方法。

消融实验总结：

  1. 核心组件有效性（表III）：在LIBERO-Long任务上，仅使用视觉-动作对齐将成功率从71.1%提升至74.1%（+3.0%）；仅使用IRH提升至75.5%（+4.4%）；两者结合达到83.6%（+12.5%），显示出强烈的互补性。在Meta-World(Hard)任务上，对齐带来+16.2%的显著提升，IRH带来+10.5%的提升。
  2. 技能抽象设计选择（表IV）：使用FSQ量化优于VQ和LFQ；采用潜在对齐的方法优于直接将观测注入解码器的方案（Obs-Cond.）。
  3. 精炼策略对比（图4，表V）：IRH（两步）的性能优于单步MLP，且在LIBERO-Long上超过扩散和流匹配头。增加IRH迭代步数（3步、5步）带来的收益可忽略（<0.3%），说明两步已足够。

总结与启发

本文的核心贡献在于：1）提出了 ARP框架，一个通过“对齐+轻量级精炼”解决动作中心离散技能语义歧义和量化精度损失的两阶段方案；2）设计了视觉-动作对齐的对比学习目标，在保持状态无关解码器的前提下增强了技能的语义感知能力；3）提出了迭代残差头，一个高效的两步精炼模块，显著提升了离散动作在精确操作中的执行保真度。

局限性：论文在讨论中提到，由于IRH的设计，该策略目前可能更适合于需要精细接触的短序列操作，对于极长序列任务的适用性有待进一步验证。此外，整个框架依赖纯视觉输入进行对齐，可能忽略了其他模态（如触觉）对精密操作的重要性。

对后续研究的启示：首先，证明了在离散技能学习中，解耦的技能表示学习（关注“如何”）与对齐预测（关注“何时/何物”）相结合是一条有效路径。其次，最小迭代精炼在处理量化误差方面展现了替代重型生成模型的潜力，为平衡策略性能与推理延迟提供了新思路。未来的工作可以探索将多模态（如语言、力觉）更深入地整合到对齐过程中，以及将IRH的迭代精炼思想扩展到更长的技能序列预测中。

💡 一句话总结

论文针对机器人长期操作中离散技能量化方法的视觉语义关联弱和动作生成精度不足问题，提出了对齐细化策略ARP。其核心创新在于：1）视觉-动作对齐目标，在共享潜在空间对比对齐视觉与预量化动作表示；2）轻量级迭代残差头，通过两步细化恢复精细控制。实验表明，ARP在LIBERO和Meta-World基准上达到最先进性能，在Kuavo 4 Pro人形机器人真实任务中显著优于多个基线方法。
