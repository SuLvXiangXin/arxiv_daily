Learning Object Manipulation from Scratch via Contrastive Interaction

arXiv: 2606.11525 作者: Biwei Huang Team 日期: 2026-06-10

📝 详细解读

研究背景与动机

物体操作是机器人学习的核心挑战，目前主流方法严重依赖专家演示或精心设计的奖励函数，这带来了昂贵的监督成本与有限的泛化能力。无监督的目标条件强化学习（GCRL）提供了一种有前景的替代方案，而对比强化学习（CRL）作为GCRL的一种实现，已在导航与运动等领域展现出从零开始学习复杂控制的能力。然而，CRL在交互丰富的操作任务中表现仍不尽如人意。本文的核心论点是，物体操作中关键的以物体为中心的交互（如接触或抓取）会引发底层动态模式的显著变化，这导致可达性结构呈现分段非线性，使得标准CRL的能量函数难以准确表征和规划。

本文针对CRL在处理交互引发的动态模式切换时的根本性挑战，提出了新的理论视角：将操作动态建模为一个分段平滑的马尔可夫过程。基于此分析，论文的核心思路是引入交互加权重采样，通过对交互发生前后的关键阶段进行重采样，引导学习到的表征更好地捕捉交互周围的动态复杂性，从而改进策略学习。

方法详解

论文的整体框架遵循标准的对比强化学习（CRL）流程，但在其核心的对比学习步骤中引入了IWR模块来改进正例未来的采样分布。

图2：学习框架总览。(a) IWR从回放缓冲区采样锚点状态-动作对，并通过候选未来目标与交互阈值的接近度重新加权，增加选择与交互相关的正例的机会。(b) 重新采样后的正例和回放边缘负例用于标准的CRL评论家更新。学习到的能量随后用于更新执行者，其新的交互轨迹被添加回回放缓冲区。

核心模块是交互加权重采样。具体而言，对于一个锚点转移x_t = (s_t, a_t)，系统考虑来自同一条轨迹的一组候选未来目标g_k = s_{t+k}。令u_{p,t+k}和y_{p,t+k}分别表示执行体（如机器人末端执行器）和目标体（如物体）在候选未来时刻的位置。定义它们的距离为d_{t+k} = ||u_{p,t+k} - y_{p,t+k}||_2。给定一个先验的交互阈值c（例如夹爪与物体的接触距离），IWR为每个候选未来分配一个软交互权重：
w_k = ε + exp(-||d_{t+k} - c||_2 / (2σ²))
其中ε > 0确保全局覆盖，σ控制交互窗口的宽度。然后，系统根据这些权重w_k对正例未来目标进行重新采样。

与现有方法（如均匀采样或仅基于轨迹上下文的采样）相比，IWR的创新点在于其采样分布被明确地向可能发生交互的区域重塑。这使得CRL的评论家（即能量函数E_φ,ψ(s, a, g) = φ(s, a)^T ψ(g)）在训练时能获得更多关于动态模式切换边界的监督信号，从而学习到能更好表征交互前后可达性变化的能量景观。

实验与结果

论文在三大类交互中心环境中评估IWR：

  1. 2D Box2D操作：五个任务，控制蓝球移动绿球到红色目标区域，度量标准为“成功周期数”。
  2. 机器人操作：四个Meta-World任务（Push, Pick-Place, Sweep-Into, Peg-Insert），度量标准为成功率。
  3. 机器人空气曲棍球：在模拟器和真实机器人上评估，任务是将飞出的球击入指定小圆目标，并测试连续击中多个目标的能力。

对比的基线方法分为两组：

  • 基于奖励的RL：PPO、SAC及其变体（SAC+HER， SAC+HINT）。
  • 对比RL方法：SGCRL和CRTR（可视为IWR的无交互感知的均匀采样消融版本）。

图3：空气曲棍球真实迁移实验。(a) 真实迁移设置下的模拟训练性能曲线。(b) 模拟器训练后的连续目标评估。(c) 真实机器人空气曲棍球设置。

关键实验结果总结如下：

  • 整体性能：如表1所示，IWR在大多数任务上超越了所有基线方法，平均性能提升了**19.8%**。无奖励的CRL方法家族整体优于基于奖励的方法。
  • 任务特性分析：IWR的增益在交互稀疏且对成功至关重要的任务中最大。例如，在Box2D的“hard”变体（物体更小）上，IWR相对CRTR提升了54.8%；在Meta-World的“Pick-Place”任务上提升了86.9%。这表明IWR有效放大了稀疏的交互相关监督信号。
  • 空气曲棍球：在模拟器中，IWR的单目标成功率有2.1%的温和提升。但在加入了噪声和观测不连续性的“真实迁移”设置下，IWR显示出更大的优势（提升4.8%）。最重要的是，在真实机器人上，IWR的成功率（12/20）远超其他方法（最佳为CRL的5/20），实现了140% 的相对提升，证明了其卓越的sim-to-real泛化能力。
  • 连续评估：如图3(b)所示，在连续击中多个目标的评估中，IWR也表现出更好的鲁棒性和精度。

消融实验方面，论文将CRTR作为IWR的“无交互加权”版本进行对比，其性能普遍低于IWR，这直接证明了交互加权重采样组件的有效性。

总结与启发

本文的核心贡献可概括为三点：

  1. 理论分析：首次将交互丰富的操作任务形式化为分段平滑的马尔可夫过程，并深入分析了交互引起的动态模式切换为何会给CRL的表征学习带来采样挑战和误差传播问题。
  2. 方法创新：提出了交互加权重采样，一个简单而有效的原则，通过重塑对比训练的采样分布来聚焦于交互临界区域，从而改善CRL的能量景观学习。
  3. 实证验证：在包括2D控制、机器人操作和空气曲棍球在内的多个交互中心环境中验证了IWR的有效性，显著提升了样本效率和最终性能，并首次实现了在真实机器人上能连续击中多个目标的goal-conditioned空气曲棍球智能体。

论文自身提到的局限性包括：IWR方法需要预先设定一个交互阈值c，这依赖于对任务交互先验的粗略知识，可能影响其在全新场景中的泛化能力。

对后续研究的启示包括：如何以更无监督或自适应（如通过学习）的方式确定交互阈值或识别交互事件；将IWR的思想扩展到更复杂的、涉及多个物体多次交互的操作任务中；以及进一步探索分段动态建模与其他无监督学习范式的结合。

💡 一句话总结

本文针对交互密集的物体操作任务中，对比强化学习因物体交互引发动态模式突变、导致能量函数难以规划和表述的问题，提出“交互加权重采样”方法。该方法通过对交互前、中、后关键阶段进行交互感知重采样，使学习到的表示能更好地捕捉交互周围的复杂动态。实验表明，该方法在多个交互环境中比先前的CRL方法采样效率和整体性能平均提升约19.8%，并在实物机器人空气曲棍球任务上，将成功率从25%提升至60%。
