GeniWorld: A Generalizable Interactive World Model for Robotic Manipulation via Visual Actions

arXiv: 2608.06332 作者: Zhi Wang Team 日期: 2026-08-06

📝 详细解读

研究背景与动机

通用机器人策略展现出了强大的多任务能力，但其在复杂和未见环境中的鲁棒性仍然有限。在多样化的真实世界环境中扩展机器人学习和评估仍然成本高昂且充满挑战。基于动作条件的世界模型提供了一个有前景的替代方案，但它们通常存在动作可控性有限以及对分布外泛化能力不佳的问题。现有方法通常将低维的数值动作向量直接输入生成模型，这种范式存在两个关键局限：首先，数值动作向量缺乏明确的空间基础，限制了复杂机器人运动的精确建模；其次，低维的动作条件化将本体运动与环境变化纠缠在一起，迫使模型过度关注与交互无关的细节，导致对未见场景的泛化能力差。

本文针对上述痛点，提出了将机器人运动以视觉形式显式地条件化世界模型的新视角。其核心思路是：通过机器人URDF模型和正向运动学将数值控制动作序列渲染成密集的视觉动作序列，以此作为条件来训练世界模型，从而将本体运动与环境动态解耦，提升模型对交互的建模能力和对未见场景的泛化能力。

方法详解

GeniWorld 的整体流程旨在将输入的数值动作转换为对未来视觉观察的预测，并支持闭环交互。

图1：GeniWorld 方法概述。我们将机器人动作通过 URDF 渲染转换为视觉运动。这些运动随后被编码为潜在表示，并与含噪声的视频潜在表示拼接。组合后的表示作为输入传递给因果 DiT，通过流匹配预测未来视频。在推理过程中，初始场景图像作为第一帧提供。动作经由基于URDF的渲染器生成运动条件，模型在利用 KV 缓存保持历史上下文的同时预测未来观察。

整体框架的输入是当前观察o_t和未来数值动作序列a_{t+1:t+H}。这些数值动作通过目标机器人的URDF模型和正向运动学系统，从目标摄像机视角渲染出对应的本体运动序列m_{t+1:t+H}，这个过程隔离了机器人的关节结构，不包含物体和背景的外观信息。因此，世界模型的核心目标变为o_{t+1:t+H} = W(o_t， m_{t+1:t+H})。

模型的核心模块与技术细节包括：

  1. 视觉动作生成与空间对齐的动作条件化：基于视频扩散模型主干，视觉动作序列m_{t+1:t+H}通过一个因果3D VAE编码器处理成动作潜在表示z_a，其维度与视频潜在表示z_v相同。然后，z_a与z_v在通道维度上进行拼接，形成一个空间对齐的联合表示z = [z_v； z_a]。这使得机器人运动动态与预训练的视觉潜在空间对齐，确保了动作和场景潜在表示中每个位置的严格空间对应关系。
  2. 因果建模与闭环交互：模型采用自回归方式进行未来观测预测。训练时，模型起初基于真实帧作为条件，随后将模型生成的预测帧作为历史观察上下文，以缓解未来预测中的暴露偏差。模型采用了因果注意力掩码，限制每个令牌只能关注其前面的令牌，确保每个预测的观察严格依赖于历史状态和过去的动作令牌。在推理时，模型利用KV缓存来维护历史令牌的上下文，同时在新生成的令牌块内应用完整的自注意力，从而实现高效、闭环的交互。
  3. 训练目标：采用流匹配训练方法。对于下一个观察潜在z_{t+1}，其目标是预测一个速度场v_θ，使其逼近真实速度场\dot{z}_{t+1}。损失函数为预测速度场与真实速度场之间的 L2 范数期望。在训练中，只有观察潜在变量被添加噪声并进行预测，而视觉动作则作为干净的条件信号使用。

与现有方法的创新点在于：通过对视觉动作而非数值动作进行条件化，显式地将机器人运动（本体运动）与场景动态（环境变化）解耦。这使得模型能够更直接地学习由机器人-环境交互驱动的场景变化，从而更好地利用预训练视频生成模型的时空动态先验知识。

实验与结果

本文在RoboTwin2.0基准上进行了综合评估，设置了Clean-to-Clean（域内评估）和Clean-to-Random（分布外零样本评估）两种场景。每个任务使用45条轨迹训练，5条评估，共50个任务，总计2250条训练轨迹和250条测试轨迹。“Random”子集在场景外观、物体实例、物体摆放和任务相关空间布局上存在巨大变化。

对比的基线方法包括Ctrl-World、IRASim和EnerVerse-AC。评估指标包括 LPIPS、PSNR、SSIM、FID、FVD 和 EWMScore。此外，论文还进行了消融实验，对比了四种动作条件化设计：数值动作、投影末端执行器轨迹、投影骨架动作以及本文提出的密集视觉动作，并对比了本文的拼接嵌入方式与ControlNet风格的调节方式。

图2：Clean-to-Random场景下的定性世界建模结果。所有模型均在干净的桌面数据上训练，并在未见场景中评估。GeniWorld保留了指令中的机器人运动，并生成了与真实情况密切匹配的交互结果，而基线方法在OOD场景中无法生成预期结果。消融结果也表明，我们的密集视觉动作能够实现更精确的交互建模。

关键实验结果总结如下：

  1. 世界建模质量与OOD泛化：如表 I 所示，GeniWorld（视觉动作）在两种场景下的所有评估指标上均取得最佳性能。尤其在 Clean-to-Random 设置下，其 FID (13.08) 和 FVD (20.15) 显著优于基线方法如 IRASim (FID 174.52， FVD 191.26)，显示了极强的 OOD 泛化能力。消融实验表明，使用视觉动作的模型性能远优于使用数值动作、末端执行器轨迹或骨架动作的变体。
  2. 训练与推理效率：

    图3：不同动作表示下的训练收敛曲线。在相同的训练配置下，我们比较了各种动作表示的生成质量（1 - LPIPS，纵轴）随训练步数（横轴）的变化。视觉动作实现了更快的收敛和始终更优的性能。

    图4：不同流匹配采样步数下的性能。我们使用50、10和5推理步评估世界建模质量，步数越少推理越快。视觉动作条件化在较少的去噪步数下始终保持着比其它动作表示更优的生成质量。

  3. 作为策略评估器的可靠性：在真实世界平台上进行四个操作任务测试。通过对比策略在GeniWorld中的模拟成功率和真实世界中的成功率（由人类或VLM评估），发现两者之间存在强正相关性（图6(a)）。即使在存在环境视觉干扰的OOD场景中，GeniWorld的评估结果也比Ctrl-World等基线方法更加稳健可靠。
  4. 数据合成以提升策略性能：实验证明，仅使用每个任务25条真实演示数据训练的基线策略，在添加GeniWorld合成的数据后，性能得到显著提升。

    图8：不同设置下的真实世界策略成功率。Real 表示仅在真实数据上训练的策略；Real + Spatial-Gen 添加了聚焦于空间泛化的 GeniWorld 合成数据；Real + Spatial-Gen + Diverse-Gen 添加了空间随机化数据和多样化场景变化数据。组合策略取得了最强的整体性能。
    具体而言，添加了65条空间随机化轨迹和65条多样化环境条件轨迹的策略，在空间重排（成功率从37.5%提升至70.0%）、视觉干扰物（从38.8%提升至72.5%）、新物体实例（从42.5%提升至70.0%）和光照变化（从35.0%提升至52.5%）等多个OOD测试条件下取得了最佳的泛化性能，整体成功率从40.8%提升至69.0%。

总结与启发

本文的核心贡献在于：

  1. 提出了GeniWorld，一种通过视觉动作条件化的交互式世界模型，它从固定场景的演示中学习，并能鲁棒地泛化到多样的未见场景，在丰富的合成想象空间中支持机器人操作。
  2. 采用了一种自回归生成模型，该模型以视觉动作为条件，将本体运动与场景动态解耦，实现了显式的交互建模，并支持与机器人策略和人类遥操作员的闭环交互。
  3. 证明了GeniWorld可以作为一种可靠的策略评估器，并能从有限的真实世界演示中合成丰富、多样化的操作数据，从而提升多种机器人系统的下游策略性能。

论文自身并未明确阐述局限性，但从其方法来看，其对机器人的URDF模型和准确的摄像机视角有依赖，且合成的数据质量依赖于预训练的视频生成骨干网络的能力。

对于后续研究，本文的启发在于：首先，将动作表示为视觉形式以解耦运动与环境动态，是一个提升世界模型泛化能力的有力且直观的思路；其次，基于世界模型的闭环交互与高效数据合成，为解决机器人学习中的数据稀缺和场景多样性问题提供了一条可行的路径。未来工作可以探索如何利用更少的、甚至不同类型的数据（如多视角、多机器人）来训练此类模型，以及如何自动化地优化数据合成的目标（例如，针对特定弱点生成对抗性场景）。

💡 一句话总结

本文提出GeniWorld模型，旨在解决机器人世界模型在未知场景中泛化性差以及数值动作可控性有限的核心问题。关键技术方法包括：基于URDF渲染的“视觉动作表示”技术，将机器人运动数值转换为带空间信息的视觉流；通过“显式解耦”运动学与环境动态来缓解场景过拟合；并结合高频率运动控制构建“自回归视频预测”模型，实现闭环交互。实验表明，模型在有限固定场景数据上训练后，能在高度随机的未见环境中实现零样本泛化，并能可靠地评估策略或在复杂环境中生成多样化轨迹以提升策略性能。
