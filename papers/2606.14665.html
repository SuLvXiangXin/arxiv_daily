EgoGuide: Egocentric Guidance for Efficient Robot-Free Demonstration Collection and Learning

arXiv: 2606.14665 作者: Yong-Lu Li Team 日期: 2026-06-12

📝 详细解读

研究背景与动机

机器人学习依赖大量真实世界演示数据，数据规模是主要瓶颈。通用操纵接口（UMI）提供了一种低成本、便携的免机器人数据收集方案，但当前的UMI式流程存在两个关键局限：第一，演示者缺乏对数据多样性的实时反馈，导致收集的演示数据大量冗余，而适应机器人不同运动学的策略需要广泛的数据覆盖；第二，多数UMI系统依赖单一手腕相机观察，视野狭窄，在发生遮挡、物体消失或长视野任务中无法捕获完整任务状态。本文针对这两个具体痛点，即缺乏数据覆盖指导导致冗余 以及单手腕相机视觉观察有限，引入了在线视觉-几何数据质量指导和自我中心视角感知的新视角。本文核心思路是通过增强现实（AR）界面为演示者提供在线数据覆盖评分以提升演示多样性，并设计一个门控残差策略，利用自我中心视角的全局上下文来校准和补充局部的腕部视图控制。

方法详解

EgoGuide作为一个闭环系统，包含硬件设计、在线数据管理以及策略学习算法。

整体框架分为数据收集与在线指导、策略学习两大部分。在收集阶段，演示者手持EgoGuide-UMI设备，佩戴Meta Quest头显。同步采集的观察数据 o = { I^W, I^H, T^W, T^H, g } 通过无线网络流式传输至工作站。工作站计算实时数据覆盖分数，通过AR界面反馈给演示者，指导其调整手部姿态、物体布局等，随后才开始记录轨迹。收集完成后，系统进行静态数据过滤。在策略学习阶段，使用收集的多视角数据训练Gated Egocentric Residual Policy (GERP)。

图2：EgoGuide硬件系统概览。EgoGuide-UMI同步记录手腕视图、头戴/自我中心视图、夹持器本体感觉和空间位姿，而在线数据管理模块计算覆盖分数并通过AR将指导信息反馈给演示者。

核心模块1：EgoGuide-UMI硬件与在线数据管理

  • 硬件设计：基于开源的exUMI手持夹持器接口，增加一个工业鱼眼相机作为手腕视图相机 I^W。使用Meta Quest头显提供头戴/自我中心相机图像 I^H 和头部位姿 T^H。夹持器上的Quest控制器提供手腕位姿 T^W。所有模态通过UDP同步无线流传输，跨模态同步误差小于20毫秒。
  • 在线数据覆盖指导：在开始记录每条演示轨迹前，系统实时计算当前状态相对于已有数据集的“覆盖分数”。该分数基于三个互补信号：手腕图像 I^W（反映策略输入的视觉多样性）、手腕位姿 T^W（反映几何和动作空间的多样性）、头部图像 I^H（从全局视角捕捉物体排列和场景上下文）。对于图像模态，使用DINOv2和CLIP编码器分别提取特征，并计算当前特征与对应特征记忆中k个最近邻特征的平均余弦相似度；对于手腕位姿，计算其与位姿记忆的归一化平移-旋转距离。所有相似度分数被转换为相对于当前记忆的新颖性百分位数（0-100）。系统以2Hz的频率在AR界面中向演示者展示三个百分位数：腕部视图新颖性、自我中心上下文新颖性、手腕位姿新颖性。
  • 部分演示与静态过滤：除了指导初始状态，系统允许演示者从任务中间状态开始记录，以改善任务后期状态的覆盖。记录完成后，系统执行静态过滤，剔除模态缺失、过短、运动不连续或图像模糊的轨迹，约丢弃2%-5%的数据。

核心模块2：门控自我中心残差策略 (GERP)
为解决从移动的人类视角直接学习策略的脆弱性问题，GERP将自我中心感知视为一个门控的替代动作提示，而非替代手腕视图控制。其主要创新在于“残差”与“门控”的设计，以及对固定自我中心相机部署的适应性。

图3：GERP概览。一个仅手腕的基础策略从 I^W 预测标称动作。一个独立的自我中心残差分支接收头部图像 I^H 和相对于头部坐标系的手腕位姿，预测一个残差动作。一个学习的门控值将此候选动作与基础动作融合。

  • 第一阶段：仅手腕的基础策略：首先训练一个标准的腕部视图扩散策略 π_b，它以手腕图像 I^W、手腕位姿 T^W 和任务指令 ℓ 为输入，预测一个在手腕相对动作空间中的标称动作块 A^b。该策略作为稳定的局部操作先验被训练。
  • 第二阶段：独立的自我中心残差策略：冻结基础策略，新增一个独立的残差分支 π_r。该分支的输入是头部图像 I^H 和转换到头部坐标系下的手腕位姿 T^(H←W) = (T^H)^{-1} T^W。π_r 输出一个完整的候选动作 A^r（与 A^b 处于相同的动作空间）以及一个标量门控值 α。
  • 门控融合与训练目标：最终预测动作由门控混合得到：Â = (1-α) A^b + α A^r。残差分支 A^r 与基础分支 A^b 一样，均以真实演示动作块 A* 为监督目标，而非学习差值 A* - A^b。训练损失函数为 ℒ_GERP = λ_res ℒ_FM(π_r; A*) + λ_act || (1-α) A^b + α A^r - A* ||_2^2，采用课程学习策略，先训练残差分支，再逐步引入融合动作损失，以稳定优化。

与现有方法相比，创新点体现在：1) 在收集阶段引入了实时、多模态的数据覆盖量化与AR反馈，将数据质量控制从后处理提前到收集过程中；2) 在策略学习阶段提出了GERP，其“残差+门控”设计不同于直接模仿头部运动的主动感知方法，也区别于将双视图简单拼接输入网络的直接融合方法，旨在鲁棒地利用辅助的、非主动控制的自我中心上下文。

实验与结果

实验在真实机器人（Flexiv Rizon 4）上进行了评估，使用了五个长视野操作任务进行验证：Pick Cube、Pepper Sorting、Garlic Storage和Rubik‘s Cube。对比的基线方法包括：1) 传统无指导的UMI数据收集；2) 仅使用手腕视图的策略 (Wrist Only)；3) 将手腕和头部视图直接输入策略的双流基线 (Wrist+Ego Direct)。评估指标包括成功率(SR)和任务进度得分(TPS)。

图4：无指导收集与EgoGuide指导收集的数据规模-性能对比。对于相同的演示数据量，EgoGuide指导收集的数据训练出的策略（π0.5）在成功率和进度得分上均显著优于无指导收集，这证明了其提升数据效率的有效性。

图5：将一个固定大小的常规数据集与额外增加的不同数量的EgoGuide数据混合训练策略。性能随着EgoGuide数据比例的加入而持续提升，表明EgoGuide数据提供了更高质量、互补的信息。

  • 在线数据管理效果：数据显示EgoGuide显著减少了达到特定性能所需的数据量。例如在Pepper Sorting任务中，要达到50%的成功率，无指导收集需要400条演示，而EgoGuide仅需200条，数据效率提升了一倍。t-SNE可视化（图6）和特征协方差迹的定量分析表明，EgoGuide收集的数据在特征空间覆盖更广，多样性更高。
  • 部分演示效果：如图7所示，启用部分演示选项后，收集的轨迹在空间分布上覆盖更广，避免了轨迹后期状态趋于相似的坍缩问题。

图6：对手腕视图图像的CLIP特征进行t-SNE可视化对比。EgoGuide（右）收集的数据特征分布比无指导收集（左）覆盖的区域更大，表明其视觉多样性更高。

图7：启用（右）和未启用（左）部分演示功能的轨迹分布对比。从任务中间状态开始记录显著增加了轨迹的覆盖范围，提升了数据在状态空间的多样性。

  • GERP策略效果：如表2所示，GERP在多个任务上表现优于仅使用手腕的策略和直接融合双视图的策略。尤其是在Rubik‘s Cube任务中，GERP取得了80%的成功率，显著高于Wrist Only (30%) 和 Wrist+Ego Direct (70%)，证明其门控机制能更有效地利用自我中心上下文，同时避免移动视角带来的干扰。

总结与启发

本文的核心贡献主要有两点：

  1. 提出了EgoGuide系统：一个集成了同步多视角感知和在线视觉-几何数据质量指导的免机器人演示收集框架，通过在收集时提供实时AR反馈，有效提升了演示数据的多样性和质量，从而提高了机器人模仿学习的数据效率。
  2. **提出了门控自我中心残差策略 (GERP)**：一种新颖的策略学习架构，它将自我中心视图作为对稳定手腕视图策略的、门控的残差动作提示。这种方法能够鲁棒地利用全局场景上下文来修正局部模糊的观察，且适用于固定视角的自我中心相机部署，提升了策略在遮挡等挑战性场景下的鲁棒性。

论文在结论部分指出了其工作的局限性在于主要改进了数据收集的起始阶段，暗示了未来可能需要对整个轨迹过程进行更细粒度的指导。这项工作对后续研究的启示在于：证明了在数据收集过程中进行实时、量化的质量干预是提升数据效率的有效途径；同时，对于如何处理机器人感知中常见的不完整、异构的观察模态，GERP的“基础策略+门控残差”设计提供了一种有前景的融合范式，可扩展到其他多模态感知融合问题中。

💡 一句话总结

本文针对机器人学习数据效率低下的核心问题，提出EgoGuide系统。通过同步采集手腕与头部视角，并结合在线视觉几何数据质量指导（AR反馈），解决了UMI数据冗余和缺乏全局上下文的瓶颈。同时，引入门控自我中心残差策略，利用头部视角修正局部观察，保持手腕控制稳定性。真实实验表明，该系统显著减少了所需演示集数量，提升了数据效率；残差策略进一步增强了视觉遮挡下的鲁棒性。
