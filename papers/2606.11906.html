When Does Language Matter? Multilingual Instructions Reveal Step-wise Language Sensitivity in Vision-Language-Action Models

arXiv: 2606.11906 作者: Wanxiang Che Team 日期: 2026-06-10

📝 详细解读

研究背景与动机

当前，视觉-语言-动作模型通过大规模预训练和任务特定微调，在语言条件机器人操作任务上展现出强大性能。然而，这些模型通常假设指令为英语，对于语言模态的分布变化（如多语言指令）的鲁棒性仍未被充分理解。在多语言文本或视觉-语言模型中，通过多语言预训练、提示工程或推理时表征对齐可以缓解性能下降，但这些方法难以直接迁移到VLA模型中。因为VLA模型的核心是生成连续的、闭环的低级控制动作序列，语言理解错误会在时序上累积并不可逆地影响长期执行，全局的、静态的表征对齐策略可能引入噪音，并通过后续步骤传播误差。

本文针对VLA模型在多语言指令下性能严重下降（成功率下降30-50%）这一具体痛点，提出了一个新视角：VLA模型的语言鲁棒性本质上是一个步长级控制问题，语言的影响在时间维度上是高度非均匀的。本文的核心思路是：通过梯度分析识别执行过程中对语言敏感的“关键步骤”，并在推理时仅对这些步骤进行有选择的表征对齐，从而高效提升多语言鲁棒性。

方法详解

本文方法基于一个核心观察：在多语言指令下，VLA模型的执行偏差并非均匀分布，而是集中在少数几个语言关键步骤。方法整体流程分为三个阶段：离线识别语言关键步骤、在线检索与门控、在线选择性对齐。

图1：VLA模型中的步长级语言敏感性示意图。多语言指令导致的执行失败集中在一部分语言关键步骤上。通过对执行过程进行步长级分析以识别这些步骤，并在推理时进行选择性干预，可显著提升语言变化下的鲁棒性。

图2：步长级流程总览。阶段1（离线）通过步长级敏感性分析识别语言关键步骤。阶段2（在线）检索最近的英语参考表征，并判断当前步骤是否为语言关键。阶段3（在线）通过检索Top-K个英语邻居并更新当前动作表征来执行步长级对齐，从而在不重新训练的情况下改善多语言执行。

核心模块一：步长级语言敏感性分析
该模块旨在量化每个执行步骤对语言输入的依赖程度。其核心是计算“文本-图像梯度比”。对于每个步骤t，分别计算预测动作相对于语言token和视觉token的平均梯度范数 (g_t^{lang}) 和 (g_t^{vis})。语言敏感性分数定义为两者的比值 (r_t = g_t^{lang} / (g_t^{vis} + \epsilon))。(r_t) 越大，表明该步骤的动作预测更依赖于语言输入而非视觉观察。分析发现，具有较大 (r_t) 的步骤与多语言指令下表征偏离英语较大的步骤高度重合，因此可将 (r_t) 作为识别语言关键步骤的依据。

核心模块二：基于检索的推理时步长级对齐
本模块包含三个步骤：

  1. 参考集构建：从英语训练轨迹的子集中，提取每个样本在每个步骤的中间层隐藏表征 ( \tilde{h}_t^{(i)} )，并关联其预计算的语言敏感性分数，构成参考集 ( \mathcal{R} )。
  2. 步长级检索与门控：在推理时，给定步骤t的当前表征 ( h_t )，从 ( \mathcal{R} ) 中检索Top-K个余弦相似度最高的邻居 ( \mathcal{N}_t )。通过一个门控机制决定是否进行对齐：计算 ( \mathcal{N}_t ) 中属于预先定义的语言关键步骤集合 ( \mathcal{C} )（根据敏感性分数排名前p%）的邻居比例。若该比例超过阈值τ，则触发干预 ( ( \mathbb{I}_t = 1 ) )，否则跳过。
  3. 相似度加权对齐：当 ( \mathbb{I}_t = 1 ) 时，对检索到的邻居表征进行加权聚合得到参考表征 ( \bar{h}_t )，权重由 ( h_t ) 与各邻居的余弦相似度经softmax计算而得。最终，对齐后的表征通过一个插值公式获得：( h_t^{aligned} = h_t + \alpha \mathbb{I}_t (\bar{h}_t - h_t) )，其中α控制对齐强度。更新后的表征被送入模型后续层以生成最终动作。

创新点
与现有方法（如全局平均对齐或英语思维链提示）相比，本文的创新点具体体现在：

  1. 时序感知：首次提出并验证了VLA模型中语言影响具有高度非均匀的时序结构，将鲁棒性问题重新定义为步长级控制问题。
  2. 选择性干预：不是对所有步骤进行统一的、可能有害的校正，而是基于梯度分析智能地选择只在语言关键步骤进行干预，避免了在语言无关步骤引入噪声。
  3. 无需训练：整个对齐过程在推理时完成，无需额外的多语言数据或模型微调。

实验与结果

实验设置：研究在LIBERO机器人操作基准上进行，该基准包含Spatial、Object、Goal、Long四个任务套件。将原始英语指令翻译成9种其他语言（中文、法语、日语、韩语、西班牙语、葡萄牙语、阿拉伯语、泰语、越南语）。评估了两个VLA模型：OpenVLA-OFT和π0.5。对比了三种基线方法：无干预、英语思维链提示、以及全局平均对齐。

关键实验结果：

  1. 多语言性能严重下降：如表1所示，在两个VLA模型上，使用非英语指令导致平均成功率相对英语下降37.7%-46.3%（OpenVLA-OFT）和35.7%-41.5%（π0.5），在Goal任务上甚至下降超过80%。
  2. 语言影响非均匀性的证据：

    图3：跨任务和模型的步长级英语表征偏差热图。颜色越深表示与英语表征的余弦距离越大。结果显示，偏差集中在特定的“热点”步骤，且同一任务内不同语言的热点模式相似，证实了语言影响的非均匀性和任务依赖性。

    图4：文本-图像梯度比与英语表征偏差（MSE）的关系散点图。在所有任务中，具有较大表征偏差的步骤也倾向于具有较高的梯度比，证明了梯度比可作为语言关键步骤的有效指标。

  3. 步长级对齐的有效性：如表2所示，步长级对齐方法显著优于所有基线。在OpenVLA-OFT上，平均成功率从51.7-65.3%提升至62.6-70.9%；在π0.5上，提升更为显著，从55.4-61.2%提升至79.8-82.1%。

    图5：隐藏表征在固定英语参考方向上的投影分布。干预后，非英语表征（彩色点）明显向英语参考（灰色点）靠拢，表明步长级对齐有效减少了跨语言表征偏差。

  4. 消融实验与组件贡献：
    • 步骤选择的重要性：如表3所示，仅在识别出的语言关键步骤进行干预，其效果优于在随机步骤干预，也优于或等于在所有步骤干预，表明关键步骤的选择是有效的，且全步骤干预可能在某些情况下引入不必要扰动。
    • 数据高效训练：如表4所示，在微调阶段，仅对语言关键步骤（50%的步骤）进行参数更新，其性能大幅优于随机选择50%步骤的策略，并能恢复全步骤微调的大部分性能增益，证明了该方法在提升训练数据效率方面的潜力。
    • 与全局对齐对比：表2显示，全局平均对齐方法效果不稳定，有时甚至导致性能下降，凸显了在VLA任务中进行步长级特异性校正的必要性。

总结与启发

核心贡献：

  1. 首次对VLA模型进行了系统的多语言评估，揭示了其在非英语指令下面临的严重性能退化问题。
  2. 通过细致的步长级分析，发现了语言对VLA模型执行过程的影响具有高度非均匀的时序结构，挑战了将语言鲁棒性视为全局对齐问题的传统观点。
  3. 提出了一种新颖的、基于梯度指导的推理时步长级对齐方法，该方法能显著提升多语言鲁棒性，并可应用于数据高效的训练策略。

局限性：论文提到其方法依赖于使用英语指令计算的梯度来识别语言敏感步骤，这虽然被证明能泛化到其他语言，但理论上可能存在语言特定的敏感模式未被捕获。此外，参考集的构建和门控阈值的设定可能对性能有影响。

对后续研究的启示：

  1. 时序分析至关重要：对于任何生成时序动作序列的具身AI模型，评估和分析其跨模态依赖（如语言-视觉）时应考虑时间维度。
  2. 对齐的代价：在闭环控制场景中，盲目地进行表征对齐（即使是多模态对齐）可能是有害的，需要设计更精细的、考虑动作后果的干预策略。
  3. 超越英语中心：未来的VLA模型设计需要从根本上考虑多语言鲁棒性，可能需要在架构或训练目标上融入对语言变化的固有不变性。

💡 一句话总结

本文研究了视觉-语言-动作模型在多语言指令下的鲁棒性问题。通过将LIBERO基准翻译为十种语言进行评估，发现模型在非英语指令下成功率骤降30-50%。分析揭示，语言影响在任务执行步骤间分布不均，少数关键步骤主导失败。基于此，作者提出一种按步骤语言敏感性进行表示对齐的推理时干预方法。该方法能显著提升模型在语言变化下的性能，表明VLA的语言鲁棒性本质上是一个逐步控制问题。
