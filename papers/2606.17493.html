When Robots Sleep: Offline Skill Consolidation for Shared-Policy Robot Learning

arXiv: 2606.17493 作者: Amit Ranjan Trivedi Team 日期: 2026-06-16

📝 详细解读

研究背景与动机

当前机器人连续学习方法主要聚焦于减轻灾难性遗忘，以保护先前学到的单个任务性能。主流方法包括：基于正则化和梯度投影的方法（如EWC， GEM）以约束参数更新；基于回放的方法（如DER， CLEAR）以重放存储的经验；以及基于蒸馏的方法（如LwF）以保留先前模型的输出。然而，这些方法通常在在线学习新技能时起作用，并且主要评估指标是每个任务的独立留存率（per-task retention）。它们面临一个关键局限：即使单个技能的留存率尚可，但技能之间在一个共享策略参数化下的协调与联合可靠性可能严重恶化。此外，模块化方法（如使用任务特定头、路由或适配器）虽可减少干扰，但在推理时需要一个选择机制，而非维持一个单一的、统一的策略控制器。

本文针对机器人连续技能学习中的一个具体痛点：在学习新技能时，旧技能的环境、奖励、演示或轨迹可能不再可用，但部署的机器人又必须保持一个能复用和协调所有已学技能的单一共享策略。论文识别了“技能耦合崩溃”这一故障模式，即共享策略的兼容性在连续学习过程中退化，即使孤立技能的成功率不为零，但相关技能组合的联合可靠性会下降。本文提出了一个新视角：将在线技能获取与离线策略巩固分离，模仿“唤醒-睡眠”周期。

本文的核心思路是：在“唤醒”阶段在线学习当前技能；在“睡眠”阶段，利用存储的、紧凑的冻结技能记忆（无需重放完整轨迹），通过纳什讨价还价协调多技能梯度，离线整合单一共享策略，以维持技能库的联合可靠性。

方法详解

Sleeping Robots框架是一个清晰的“唤醒-睡眠”循环流程，旨在序列化学习多个技能的同时，通过离线阶段巩固一个单一的共享策略。

图1: Sleeping Robots概述。 (a) 唤醒：仅使用当前技能数据训练共享策略。 (b) 记忆存储：将唤醒结束时的技能存储为紧凑的冻结记忆（RL用评论家记忆，模仿学习用行动者记忆）。 (c) 睡眠：离线整合共享策略，基于冻结记忆形成每个技能的目标，归一化梯度，并通过纳什讨价还价（配合可选的锚定和稳态兴奋性）组合它们，在无需环境交互或轨迹回放的情况下得到θ_k^sleep。 (d) 评估与循环：评估巩固后的策略在所有已学技能上的表现，并为下一个技能重复唤醒-睡眠循环。

整体框架：框架处理一个有序技能序列 T_1:K。它维护一个共享策略 π_θ。对于每个新技能k：

  1. 唤醒阶段：策略仅使用当前技能k的数据（RL交互或模仿演示）进行在线训练，得到参数θ_k^wake。不访问旧技能轨迹。
  2. 记忆冻结：唤醒结束后，为技能k创建一个冻结记忆M_k。
  3. 睡眠阶段（当k≥2时）：策略θ（初始化为θ_k^wake）进行离线更新，不使用任何环境交互。更新基于所有已存储的记忆S_k = {M_i}_{i=1}^k。
  4. 评估与迭代：用θ_k^sleep作为巩固后的策略检查点，进行评估，然后进入下一个技能的唤醒阶段。

核心模块与技术细节：

  1. 紧凑冻结技能记忆：这是离线巩固的基础。为避免存储完整轨迹，论文设计了两种记忆：

    • 对于RL策略（如SAC）：记忆M_k^Q = (Q_φ_k, B_k, ν_k)，包含一个冻结的技能特定评论家Q_φ_k、一个无序的状态缓冲区B_k（仅含状态，不含动作、奖励或转移）、以及评论家归一化器的快照ν_k。
    • 对于模仿学习策略（如ACT）：记忆M_k^π = (π_θ_k^wake, B_k)，包含冻结的唤醒结束时的策略快照π_θ_k^wake，以及一个无序的观测缓冲区B_k（如机器人状态和图像）。

  2. 睡眠目标与梯度：每个冻结记忆为当前共享策略π_θ定义一个可微的替代目标。

    • RL记忆：目标L_i^Q(θ) = - E_s∼B_i [ Q_φ_i( ν_i(s), π_θ(s) ) ]，即最大化当前策略在旧状态上根据冻结评论家评估的价值。
    • 模仿记忆：目标L_i^π(θ) = E_o∼B_i [ || π_θ(o) - π_θ_i^wake(o) ||_2^2 ]，即通过蒸馏使当前策略的输出接近冻结的行动者快照。
      计算每个技能的目标梯度 g_i = ∇_θ L_i(θ)。

  3. 基于纳什讨价还价的睡眠整合：为了协调多个记忆的梯度，避免单一记忆主导更新，论文采用了经过修改的纳什协商。

    • 首先，对每个梯度进行归一化：ĝ_i = g_i / (||g_i||_2 + ε)。
    • 然后，通过求解一个优化问题来计算凸权重α*：α* = arg max_α ∈ Δ^(k-1) Σ_i=1^k log( ⟨ ĝ_i, Σ_j=1^k α_j ĝ_j ⟩ + ε_Nash )。
    • 最终的睡眠更新方向为g* = Σ_i=1^k α*_i ĝ_i。这个公式寻求一个对所有记忆梯度方向都保持“一致”的更新方向，具有尺度不变性，适配了旧任务损失不可得的序列化场景。

  4. 自适应睡眠锚定：为防止整合更新过于激进，引入一个保守的锚定项。在睡眠开始时，检查当前策略参数θ与之前各唤醒检查点θ_i^wake的距离c_i。如果min_i<k c_i小于阈值τ，则激活锚定。此时，睡眠总目标加上一个L2正则项：L_sleep(θ) = Σ_i=1^k α*_i L_i(θ) + (λ_k/2) || θ - θ_(k-1)^sleep ||_2^2，其中λ_k为锚定系数。锚定项将策略拉向上一个巩固检查点，增加稳定性。

  5. 前馈RL行动者的局部兴奋性：针对前馈网络RL行动者，论文引入了一个局部兴奋性变量e_i到每个隐藏神经元，使得激活y_i = e_i σ( w_i^T x )。e_i不通过反向传播更新，而是根据本地激活统计进行自适应调整：ā_i ← (1-β)ā_i + β y_i, e_i ← clip_(e_min, e_max)( e_i + η_e (α_target - ā_i) )。这个过程在唤醒和睡眠阶段使用不同的学习率η_e进行，旨在稳定神经元的活动水平。

与现有方法的创新点：

  • 目标不同：直接针对“技能耦合崩溃”，强调共享策略下技能对的联合可靠性，而非仅单个技能留存。
  • 机制创新：提出“离线巩固”阶段，与在线学习分离。利用紧凑的冻结记忆（而非完整轨迹回放）生成梯度信号。
  • 算法适配：将需要所有任务损失同时可得的纳什MTL梯度协调方法，适配到序列化学习场景，通过冻结记忆提供的替代梯度来实现。
  • 统一策略：始终坚持单一共享策略推理，无需任务特定头、路由或适配器。

实验与结果

实验设置：

  • 基准：在两个五技能序列上评估：
    1. Meta-World MT5：模拟Sawyer机械臂操作任务（reach, door-open, drawer-open, window-close, button-press）。使用SAC策略和评论家记忆。
    2. SurgicAI：达芬奇兼容的缝合模拟器任务（approach, place, insert, regrasp, pullout）。使用视觉条件ACT策略和行动者记忆。
  • 评价指标：
    • 平均最终成功率：衡量孤立技能留存。
    • 配对可靠性分数：在预注册的相关技能对上计算min(S_i, S_j)的平均值，衡量共享策略下技能对的联合可靠性。
    • 后向迁移：衡量后续学习对旧技能的影响（负值表示遗忘）。
    • 协同保留指数：衡量完整流学习后，参考技能轨迹子空间的保留情况。
  • 对比基线：涵盖了稳定性约束方法、回放方法、蒸馏方法、多技能协调方法等。

关键实验结果：
在Meta-World MT5上，Sleeping Robots显著优于所有非Oracle基线。如表I所示，其最终AFSR达到0.578 ± 0.016，比最强的基线（Reset & Distill， 0.353 ± 0.018）提升了约64%。其PRS达到0.245 ± 0.020，约为最强基线（0.123 ± 0.013）的2.0倍。同时，SPI也最高（0.767 ± 0.017）。

图2和表三：MT5的消融实验结果表明，移除任何一个核心组件（纯唤醒、平均梯度、无锚定、无兴奋性、关闭唤醒/睡眠兴奋性）都会导致性能下降，证实了各模块的有效性。例如，纯“唤醒-仅”模式PRS为0，表明没有离线巩固，配对可靠性完全丧失。完整的Sleeping Robots在AFSR和SPI上表现最佳，在PRS和BWT上位列第二，取得了最佳的综合平衡。

图2：Meta-World MT5和SurgicAI上的连续学习动态。图表展示了AFSR、PRS、BWT和SPI指标随技能学习进程的变化。Sleeping Robots（红色实线）在MT5的大多数指标上显著且持续地领先于其他基线方法，在SurgicAI的AFSR和BWT上也取得最佳表现。阴影区域表示标准误差。

在SurgicAI上，如表II所示，Sleeping Robots在连续学习方法中取得了最高的AFSR（0.410 ± 0.010）和最好的BWT（-0.338 ± 0.024）。与自身纯唤醒版本相比，离线睡眠将AFSR提高了一倍以上，并将BWT从-0.700显著改善到-0.338，证明了离线整合的有效性。

总结与启发

核心贡献：

  1. 提出了“技能耦合崩溃”这一共享策略连续学习中的关键故障模式，并引入了配对可靠性分数对其进行度量。
  2. 提出了Sleeping Robots框架，其核心是无需重放轨迹的紧凑冻结技能记忆，以及基于纳什讨价还价的离线梯度整合，实现了跨RL和模仿学习基底的单一策略巩固。
  3. 在模拟操作和视觉条件手术模仿两个基准上验证了该框架的有效性，显著提升了平均技能成功率和技能间的联合可靠性。

局限性：论文自身提及，该方法假设了“睡眠”阶段的存在，这是一个离线的、非实时的巩固过程。在需要持续在线适应且无法容忍离线停顿的场景中可能不适用。

对后续研究的启示：

  1. 评估范式的扩展：强调未来连续学习研究不仅要关注平均精度或成功率，还应评估技能间的协同与联合可靠性。
  2. 离线巩固的潜力：展示了将在线学习和离线巩固分离的有效性，为机器人长期部署中的策略维护提供了新思路。
  3. 方法通用性：框架设计兼容不同的策略表示（如SAC， ACT）和记忆类型（评论家、行动者），鼓励后续研究将其应用于更广泛的机器人学习基底和任务领域。
  4. 结合在线方法：未来工作可探索将离线巩固机制与在线连续学习方法相结合，以应对更严苛的实时学习约束。

💡 一句话总结

本文针对机器人连续学习新技能时共享策略中技能协同可靠性恶化（即“技能耦合崩溃”）的问题，提出“Sleeping Robots”唤醒-睡眠框架。关键技术包括：在唤醒阶段学习新技能，在睡眠阶段利用冻结的技能记忆（如冻结批评器和行动者快照）离线整合共享策略，并通过纳什讨价还价结合梯度以实现稳定优化。实验表明，该方法在Meta-World MT5上平均成功率提升64%，配对可靠性提高2.0倍；在SurgicAI上也改善了平均成功率和向后转移。
