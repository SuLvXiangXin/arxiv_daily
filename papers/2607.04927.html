DSWAM: A Dual-System World Action Foundation Model for Fine-Grained Robot Manipulation

arXiv: 2607.04927 作者: Yi Xu Team 日期: 2026-07-06

📝 详细解读

研究背景与动机

当前机器人操作领域并存两种主流方法：基于视觉-语言-动作（VLA）的策略和世界动作模型（WAM）。VLA策略依赖于预训练的视觉-语言主干网络，能够将语言指令直接映射为机器人动作，具备天然的语义理解和任务规划接口。然而，其常见的单帧、观测到动作的映射范式，在建模机器人干预下的场景动态演变方面，提供的时序上下文有限。WAM则通过视频预测、视频-动作协同训练等方式，学习行动如何影响视觉状态，为物理动态提供了密集的时序监督，因此在抓取、放置、可变形物体操作等需要精确物理交互的任务中表现出色。但现有的WAM主要被设计为执行策略，通常缺乏像VLA那样的显式语言层面接口，用于将粗略的用户指令分解为一系列可执行的细粒度子任务。

针对WAM在语义任务分解方面的不足，以及现有VLA与WAM对比研究常因数据、机器人平台、任务协议不一致而难以公平评估其核心性能差异的问题，本文提出了DSWAM（双系统世界动作基础模型）。其核心思路是将语义任务分解与世界感知的物理执行解耦：保留一个系统作为默认的WAM执行器，仅在指令需要分解时，激活另一个可选的高层视觉-语言子任务规划器。

方法详解

整体框架是一个双系统融合的管道。System 1（系统1）是默认的控制路径，即WAM执行器；System 2（系统2）是可选的高层视觉-语言子任务规划器。在部署时，对于原子指令或WAM执行器已能可靠解决的任务，系统直接运行在“仅WAM”模式，系统2不被激活，执行器以原始提示作为语言条件。当粗略指令需要分解时，系统2被激活，它基于短期视觉历史（最近5帧，每秒1帧采样）和全局任务提示，预测下一个可执行的子任务指令，并将其作为更新后的语言条件传递给系统1执行。执行器在每个时间步接收多模态观测（包括多视角RGB图像、语言条件/子任务指令、本体感知状态），并预测一个未来H步的连续动作块。

核心模块包括两个：一是可选的System 2规划器，二是作为核心的System 1 WAM执行器。

  • System 2 规划器：基于Rynnbrain4B风格的视觉-语言模型构建。其核心作用是进行过渡感知的子任务预测。训练数据通过对机器人轨迹视频进行子任务分割和标注获得。规划器不仅学习识别当前子任务，更关键的是，在非终止子任务的最后一个采样窗口，它会学习预测下一个子任务指令，而在终止子任务的末窗口则输出“done”。这使得规划器能够在子任务边界临近时发出下一个指令。其损失函数为标准自回归语言建模损失。

图1：DSWAM整体框架。大规模真实世界数据用于训练。System 2是一个可选的视觉-语言规划器，将粗略指令分解为可执行的子任务。System 1是默认的WAM执行器，使用预训练的视频模型和动作专家，从观测、语言条件和本体感知中预测动作块。视频协同训练提供训练时的世界建模监督，而推理时避免显式的未来视频生成，并使用TensorRT加速以实现高效部署。

-## System 1 WAM执行器**：其设计旨在保留视频世界建模表征优势的同时，避免推理时显式生成未来视频带来的开销。执行器通过一个视觉主干网络将当前多模态上下文编码为潜在世界特征，并基于此直接预测动作块。创新点在于其训练范式：它采用动作预测损失和视频协同训练损失的组合进行训练。视频协同训练损失作用于未来的潜在视觉令牌，为模型提供了关于物理动态的密集监督信号。然而，在推理时，模型仅进行一次前向传播，直接输出动作块，完全不生成或解码未来帧。动作预测采用条件流匹配（Conditional Flow Matching）方法，适合于生成平滑的双臂连续控制轨迹。整体训练损失为 ℒ = ℒ_act + λ_vid * ℒ_vid。

与现有方法相比，本文的创新点具体体现在：

  1. 可选的规划机制：不同于为所有指令强制进行任务分解，DSWAM的System 2是可选的，这使得系统在原子任务上避免了不必要的规划开销，保持了WAM的高效执行优势。
  2. 高效的WAM推理路径：遵循Fast-WAM等工作的思路，将世界建模的监督作用限制在训练阶段，推理时执行器直接输出动作，提升了实时性。
  3. 为真实机器人部署的系统级优化：集成了实时分块（RTC）、异步执行和TensorRT加速。RTC使策略查询（预测新动作块）与机器人控制（执行当前动作块）异步进行，TensorRT则将计算密集的Transformer路径编译优化，显著降低了策略延迟，使得这种基础模型级的策略能够用于低延迟的实时控制。

实验与结果

实验使用了以下基准和平台：

  • 仿真基准：RoboTwin 2.0，包含50项双手操作任务，评估了“清洁”（固定初始配置）和“随机化”（变化物体位姿和场景布局）两种设置。
  • 真实世界基准：采用与DeMaVLA匹配的家庭衣物折叠协议，使用ALOHA风格的双臂平台，评估折叠衬衫、裙子、裤子和毛巾四项任务，并分为“简单”和“困难”两种衣物实例。
  • System 2有效性验证：使用真实世界桌面分拣任务，指令为“整理桌上的物体”，并分解为两个子任务。

对比的基线方法包括代表VLA的π₀, π₀.₅, DeMaVLA，以及代表WAM的Motus和Fast-WAM。

关键实验结果：

  • RoboTwin 2.0仿真：在清洁设置下，DSWAM平均成功率（SR）达92.38%，在随机化设置下达91.90%，均优于所有基线。相较于最强VLA基线DeMaVLA，清洁和随机化设置的SR分别提升了3.96%和5.12%。
  • 真实世界折叠（WAM-only模式）：在此公平对比设置下（禁用System 2），DSWAM将平均折叠成功率从DeMaVLA的92.5%提升至96.3%，同时平均完成时间从2′18″缩短至1′44″。这证明了在同等条件下，WAM风格的执行器在物理密集型任务上可以超越强VLA策略。
  • System 2有效性：在需要分解的桌面分拣任务中，使用System 2提供子任务监督训练的WAM执行器，相比仅用原始粗略指令训练的WAM执行器，成功率更高，每次运行的平均执行错误数更少，表明子任务级监督提升了任务执行的稳定性。

消融实验体现在整体设计的各个环节贡献上：WAM执行器得益于视频协同训练带来的世界建模监督；高效的推理路径（无未来视频生成）和系统级优化（RTC、TensorRT）共同实现了真实机器人上的低延迟部署；而可选的System 2则为复杂多步指令提供了必要的分解能力，且不影响简单任务的执行效率。

总结与启发

本文的核心贡献可概括为三点：

  1. 提出了DSWAM双系统框架：创新性地将语义任务分解与世界感知的物理执行解耦，System 1作为默认的强执行器，System 2作为按需激活的规划器，兼顾了VLA的规划能力和WAM的物理执行优势。
  2. 在公平设定下实现了WAM与VLA的受控比较：通过在DeMaVLA设定的相同机器人平台、训练数据、任务协议和评估标准下构建并评估DSWAM（禁用System 2），首次在真实机器人上清晰展示了WAM执行范式相对于VLA策略的潜在性能优势。
  3. 展示了卓越的实证性能与部署可行性：DSWAM在仿真和真实世界任务中均取得了领先的成功率，并通过TensorRT加速、RTC等系统工程，证明了大规模基础模型策略在真实机器人上高效、低延迟部署的可行性。

论文自身提到的局限性主要隐含在部署优化部分，即为了达到实时性，进行了大量的工程优化（如TensorRT编译、异步执行），这虽然必要但也增加了系统复杂性。

本文对后续研究的启示在于：首先，任务规划与物理执行的可选式解耦设计，为构建兼具高层语义理解和底层操作鲁棒性的通用机器人系统提供了新思路。其次，将世界建模的监督作用与推理时的计算开销分离，是提升WAM类模型实用性的关键方向。最后，在对比不同机器人学习范式时，严格控制实验条件（数据、平台、协议）对于得出可靠结论至关重要。

💡 一句话总结

这篇论文提出DSWAM模型，旨在解决当前世界动作模型在执行复杂家庭任务时缺乏语言指令分解能力，以及与视觉语言动作策略之间缺乏公平性能对比的问题。模型采用双系统架构：System 1 作为WAM核心执行器，负责世界感知的动作生成；System 2 作为可选视觉语言规划器，用于在需要时进行子任务分解。为实现高效真机部署，模型集成了TensorRT加速、异步执行和实时分块技术。实验在DeMaVLA真机变形操作场景下进行严格公平对比，DSWAM在仅启用执行器模式下，将折叠任务平均成功率从92.5%提升至96.3%，完成任务时间从2分18秒减少为1分44秒，同时证明子任务规划能进一步提升复杂任务的执行稳定性。
