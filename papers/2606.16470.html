Decoupled Object-Centric Video Understanding for Generating Robotic Manipulation Commands

arXiv: 2606.16470 作者: Nak Young Chong Team 日期: 2026-06-15

📝 详细解读

研究背景与动机

目前，将视频演示翻译为可执行的机器人命令仍具挑战性。现有的通用视频描述方法侧重于全局场景理解，缺乏机器人执行所需的物体级精度。针对此任务的视频到命令方法，如V2CNet引入了辅助动作分类分支以改进动作预测，Watch-and-Act则利用视觉变化图通过帧差定位交互区域，但这些方法在识别任务相关物体方面仍存在根本性困难。系统必须区分直接参与操作的物体与无关物体及偶然变化，否则生成的命令在杂乱场景或遮挡下容易指向错误物体。时态建模对于动作理解至关重要，但传统方法如3D CNN和双流网络计算成本高。同时，尽管视觉语言模型（VLM）能提供强大的语义理解和零样本泛化能力，但当其直接应用于完整视频帧时，仍需在复杂场景中识别相关物体，导致物体指代不一致。本文的核心观点是，动作识别依赖于时态特征聚合，而物体识别则需要局部的、实例级的视觉分析，两者应区别处理。因此，本文提出了一种解耦的物体中心视频理解框架，将动作识别与物体识别分离，结合高效的时态移位模块（TSM）动作理解与基于轨迹引导的物体选择，最终生成结构化的、无歧义的动作-物体命令。

方法详解

整体框架（参见图1）由两个并行分支组成：动作表示分支（Action Representation Branch）和物体感知分支（Object-Aware Branch）。给定一个人类操作演示的视频输入，系统最终输出一个指定动作和所涉物体的结构化命令 S = A ⊕ I。区别于完整的自然语句，此命令采用无语法格式（如“put apple into bowl”），以强调机器人执行所需的核心组件。

图1：提出的框架架构。左侧的动作表示分支使用带有时态移位模块（TSM）的ResNet骨干网络，随后进行时间池化和分类。右侧的物体感知分支提取关键帧，检测并跟踪交互物体，通过角色和质量过滤选择任务相关实例，并使用VLM进行类别识别。

动作表示分支负责从下采样后的视频中预测操作原语（如触摸、拾取、移动等）。其核心是在ResNet骨干网络中集成了时态移位模块（TSM）。TSM通过在时态维度上移位特征通道，实现相邻帧间的信息交换，且无需额外参数或计算量。具体操作如公式（3）所示，它将部分通道的特征替换为前/后一帧的对应特征。本文采用“残差移位”策略，将TSM模块插入残差分支而非主路径，以保护骨干网络的空间特征不被覆盖。最终，时态聚合后的视频表示通过一个线性分类器和softmax函数预测动作分布，使用交叉熵损失进行训练。

物体感知分支负责定位和识别任务相关物体。其流程包含四个步骤：

  1. 关键帧提取：并非所有帧对物体识别贡献均等。通过计算灰度转换后的帧间绝对像素变化均值作为运动显著性分数（公式6），再经过阈值过滤和Top-M排名（公式7），选择出包含有意义视觉变化（即交互时刻）的关键帧，以过滤静态或模糊帧。

  2. 物体检测与追踪：关键帧输入一个人-物交互（HOI）检测器，识别与人类手部交互的物体候选。这些物体在帧间被追踪以生成运动轨迹，得到一组具有关联边界框和轨迹的候选物体集合。

  3. 物体选择算法：这是一个关键创新模块，用于从候选集中筛选最相关的物体。它分为两个阶段：

    • 第一阶段：功能角色分类。对于“传递”类动作（如拾取、移动、放置），操作物体通常比静止的容器或表面显示出更大的位移和垂直变化。算法通过计算每个被追踪物体的总位移 D(o) 和垂直坐标方差 V(o)（公式8），并根据阈值 τ_D 和 τ_V 将其分类为“可拾取”集 P1 或“可放置”集 P2（公式9）。对于推、拉、倒、放等其他原语，角色区分可靠性较低，因此该算法主要针对传递型交互设计。
    • 第二阶段：实例质量选择。在每个功能类别（P1 或 P2）内部，采用综合评分选择最佳实例 o*（公式10）。评分结合了清晰度分数 B(o)（基于拉普拉斯响应方差，越高越清晰）和手部重叠度 IoU(o, h)（与检测到的手部边界框的交并比，越低遮挡越少）。最终选择标准是最大化 α * B(o) - β * IoU(o, h)，在视觉清晰度和最小化手部遮挡间取得平衡。本文设置 α = β = 1.0。

  4. 基于VLM的物体识别：经过选择的物体裁剪图像被送入一个视觉语言模型（VLM，本文使用LLaVA），并使用固定提示词“What object is shown in this image? Respond with only the object name.”来预测物体类别标签。由于物体识别与动作分类解耦，并依赖于预训练的视觉-语义表示，该框架能够识别训练集中未出现的物体类别，实现零样本泛化。

实验与结果

实验设置：使用修改版的Something-Something V2数据集，选取了10个对应机器人操作原语的动作类别进行训练和评估。训练集118,562个视频，测试集12,480个视频。另收集了135个自录视频以评估真实世界泛化能力。物体识别评估分为标准物体（12类，训练集中出现）和新物体（9类，零样本测试）两组。基线方法包括Video2Command、V2CNet、Watch-and-Act等任务专用方法，以及ChatGPT-4o-mini、Qwen2.5-VL等多种通用VLM。

动作分类结果：在基准测试集上，TSM模型达到了86.79%的Top-1准确率和94.55%的Top-5准确率。在自录视频上，Top-1准确率降至68.15%，但Top-5仍高达94.81%，表明正确动作类别通常位于前5预测中。

视频到命令生成结果：如表2所示，在标准物体集上，本文方法的BLEU-4得分为0.337，比最强的任务专用基线Watch-and-Act（0.187）高出80.2%。在新物体集（零样本）上，优势更为明显，本文方法的BLEU-4得分（0.261）比Watch-and-Act（0.107）高出143.9%。在ROUGE-L、METEOR和CIDEr等语义指标上，本文方法也普遍领先，尤其在METEOR和CIDEr上对新物体集的提升分别达到157.9%和171.7%。结果显示，尽管使用紧凑的无语法格式且未经任务特定微调，本文方法仍显著优于所有任务专用基线，并在与大型通用VLM的比较中保持竞争力或实现超越。

图2：六个操作动作的定性示例，展示了选定帧和物体轨迹。自上而下，从左至右分别为：(a) 放下鸡蛋, (b) 移动橙子, (c) 拾起勺子, (d) 将瓶子里的水倒入杯子, (e) 推动积木, (f) 将鸡蛋放入平底锅。图中可视化了物体选择和轨迹分析的结果。

消融实验：如表3所示，移除任何核心组件都会导致性能下降。

  1. 移除关键帧提取（改用均匀采样）：在标准物体集上BLEU-4下降11.6%，说明选择交互时刻能提供更清晰的物体视图。
  2. 移除物体选择算法（使用所有检测到的物体）：性能下降最显著，在标准物体集上BLEU-4下降29.7%，证实了基于轨迹的分析和质量过滤对于识别任务相关物体、生成精确命令至关重要。
  3. 用训练好的CNN分类器替换VLM：在标准物体集上BLEU-4下降7.4%，在新物体集上大幅下降45.6%。这凸显了VLM的预训练知识对于零样本泛化的重要性。

总结与启发

核心贡献：

  1. 提出了一个解耦的识别-标识框架，将动作分类与物体识别分离，使得每个组件可以独立设计和评估。
  2. 设计了一个物体中心的选择流水线，包括基于运动轨迹的功能角色分类，以及结合模糊检测和重叠最小化的实例质量筛选。
  3. 集成视觉语言模型进行物体识别，无需重新训练即可泛化到新物体类别，利用了VLM的语义知识和零样本能力。

局限性：论文指出，物体选择算法依赖于物体间清晰的空间分离，且主要针对最多涉及两个功能不同物体的交互场景。当三个或更多物体同时交互，或手部持续遮挡导致轨迹估计不可靠时，其性能会下降。

对后续研究的启示：本文验证了将复杂的视频理解任务分解为专注于不同模态（时态动作 vs. 静态物体）的子任务的有效性。这种模块化设计不仅提升了性能，也增强了系统的可解释性和可扩展性。未来工作可以探索使用学习型轨迹分类器处理多物体交互，并研究框架的实时部署问题。同时，如何将更丰富的情景信息（如物体属性、空间关系）无缝融入当前的动作-物体命令结构，也是一个有前景的方向。

💡 一句话总结

本文针对将视频演示转化为机器人操作命令时，难以准确识别功能相关对象、导致命令模糊的核心问题，提出一种解耦的对象中心视频理解框架。方法关键是将动作识别与对象识别分离：集成Temporal Shift Modules（TSM）进行高效时空动作分类，并设计基于轨迹角色分类、模糊检测和重叠最小化的对象选择算法，再结合Vision-Language Models（VLMs）实现对象类别识别与零样本泛化。在改进的Something-Something V2数据集上，该方法动作分类准确率达86.79%，BLEU-4分数在标准和新颖对象上分别提升至0.337和0.261，比最强基线分别提高80.2%和143.9%。
