WCM: A World Critic Model for Vision-Language-Action Reinforcement Learning

arXiv: 2607.29613 作者: Xipeng Qiu Team 日期: 2026-07-31

📝 详细解读

研究背景与动机

在机器人操作领域，视觉-语言-动作（VLA）模型通过强化学习（RL）进行后训练已显示出强大的潜力。当前主流的基于批评家（critic）的方法，其价值估计器通常仅基于单帧观察或单帧VLM主干潜在特征运作。然而，机器人控制本质上是一个部分可观测马尔可夫决策过程（POMDP），单帧输入无法捕捉动态信息（如运动、接触进程等），导致状态信息不完整。尽管有研究尝试将观察历史纳入批评家模型，但简单的多帧架构（如帧堆叠）在高维视觉空间中面临指数复杂度，并且纯标量回报回归提供的稀疏监督信号不足以有效学习跨时序的动态特性。根本原因在于状态近似问题：没有明确的世界建模目标，批评家的表示无法捕获准确价值估计所需的时序结构。

本文针对上述痛点，提出了一种新视角：批评家模型的表示瓶颈不在于是否使用历史，而在于缺乏一个能明确训练其表示以捕捉环境动态演化的目标。受大型语言模型中“下一词预测”成功启发，本文提出世界批评家模型（World Critic Model， WCM），其核心思路是将未来的潜在状态预测与价值估计在单个架构中统一起来，通过联合优化使批评家表示能够更好地编码环境动态，而不仅仅是回归回报。

方法详解

WCM的整体框架基于轻量级的LeJEPA架构，旨在统一世界预测和价值估计，同时最小化模型复杂度以支持从零开始训练。

图2：WCM方法概述。(a) 架构。观察编码器将过去K帧的图像映射为序列化潜在状态。同时，配备两个解码器头的预测器分别预测下一个状态和估计价值。(b) 同策略（On-policy）流程：WCM根据同策略采样轨迹估计价值，以计算用于PPO/Flow-SDE更新的GAE优势。(c) 异策略（Off-policy）流程：统一的数据库（SFT数据+采样数据）被用来通过AWR/RECAP稳定地更新WCM和策略。

模型主要包含四个组件：观察编码器、世界预测器（历史主干网络）以及两个轻量级预测头。给定从时间步 t-K+1 到 t 的观察历史（K为历史长度），一个通用的观察编码器首先独立处理每个观察，将其转换为潜在嵌入 z_{t-k}。这个编码器可以是视觉Transformer（ViT）或底层VLA策略的VLM主干网络。语言指令 ℓ 由CLIP编码，并通过一个学习的适配器 A_lang映射到WCM的潜在空间，得到语言令牌 u_ℓ。编码后的视觉历史首先与语言令牌进行交叉注意力交互。然后，这个经过语言条件化的序列由一个因果Transformer历史主干网络 Tr_φ（也称为世界预测器）处理，得到隐藏表示 h_t。该隐藏表示被馈送到两个独立的解码器头：

  1. 价值解码头 D_value：用于回报估计，输出预测价值 V^_t。
  2. 世界解码头 D_world：用于在给定当前动作 a_t 和当前潜在状态 z_t 的条件下，通过一个带门控FiLM的残差块预测下一个潜在状态 z^_{t+1}。

训练目标结合了三个部分：

  1. 预测损失 L_pred：使用教师强制（teacher-forcing）计算预测的下一个潜在状态与真实下一个潜在状态之间的L2误差。
  2. Sketched-Isotropic高斯正则化损失 L_SIGReg：应用于潜在表示 z_t，鼓励其匹配各向同性高斯分布，以防止特征空间崩溃或模态退化。
  3. 价值损失 L_value：基于稀疏奖励定义的回报 G_t，计算预测价值 V^_t 与 G_t之间的L2损失。

总损失函数为：L = L_value + λ · L_pred + η · L_SIGReg，其中 λ 和 η 是超参数，控制预测损失和正则化损失的权重。所有组件进行端到端训练。

与现有方法相比，WCM的核心创新在于引入了联合优化的未来状态预测任务作为辅助监督。这使得批评家模型的隐藏表示 h_t 被显式地训练以编码环境动态（通过预测下一个状态），而不是仅仅拟合一个标量回报，从而更好地逼近任务相关的预测状态，缓解了部分可观测性带来的挑战。

实验与结果

实验在四个模拟基准测试（ManiSkill, MetaWorld, CALVIN, LIBERO-Plus）的149个任务以及7个真实世界机器人操作任务上进行。平台涉及模拟器和WidowX-250S真实机器人。策略使用少量演示数据进行有监督微调（SFT）初始化，包括 π_0、π_0.5 和 OpenVLA-OFT 等VLA主干网络。

对比的基线方法包括：

  • 对于 π 风格策略：Flow-Noise, Flow-SDE, π-stepNFT。
  • 对于 OpenVLA-OFT：标准PPO和GRPO。
  • 真实世界实验：对于OpenVLA-OFT使用AWR，对于π_0.5使用RECAP。

关键实验结果总结如下：

  1. 在模拟基准上取得SOTA性能：在ManiSkill的分布内（IND）测试中，WCM相较于SFT基线取得了显著提升（例如，使用OpenVLA-OFT时成功率从28.1%提升至99.0%，+70.9%）。即使在零样本初始化（成功率仅0.78%）的极端情况下，WCM仍能将性能提升至98.7%（+97.9%）。在MetaWorld和CALVIN的复杂和长视野任务上也表现出色。
  2. 强大的分布外（OOD）泛化能力：在ManiSkill的OOD测试（涵盖视觉、语义、执行三个层面的变化）中，WCM在所有VLA主干网络上均超越了基线方法。例如，π_0.5结合WCM在OOD平均成功率达到64.4%，显著高于Flow-SDE的49.3%和Flow-Noise的53.4%。
  3. 在真实世界任务中表现优异：在7个真实世界任务（包括动态抓取、长视野、可变形物体操作等）上，WCM引导的策略在几乎所有任务上都优于基线AWR或RECAP方法。例如，π_0.5+WCM在“传送带寿司抓取”任务上的成功率为33/50，显著高于SFT的4/50和RECAP的27/50。
  4. 消融实验验证核心设计：

    图5：关于批评家架构和观察历史长度的消融研究。结果显示：（1）仅扩展基线MLP批评家的输入历史帧数（MLP-2/3/4/5）性能提升有限或不稳定。（2）使用具有时序建模能力的ViT（即WCM的 λ=0 版本）仍然效果不佳。（3）引入世界预测目标（完整WCM）才能取得最佳性能。历史长度并非越长越好，在实验中长度3表现最佳。

    消融实验表明：a) 世界预测目标至关重要，移除该目标（λ=0）会导致性能下降；b) 仅仅增加历史长度而不改变架构（MLP-K）或仅使用时序建模（ViT）不足以解决部分可观测性问题；c) 历史长度存在一个最优值（在实验中为3帧），更长历史带来的收益有限。

总结与启发

本文的核心贡献在于：1）指出了基于批评家的VLA-RL中存在因部分可观测性导致的表示瓶颈；2）提出了世界批评家模型（WCM），通过联合优化未来状态预测和价值估计，使批评家表示能显式编码环境动态；3）验证了WCM能够无缝集成到同策略和异策略训练流程中，并在广泛的模拟和真实世界任务中一致地提升性能和泛化能力。

论文自身提到的局限性包括：部分实验结果表明，更长的观察历史并非总是带来性能提升，其收益存在一个饱和点，这可能与具体任务的性质和信号稀疏性有关。

对后续研究的启示：WCM的成功验证了将预测性世界建模目标引入价值函数学习是一种有效途径。这为处理高维、部分可观测的机器人RL问题提供了新方向，未来可探索更复杂的世界模型架构、多模态预测目标（如奖励预测），或将此理念应用于其他需要长程时序推理的决策任务中。

💡 一句话总结

本文针对Vision-Language-Action强化学习中critic模型因部分可观察性导致的表示不足问题，提出了World Critic Model (WCM)。WCM基于轻量级LeJEPA架构，通过联合预测未来潜状态和估计价值，使critic能捕捉时间动态而非仅回归标量回报。实验在四个基准的149项任务中显示，WCM在分布内和分布外设置下均达到最先进性能，泛化增益显著，并在七个真实世界操作任务中验证了稳定性。
