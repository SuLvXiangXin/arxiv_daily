End-to-End Dexterous Grasp Learning from Single-View Point Clouds via a Multi-Object Scene Dataset

arXiv: 2603.15410 作者: Fenglei Ni Team 日期: 2026-03-16

📝 详细解读

研究背景与动机

灵巧抓取是机器人操作的基础能力，但当前主流方法存在关键局限。首先，大多数灵巧抓取研究聚焦于单物体场景，忽略了真实多物体场景中物体间的遮挡、接触等复杂关系。其次，现有数据集通常针对平行夹爪，或虽为灵巧手但缺乏对预抓取手势的显式建模，且多基于单物体场景，限制了数据驱动方法在真实复杂环境中的泛化能力。最后，从单视角、不完整的点云中直接预测高自由度灵巧手的完整抓取配置（包括手部位姿和关节角度）仍是一个挑战。

本文针对上述痛点，提出了一种新的视角：构建一个包含多物体场景、显式建模预抓取手势和抓取偏移的灵巧抓取数据集，并在此基础上设计一个端到端的网络，直接从单视角点云预测密集的灵巧抓取配置。其核心思路是：通过一个两阶段的数据生成策略构建大规模、高质量的多物体场景抓取数据集，并利用一个包含抓取参考点预测、偏移补偿和关节配置预测的双模块网络，实现对不完整点云的鲁棒抓取学习。

方法详解

整体框架分为数据生成和网络预测两部分。网络预测部分，DGS-Net 是一个端到端的抓取预测网络，输入为多物体场景的单视角点云 𝒫 ∈ ℝ^(N×3)，输出为每个物体对应的灵巧手抓取配置 G = (T, R, J_init, J_end)，其中 T 为工具中心点（TCP）位置，R 为手部6D旋转，J_init 和 J_end 分别为预抓取和最终抓取的20维关节角度。

图2：DGS-Net 整体流程。网络以点云为输入，PTv3提取多尺度特征。模块I（绿色）预测抓取参考点得分和6D旋转；模块II（黄色）基于模块I的输出和点云特征，预测抓取偏移以及预抓取和最终抓取的关节配置。训练时（底部），模块II使用真实标签以加速收敛；推理时（顶部），模块II使用模块I的预测，形成端到端流程。

DGS-Net 以 Point Transformer V3 (PTv3) 为骨干网络，利用其大感受野和多尺度自注意力机制捕获丰富的全局与局部点云特征。网络包含两个核心模块：

  1. 模块I（抓取位姿预测模块）：PTv3从场景点云中提取多尺度全局特征 f ∈ ℝ^(N×C)。随后通过稀疏卷积层为每个点预测抓取参考点得分 G_s ∈ ℝ^(N×2)（表示该点作为抓取参考点的可能性）和6D旋转表示 R ∈ ℝ^(N×6)。
  2. 模块II（抓取精化模块）：该模块将抓取参考点得分 G_s、抓取位姿 R 和全局点云特征 f 输入一个自注意力编码器，随后通过多个稀疏卷积层预测预抓取关节角度 J_init、最终抓取关节角度 J_end 以及抓取偏移 σ ∈ ℝ^3。最终的手部 TCP 位置 T 通过结合得分最高的抓取参考点 P_Gs（经得分阈值>0.7过滤和空间非极大值抑制后选出）与预测的偏移计算得到：T = P_Gs + σ。该偏移量旨在补偿因点云不完整或传感器噪声导致的TCP与点云中参考点之间的误差。

与现有方法相比，创新点体现在：1) 端到端预测：直接从单视角点云预测完整的高维抓取配置，无需先进行物体分割或点云补全。2) 双模块解耦设计：将全局抓取位置/姿态感知与局部关节/偏移精化分离，缓解了从原始几何直接回归关节角度的困难。3) 显式偏移建模：通过学习抓取偏移，网络能更好地处理点云稀疏性，实现更精确的手-物对齐。4) 预抓取配置预测：显式输出预抓取手势 J_init，为执行器提供了可执行的接近轨迹起点。

为支持网络训练，本文提出了一个两阶段的抓取数据生成流程。

图3：单物体抓取数据生成流程。(a) 使用指尖点约束和导纳控制为单个物体生成密集抓取。(b) 圆形/矩形指尖点约束示意图。(c) 不同约束下生成的抓取示例。(d) 圆形约束中参数 r 和 h 变化时产生的不同抓取关节配置。

第一阶段：单物体密集抓取合成。如图3所示，对于每个物体，在其包围盒内随机采样手部TCP位置和旋转以生成多样化的抓取位姿。通过改变参与抓取的手指数量（五指、两指、三指）和施加在指尖平面上的几何约束（圆形或矩形，参数 r 和 h 随机采样）来定义目标指尖位置。通过逆运动学计算目标关节角度，并使用导纳控制模拟手指闭合过程，记录最终稳定的关节角度作为 J_end。预抓取配置 J_init 通过对 J_end 的关节角度进行经验性缩放得到（如公式9所示），以确保接近过程中不发生碰撞。

图4：场景级抓取数据生成流程。(a) 将单物体抓取集变换到多物体场景中，并进行碰撞检测筛选。(b) 点云上的抓取标签：蓝色为物体点云；紫色为灵巧手TCP；红色为抓取参考点（物体点云中离手TCP最近的点）；绿色为每个抓取参考点邻域内的抓取候选点；灰色为桌面点云。

第二阶段：场景级抓取生成与标注。如图4所示，随机选取5-15个物体放入场景中，让其自由落体形成稳定堆叠。将第一阶段生成的各物体抓取集变换到场景坐标系中，形成候选抓取集。对每个候选抓取进行碰撞检测（包括预抓取接近过程），仅保留无碰撞的抓取作为有效的场景级抓取标注 𝒢_scene。最后，从256个不同视角渲染RGB-D图像并生成对应的点云，与 𝒢_scene 配对构成训练样本。点云语义标签包括抓取参考点、抓取候选点和不可抓取点。

网络训练采用多任务损失函数 ℒ_total（公式6），包含抓取点分类损失 ℒ_gp（使用加权交叉熵以处理类别不平衡）、旋转回归损失 ℒ_R（结合矩阵MSE损失和测地线旋转误差损失）、偏移回归损失 ℒ_T（使用相对L1损失）以及关节角度回归损失 ℒ_J_init 和 ℒ_J_end（均使用MSE损失）。

实验与结果

实验在模拟环境和真实机器人平台上进行。使用本文构建的数据集进行训练和评估，该数据集包含307个物体、240个多物体场景和超过35万个已验证抓取。

对比的基线方法包括：HGC-Net（将抓取姿态限制在5个预定义类别的场景级灵巧抓取网络）、DexGraspNet 2.0（基于扩散模型的场景级灵巧抓取生成方法）、以及本文方法的变体 DGS-Net w/o offset（不预测抓取偏移）和 DGS-Net w/o pre-grasp（不预测预抓取配置，使用固定张开手势）。

图5：模拟环境中的抓取成功率、平均穿透深度和穿透体积对比。DGS-Net 在成功率（88.63%）和低穿透指标（深度0.375mm，体积559.45mm³）上均优于基线方法。

关键实验结果如下：在模拟评估中，DGS-Net 取得了 88.63% 的抓取成功率，显著高于 HGC-Net (71.02%) 和 DexGraspNet 2.0 (79.80%)。同时，DGS-Net 表现出更低的物体穿透，平均穿透深度为 0.375 mm，穿透体积为 559.45 mm³，均优于对比方法。消融实验表明，移除偏移预测分支（DGS-Net w/o offset）导致成功率下降至85.21%，穿透深度增加至0.542mm；移除预抓取配置预测（DGS-Net w/o pre-grasp）使成功率降至82.35%，证明了这两个设计组件的有效性。

图6：真实机器人平台实验设置及抓取示例。

图7：真实场景中对新物体的抓取性能。DGS-Net 在抓取成功率和抓取清除率（成功抓取并移开物体）上均表现最佳。

在真实机器人平台（DexHand Pro灵巧手）上，对未见过的物体进行测试，DGS-Net 取得了 78.98% 的抓取成功率和 87.23% 的抓取清除率（Clearance），优于 HGC-Net (成功率62.50%，清除率68.75%) 和 DexGraspNet 2.0 (成功率75.00%，清除率81.25%)。网络单次推理时间约为 0.45秒，具备实时性。

总结与启发

本文的核心贡献可概括为三点：1) 提出了 DGS-Net，一个能从单视角点云端到端预测密集灵巧抓取配置的网络，通过显式建模抓取偏移和预抓取手势提升了预测精度和物理一致性。2) 设计了一个 两阶段的抓取数据生成流程，构建了一个包含多物体场景、大规模且物理有效的灵巧抓取数据集，填补了该领域的数据空白。3) 在模拟和真实实验中均展现了 卓越的性能与泛化能力，在抓取成功率和减少物体穿透方面优于现有方法。

论文自身提到的局限性主要在于数据集的规模（307个物体，240个场景）相对于一些大规模合成数据集（如DexGraspNet 2.0包含数千场景）较小，这可能在极端复杂场景的泛化上存在限制。

本文对后续研究的启示在于：证明了显式建模抓取偏移和预抓取配置对于从非完整观察中学习精确、可执行抓取的有效性。其两阶段（物体级到场景级）的数据构建范式为高效生成高质量、物理可信的抓取数据提供了可行路径。未来工作可以探索更大规模、更多样化的数据集，或将这种显式建模思想与更强的生成模型（如扩散模型）结合，以进一步解决复杂场景下的灵巧操作问题。

💡 一句话总结

本文针对多物体场景中灵巧抓取泛化能力有限的问题，提出DGS-Net端到端抓取预测网络和两阶段数据生成策略。DGS-Net从单视角点云直接学习密集抓取配置；数据生成策略从单物体抓取合成扩展至场景级，构建包含307个物体、240个场景和超35万验证抓取的数据集。实验表明，DGS-Net在模拟和真实平台上的抓取成功率分别达88.63%和78.98%，平均穿透深度仅0.375 mm、穿透体积559.45 mm³，性能优于现有方法。
