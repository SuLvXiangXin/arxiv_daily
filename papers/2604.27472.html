PRTS: A Primitive Reasoning and Tasking System via Contrastive Representations

arXiv: 2604.27472 作者: Xuelong Li Team 日期: 2026-04-30

📝 详细解读

研究背景与动机

当前，视觉-语言-动作（VLA）模型通过利用强大的视觉-语言模型（VLM）作为感知主干，在机器人控制方面取得了显著进展。主流方法通常采用双系统或混合Transformer（MoT）架构：系统2（VLM）负责高层语义理解和任务推理，系统1（动作专家）执行底层连续控制。然而，现有VLA模型在预训练阶段几乎完全依赖于监督行为克隆，这忽视了一个根本特性：机器人轨迹本质上是一个随时间推进的、达成目标的过程。这要求通用机器人策略的内部表征不仅要编码静态的视觉-语言语义关联，还要封装朝向最终目标的时间进度，即量化评估当前状态-动作对达成语言指定目标的可能性，即目标可达性。虽然VLM擅长编码场景与概念之间的静态语义相似性，但其本质上缺乏对目标可达性的量化估计。

本文针对现有VLA预训练方法缺乏对任务时间进展和目标可达性量化感知的痛点，提出了一个新的视角：通过目标条件强化学习（GCRL）的视角重新构建VLA预训练。具体而言，本文将语言指令视为目标，并采用对比强化学习（CRL），使模型学习一个统一的嵌入空间，其中状态-动作嵌入与目标嵌入的内积近似于对数折扣目标占据概率，从而在静态语义匹配之外，定量评估物理可行性。本文的核心思路是：通过从离线轨迹中直接提取密集的目标可达性监督信号，并将其以极低开销融入VLM主干，赋予高级推理系统内在的目标可达性意识，从而桥接语义推理与时间任务进展。

方法详解

PRTS的整体架构基于Qwen3-VL-4B-Instruct，包含两个训练阶段。在预训练阶段，模型接收统一的令牌序列输入，包括多视角视觉令牌（经Qwen ViT编码）、文本化的本体感知状态令牌、语言指令令牌以及FAST令牌化的自回归动作块令牌。关键创新在于，在序列末尾附加了两个辅助令牌块：<CRL_action>和<CRL_goal>。这两个块末尾的可学习令牌<|action_end|>和<|goal_end|>的隐藏状态，会分别通过轻量级MLP头，产生状态-动作表征 φ(s_t, a_t) 和目标表征 ψ(l)。通过一个角色感知因果掩码（role-aware causal mask）确保信息隔离：<CRL_action>令牌仅关注视觉和本体感知信息；<CRL_goal>令牌仅在其自身块内自注意力；自回归动作令牌保持标准的因果注意力。所有三个输出——离散动作逻辑值、φ(s_t, a_t) 和 ψ(l)——在单次前向传播中产生，并联合优化。在后训练阶段，附加一个全新初始化的、基于DiT的流匹配动作头，通过流匹配损失进行微调以产生连续动作块。

图1：PRTS整体架构概述。模型基于Qwen3-VL，在预训练阶段（上半部分），输入包含视觉、本体、语言和动作令牌，并附加<CRL_action>和<CRL_goal>块。角色感知因果掩码（左下）防止不同角色令牌间的信息泄漏。三个输出（动作预测、状态-动作表征φ、目标表征ψ）通过行为克隆损失和双向对比损失联合训练，使得 φ(s_t, a_t)^T ψ(l) ≈ log Q_l^π(s_t, a_t)。后训练阶段（下半部分）附加并微调一个流匹配动作头用于连续控制。

核心模块是语言条件对比强化学习（Language-Conditioned Contrastive RL）。标准CRL在基于状态的目标设定中，从一个轨迹中采样状态-动作对(s_t, a_t)，然后从未来时间步按几何分布采样一个目标状态s_g。在PRTS中，目标被定义为语言指令l，它在同一轨迹的所有时间步共享。这导致了“多正例”问题，即一个批次中许多状态-动作对共享同一个语言目标。为解决此问题，PRTS提出了双向对比目标和时间加权方案。

首先，定义时间权重 q_ij = γ^(T_j - t_j) / Σ γ^(T_j‘ - t_j’)，其中γ是折扣因子，T是轨迹总步数，t是当前步。该权重给接近任务完成的状态分配指数级更大的权重，模拟了几何分布的衰减。

双向对比目标包括：

  1. 状态-动作到语言（s,a → l）目标：每个状态-动作锚点与其对应的语言指令构成唯一正例，与其他任务的语言指令构成负例。损失由样本权重γ^(T_i - t_i)加权。该目标主要促进任务级区分，使状态-动作对与其对应语言目标对齐。
  2. 语言到状态-动作（l → s,a）目标：每个语言锚点对应多个属于同一任务的状态-动作正例。损失使用上述时间权重q_ij作为软目标进行加权。该目标强制表征内积满足 ψ_i^T φ_j ∝ (T_j - t_j) log γ，从而在表征空间中编码到任务完成的时间距离。

理论证明（定理1），优化 l → s,a 目标所得的最优表征满足 ψ*(l)^T φ*(s,a) = log Q_l^π*(s,a) + C(l)，其中Q_l^π*(s,a)是在策略π*下从(s,a)出发达到目标l的折扣状态占据概率（即目标可达性）。因此，两个目标的结合确保了学习到的表征既能捕获任务身份，也能捕获任务进度，且其内积是对数折扣目标占据概率的有效估计。

与现有方法（如需要显式奖励标注或单独价值网络的π*_0.6、VLAC）相比，PRTS的创新点在于：1) 将目标可达性估计构建为对比学习问题，无需奖励标签、回报离散化、成对数据整理或辅助价值网络；2) 通过角色感知因果掩码和附加令牌块，在单次前向传播中实现行为克隆与对比表征学习的统一联合优化，开销可忽略；3) 通过时间加权方案适配语言条件设定，从轨迹结构中隐式提取密集的目标可达性监督。

实验与结果

PRTS在仿真和真实世界环境中进行了广泛评估。使用的仿真基准数据集包括：LIBERO（10个任务）、LIBERO-Pro（15个任务）、LIBERO-Plus（14个任务）以及SimplerEnv（WidowX）。真实世界评估在一个包含14个复杂操作任务的综合套件上进行，平台包括双臂RealMan和单臂Flexiv。对比的基线方法包括：RT-2、VLA基模型（PI0、PI0.5、GR00T-N1）、以及专门针对长视野任务的方法（SPIRIT-V1.5、Wall-X、Pragmatic VLA）。

实验结果表明，PRTS在多个基准上达到了最先进的性能。在LIBERO-Pro上，PRTS的成功率达到84.0%，显著优于PI0.5（78.0%）和GR00T-N1（75.3%）。在LIBERO-Plus上，PRTS取得了86.4%的成功率，相比PI0.5（80.0%）和GR00T-N1（78.6%）有显著提升。在包含长视野、接触丰富任务的SimplerEnv上，PRTS的成功率（85.0%）大幅领先于PI0.5（72.5%）和GR00T-N1（70.0%）。

图5：在LIBERO、LIBERO-Pro、LIBERO-Plus和SimplerEnv基准上的成功率对比。PRTS在所有基准上均取得最优或接近最优性能，尤其在长视野和接触丰富的SimplerEnv任务上优势明显。

图6：在14个真实世界复杂操作任务上的平均成功率。PRTS（85.7%）显著优于其他VLA基线（PI0.5: 71.4%， GR00T-N1: 64.3%），展示了其强大的现实世界泛化能力。

消融实验验证了各核心组件的贡献。移除对比学习（CRL）模块（即仅使用行为克隆）会导致在所有评估设置中性能显著下降，尤其是在长视野和零样本新指令任务上。单独使用 s,a → l 或 l → s,a 对比目标，性能均不及完整的双向目标，证实了结合任务区分和进度编码的必要性。移除时间加权（即使用均匀权重）也会损害性能，表明时间结构信息对于学习有效的目标可达性表征至关重要。

图7：消融实验结果。对比了完整PRTS、仅行为克隆（w/o CRL）、仅使用单向对比目标（仅 s,a→l 或仅 l→s,a）以及无时间加权（Uniform Weight）的变体。完整模型在所有指标上表现最佳，证实了双向对比目标与时间加权方案的有效性。

图8：在LIBERO-Pro的零样本新指令泛化测试上的表现。PRTS相比基线展现出更强的对未见过的语言指令的泛化能力。

此外，定性分析（如图9、10所示）展示了PRTS学习到的表征空间具有清晰的几何结构，其中状态-动作表征根据其到达目标的进度（时间距离）被有序排列，而基线方法的表征则缺乏这种结构。

总结与启发

本文的核心贡献可概括为三点：1) 理论框架：将VLA预训练重新构建为目标条件强化学习问题，首次将对比强化学习（CRL）引入大规模VLA模型训练，以学习量化目标可达性表征。2) 方法创新：提出了语言条件的双向对比目标与时间加权方案，解决了语言指令作为共享目标带来的“多正例”挑战，并证明了其与标准CRL的理论等价性；设计了角色感知因果掩码的单前向传播架构，以可忽略的开销统一了行为克隆与对比表征学习。3) 实证验证：在大规模多任务数据集（167B令牌）上预训练模型，并在仿真与真实世界的复杂、长视野、零样本任务上实现了最先进的性能，显著提升了执行成功率和规划鲁棒性。

论文自身提到的局限性包括：1) 对比学习目标依赖于专家演示数据中隐含的时间结构假设，在次优或嘈杂数据上可能效果不佳；2) 时间加权方案假设任务完成概率随剩余步数指数衰减，这可能对非单调任务或存在多个解路径的任务过于简化；3) 尽管架构设计高效，但引入额外的对比学习头仍带来少量参数和计算开销。

本工作对后续研究的启示在于：为VLA模型注入时间感知和物理可行性评估能力是提升其决策质量的关键方向；从离线轨迹中隐式提取结构化信号（如目标可达性）是一种有前景的范式，可减少对昂贵人工标注的依赖；所提出的统一架构表明，将强化学习目标与大型语言模型的生成式预训练相结合是可行且有效的，为构建更通用、更鲁棒的机器人基础模型开辟了新路径。

💡 一句话总结

本文解决了现有视觉-语言-动作模型在预训练时忽视机器人学习作为目标达成过程这一本质，缺乏对任务时间进展理解的问题。提出了PRTS系统，其核心技术是**基于目标条件强化学习的对比表示学习**：将语言指令视为目标，通过对比强化学习使模型学习一个统一的嵌入空间，其中状态-动作与目标嵌入的内积近似于达成目标的概率，从而量化评估物理可行性。实验表明，该方法在LIBERO等多个基准上达到SOTA，尤其在长时程、接触丰富的任务及零样本新指令设置上提升显著，证实了目标可达性感知能有效提升策略的执行成功与长时规划能力。
