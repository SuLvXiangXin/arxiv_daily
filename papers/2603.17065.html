TeleDex: Accessible Dexterous Teleoperation

arXiv: 2603.17065 作者: Yuchen Cui Team 日期: 2026-03-17

📝 详细解读

研究背景与动机

随着机器人学习日益依赖大规模数据，高效、便捷地收集演示数据变得至关重要。然而，当前最先进的策略在迁移到新任务、场景或机器人平台时，泛化能力有限，往往需要收集额外的、针对特定任务或机器人的演示数据。现有的数据收集接口（如VR控制器、3D空间鼠标或主从式硬件）通常依赖于昂贵、非便携的专用硬件，难以在实验室之外的环境大规模部署。对于需要多指灵巧操作的任务，这一问题尤为突出，因为相应的遥操作硬件更加稀缺且复杂。

尽管基于智能手机的遥操作系统（如Roboturk、TeleMoMA）因其便携性和低成本展现出潜力，但它们通常仅限于6自由度末端执行器位姿控制，无法传输精细的手指关节指令，因此不适用于需要灵巧操作的任务。本文旨在解决这一关键痛点，提出一种利用普通智能手机作为通用接口，实现低成本、低门槛的灵巧手遥操作与数据收集系统。其核心思路是：利用手机内置传感器（ARKit）和摄像头，实时流式传输6自由度手腕位姿和21自由度手部关键点估计，并通过一个3D打印的腕戴式支架实现手指级控制，结合Dex-Retarget算法将人手动作映射到任意URDF定义的机器人手上，从而提供一个统一的、可扩展的灵巧遥操作解决方案。

方法详解

TeleDex系统支持两种遥操作模式：基础手持模式和腕戴灵巧模式。系统整体架构如图2所示。

图2：TeleDex系统架构。左侧为使用3D打印腕戴接口的灵巧模式，支持21自由度手部与6自由度手腕跟踪；右侧为仅使用手机的6自由度末端执行器控制模式。捕获的状态通过Dex-Retarget处理，以映射到任意机器人URDF模型。

基础手持模式：在此配置下，手机作为一个独立的6自由度跟踪设备。系统利用ARKit估计设备位姿，无需额外硬件或校准。操作开始时，系统记录机器人的初始末端执行器位姿 ( {}^{R}T_{EE}^{0} ) 和当前手机位姿 ( {}^{A}T_{P}^{0} ) 作为参考。设当前手机位姿为 ( {}^{A}T_{P} )，则相对运动为 ( \Delta{}^{A}T_{P}=({}^{A}T_{P}^{0})^{-1}{}^{A}T_{P} )。通过一个固定的坐标对齐变换 ( {}^{P}T_{R} ) 来补偿手机坐标系与机器人控制坐标系之间的偏移。最终指令发送的机器人位姿计算为：( {}^{R}T_{EE}={}^{R}T_{EE}^{0},{}^{P}T_{R},\Delta{}^{A}T_{P} )。系统还提供了缩放位置变化的选项，以根据用户需求调整控制灵敏度。

腕戴灵巧模式：为支持手指级操作，系统开源了一个3D打印的腕戴式接口。手机通过该接口刚性固定在操作者手腕上，保持固定偏移。在此配置下，系统同时利用ARKit跟踪手机位姿 ( {}^{A}T_{P} )，并利用前置摄像头估计21个手部关键点。由于摄像头随人手移动，操作者可以自由活动，避免了基于固定外部摄像头方案中因视角遮挡或深度模糊导致的问题。手腕位姿通过固定变换 ( {}^{P}T_{H} ) 计算：( {}^{A}T_{H}={}^{A}T_{P}{}^{P}T_{H} )，并用于控制机器人手臂。同时，手部关键点通过Dex-Retarget算法，根据目标灵巧手的URDF模型，被重新定向到多自由度机器人手上。这种解耦设计使得同一接口能够泛化到具有不同运动学结构的机器人手上。

系统实现：TeleDex由一个公开发布的iOS应用程序和一个配套的Python包组成。如图3所示，手机应用实现了两种控制模式的接口。用户首先在机器人端启动Python服务器，当手机与服务器处于同一网络时，通过扫描二维码建立连接。连接确认后，即可开始实时控制和数据流传输。应用界面包含可配置的屏幕按钮，支持用户自定义回调函数，例如动态锁定控制维度、重置参考坐标系或调整运动缩放比例。机器人端的Python API提供了一个轻量级接口，用于接收流式位姿和手部跟踪数据，执行必要的坐标变换，并将处理后的状态暴露给下游控制管道。

图3：TeleDex手机应用界面截图。

与现有方法相比，TeleDex的核心创新点在于：1）首次将智能手机同时用作6自由度手腕位姿跟踪和21自由度手部关键点估计的集成设备，无需任何外部跟踪基础设施；2）通过一个低成本、可3D打印的腕戴式物理接口，将手机从手持设备转变为可穿戴的灵巧操作输入设备；3）提供了一个开源、轻量级、易于部署的完整系统（包含App和Python API），显著降低了灵巧遥操作的门槛。

实验与结果

实验在三个平台上进行评估：配备平行夹爪的xArm7（真实世界）、配备多指灵巧手的RealMan移动机械臂（真实世界），以及大规模模拟基准MolmoSpaces-Bench（模拟）。所有实验均使用运行公开版TeleDex应用的iPhone。

RQ1: 演示收集效率：在模拟环境中，将TeleDex与键盘和3Dconnexion SpaceMouse进行对比。任务包括MS-Pick（拾取指定物体）和MS-Open（打开抽屉或柜门）。实验测量了在规定30秒时限内，获得一次成功演示所需的平均时间。

图5：MolmoSpaces-Bench用户研究设置：左图使用SpaceMouse；右图使用键盘。

图6：在MolmoSpaces-Bench中，MS-Open和MS-Pick任务中用户获得成功的平均时间。结果显示，TeleDex相比SpaceMouse和键盘基线，能实现更快、更高效的演示收集。

RQ2: 直观的灵巧遥操作：在真实世界的RealMan平台上进行用户研究，评估灵巧操作能力。任务包括多形状物体抓放、目标钢琴键按压和蛋盒打开与取物。将TeleDex的操作完成时间与“策略感知速度”下人类直接执行相同任务的时间（作为近似理想演示收集速度的基线）进行对比。

图7：用于RQ2用户研究的灵巧任务：(a) 不同几何形状物体的抓放。(b) 目标钢琴键按压。(c) 蛋盒打开与物体提取。(d) 用户研究期间参与者执行任务。

结果如表II所示，所有参与者在简短熟悉后都能使用TeleDex完成所有任务。TeleDex在抓放任务上的平均完成时间为74.0±39.0秒，钢琴键按压为75.8±19.7秒，蛋盒打开为18.7±6.6秒。虽然慢于人类基线，但证明了其能够支持完成需要精确抓握、独立手指关节运动和接触敏感操作的任务。

复杂操作实验：进一步在xArm7上测试了更具挑战性的动态任务，包括动态物体捕捉、反应式守门和精确的导线环追踪（图8）。这些任务验证了系统低延迟、反应灵敏和高精度控制的能力。



图8：使用xArm7和TeleDex进行的动态、反应式和精确操作示例：(a) 动态物体捕捉，(b) 反应式守门，(c) 精确导线环追踪。

策略训练：为验证TeleDex收集的演示数据适用于下游策略学习，在MuJoCo中设计了一个模拟水果抓放任务（图9）。使用TeleDex收集了120条演示轨迹，并训练了一个简单的行为克隆基线策略（CNN编码器+MLP策略头）。该策略在20个评估回合中取得了80%（16/20）的成功率。

图9：用于策略训练实验的MuJoCo模拟水果抓放任务。

第三方评估：如图10所示，TeleDex已被多个第三方研究项目采用，成功部署在KUKA iiwa、Franka Panda、xArm-7等多种机器人平台上，验证了其易部署性和跨平台通用性。

总结与启发

本文的核心贡献包括：1）提出了TeleDex，一个完全开源、基于智能手机的灵巧遥操作系统，它通过结合手机内置传感器与一个可选的3D打印腕戴接口，首次实现了无需外部跟踪基础设施的、可访问的21自由度手部遥操作。2）通过系统的用户研究证明，TeleDex在演示收集效率上优于键盘和SpaceMouse等常见商品化接口，并能支持真实世界中多种需要精细手指控制的灵巧操作任务。3）验证了使用TeleDex收集的演示数据可用于训练有效的模仿学习策略，并且系统已成功集成到多个第三方研究项目中，展示了其跨平台的实用性和可扩展性。

论文提到的局限性在于：长时间使用腕戴配置可能会因智能手机的额外重量导致用户疲劳，这与VR控制器等其他可穿戴遥操作设备存在的工效学问题类似。

这项工作为机器人社区提供了一个低成本、易部署的灵巧数据收集工具，有望促进需要大量人类演示的机器人学习研究。其设计思路——利用普及的消费级设备（智能手机）和模块化、开源的软硬件——为未来开发更易用、更通用的机器人交互接口指明了方向。后续研究可以探索更轻量化的硬件配置、替代的佩戴方式，或结合共享自主权方法来进一步减轻操作者负担。

💡 一句话总结

本文针对机器人操作策略泛化能力有限、部署时数据收集门槛高的问题，提出TeleDex系统。该系统利用普通手机作为低成本便携接口，通过流式传输低延迟6-DoF手腕姿态和21-DoF手部状态估计，并重定向至机器人手臂与多指手，无需外部跟踪设备，支持手持和3D打印手部安装两种模式。在模拟和真实世界操作任务中的评估表明，TeleDex能有效作为统一可扩展的遥操作接口，助力快速收集演示数据以支持策略微调。
