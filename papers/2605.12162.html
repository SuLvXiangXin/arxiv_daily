X-Imitator: Spatial-Aware Imitation Learning via Bidirectional Action-Pose Interaction

arXiv: 2605.12162 作者: Cewu Lu Team 日期: 2026-05-12

📝 详细解读

研究背景与动机

机器人模仿学习领域，当前主流方法在处理空间感知与动作生成的交互上存在关键局限性。一类方法依赖深度或点云等3D几何表征进行隐式特征学习，但难以提取精确的物体级关系；另一类方法利用流或视觉提示等显式空间引导，但流缺乏物体级语义，视觉提示则局限于2D平面。最直接的显式空间感知方式是物体的6D姿态。近期方法利用物体姿态轨迹，但通常仅将其作为动作生成的中间步骤或辅助监督。这两种范式都未能建立真正的互惠连接：辅助监督在推理时缺乏显式交互，而将姿态作为中间动作则强制了严格的单向顺序流程。这种解耦或单向的特性，与人类操作中空间感知与动作执行紧密耦合、双向循环的过程形成鲜明对比。本文针对这一痛点，提出通过建模动作序列与物体姿态轨迹的联合预测，建立双向的动作-姿态交互循环，以模仿人类依赖内部前向模型进行状态预测与更新的机制。核心思路是提出一个双路径框架，使前一时刻生成的动作能作为条件上下文来预测当前姿态，反之亦然，从而实现空间推理与动作执行之间的持续相互细化。

方法详解

X-Imitator的整体框架是一个双路径架构，包含一个动作分支和一个姿态分支，两者共享视觉编码器提取的感知特征。其核心创新在于跨时间步的交互机制：一个分支在时间步t-1的输出，作为另一个分支在时间步t的额外条件输入。

图1：X-Imitator整体框架。框架维护两个交互分支：动作分支（策略）和姿态分支，两者共享视觉特征。关键创新是跨步交互机制：一个分支在时间步t的输出，作为另一个分支在时间步t+1的额外条件输入。

具体而言，给定时间步t的视觉观测O_t（通常包含RGB-D图像和机器人本体感知），共享视觉编码器提取特征F_t^vis。动作分支F_a预测未来动作轨迹A_t = {a_t, a_{t+1}, ..., a_{t+H-1}}，其条件不仅包括F_t^vis，还包括上一时刻预测的物体姿态轨迹P_{t-1}。反之，姿态分支F_p预测未来物体姿态轨迹P_t = {p_t, p_{t+1}, ..., p_{t+H-1}}（其中p_i ∈ SE(3)），其条件包括F_t^vis和上一时刻预测的动作轨迹A_{t-1}。这一双向交互的更新规则形式化定义为：
{ A_t = F_a( Cond_a( φ_a(P_{t-1}), F_t^vis ) )
P_t = F_p( Cond_p( φ_p(A_{t-1}), F_t^vis ) )
其中φ(·)将过去轨迹投影到特征空间，Cond(·)是特征融合算子（当t=0无过去估计时，直接输出F_t^vis）。

为证明框架的通用性，论文基于三种代表性的视觉运动策略实例化了动作分支：基于点云扩散的DP3、基于图像Transformer的ACT和基于点云Transformer的RISE。姿态分支统一实现为一个轻量级的扩散头。不同实例化的关键区别在于条件序列投影器φ(·)和特征融合算子Cond(·)的具体实现。

图2：动作分支中的特征融合。左图：X-DP3中的加法融合。右图：X-ACT中的拼接融合。视觉特征F_t^vis由各基础方法的感知模块提取。姿态轨迹特征F_t^pose通过以下方式获得：对于X-DP3和X-RISE，使用MLP处理展平的P_{t-1}；对于X-ACT，对P_{t-1}进行自注意力计算，再与F_t^vis进行交叉注意力计算。

  • X-DP3：使用三层MLP将展平的条件序列（A_{t-1}, P_{t-1}）投影为特征（F_t^act, F_t^pose），然后通过逐元素加法与视觉特征F_t^vis融合，输入各自的扩散头。
  • X-ACT：将条件序列线性投影为token序列，先进行自注意力捕获时序依赖，再以条件token为查询，以基于ResNet的视觉token F_t^vis为键和值进行交叉注意力，得到视觉增强的条件特征。在动作分支，F_t^pose与F_t^vis拼接后输入Transformer生成动作；在姿态分支，F_t^act和F_t^vis沿序列维度缩减后逐元素相加，用于引导姿态轨迹扩散。
  • X-RISE：条件序列展平后经线性层投影为特征（F_t^act, F_t^pose），作为两个读出token去查询处理后的点云token，得到视觉增强的条件特征，直接用于引导动作和姿态扩散。

训练采用端到端的联合损失函数：L = L_action + λ · L_pose。其中L_action对于X-ACT是CVAE重建损失，对于X-DP3和X-RISE是动作序列的扩散去噪MSE损失；L_pose是姿态轨迹的扩散去噪MSE损失；λ是平衡超参数，固定为1。

与现有方法相比，创新点具体体现在：1) 提出了跨时间步的双向动作-姿态交互机制，超越了仅将姿态作为单向引导或辅助监督的常见做法；2) 联合建模消除了推理时对外部姿态估计器的依赖；3) 框架设计为即插即用的模块化架构，可灵活集成到多种视觉运动策略中。

实验与结果

实验使用了四个多样化的模拟基准测试集共24个任务：Adroit、DexArt、MetaWorld（包含hard和very hard设置）以及双臂操作的RoboTwin 2.0。此外，还在3个真实世界任务上进行了验证。对比的基线方法包括代表性的点云策略DP3、RISE和图像策略ACT，以及DP3与MBA增强的结合版本。

关键实验结果如下：
X-Imitator能持续提升各种视觉运动策略的空间感知和整体性能。在Adroit、DexArt和MetaWorld基准上，X-DP3取得了63.8%的平均成功率，显著优于基础DP3（54.6%）和DP3+MBA（58.9%），如表1所示。在需要精确空间对准的任务（如Door、Pen、Stick Pull）上，X-DP3的提升高达21%（图4）。在RoboTwin 2.0基准上（表2），X-Imitator展示了跨不同基础策略的强通用性，尤其为缺乏空间感知的图像策略ACT带来了显著增益（从27.86%提升至37.57%）。X-DP3和X-RISE也分别从52.57%和60.14%提升至58.29%和64.43%。

图4：我们的X-DP3与DP3及其MBA增强版本在Adroit、DexArt和MetaWorld共17个模拟任务上的对比。每个模拟基准的平均成功率见表1。

消融实验验证了双向交互机制的有效性。论文设计了三种DP3变体（图5）：DP3+SepAux（无交互的多任务学习）、DP3+UniAux（将动作和姿态拼接作为统一扩散目标）、DP3+Hybrid（混合训练策略）。结果（表1中间行）显示X-DP3优于所有变体，证实了双路径双向交互在捕获空间依赖性方面比非交互或单向交互方案更有效。

图5：消融研究中DP3变体的比较图示。包括DP3+MBA以进行完整比较。

图6：条件轨迹长度N对X-DP3和X-RISE在三个RoboTwin 2.0任务上性能的影响研究。更长的条件轨迹能更好地捕捉运动模式，并倾向于带来更好的性能。

此外，研究还发现条件轨迹长度N影响性能（图6）。更长的条件轨迹能更好地捕捉运动模式，并倾向于带来更好的性能。计算开销方面，以RISE为例，X-RISE参数从51M增加到71M，训练时每次迭代的内存使用和耗时略有增加，推理频率从11Hz降至6Hz（两个分支顺序执行，可通过并行加速）。

总结与启发

本文的核心贡献在于：1) 提出了一个新颖的双向动作-姿态交互框架X-Imitator，将空间感知与动作执行建模为紧密耦合的闭环，实现了跨时间步的持续相互细化；2) 该联合建模消除了推理时对脆弱的外部姿态估计器的依赖，增强了在遮挡等挑战下的鲁棒性；3) 框架设计为即插即用、模块化的，可无缝集成到多种现有的视觉运动策略中，并展示了广泛的适用性和显著的性能提升。

论文自身提到的局限性包括：由于增加了姿态扩散头，推理速度有所下降（尽管可通过并行化缓解）；条件轨迹长度N需要调整以平衡性能与效率。

这项工作对后续研究的启示在于：将感知与动作建模为双向交互的、共同进化的过程，而非解耦或单向的流水线，是提升机器人空间操作能力的一个有前景的方向。这种“内部前向模型”的建模思路可进一步扩展到更复杂的多物体交互、非刚性物体操作等场景。此外，如何更高效地实现双向交互、如何处理动态场景中的多模态不确定性，是值得探索的未来方向。

💡 一句话总结

本文针对机器人模仿学习中空间感知与动作生成割裂的问题，提出X-Imitator框架。其核心是**双向动作-姿态交互机制**，通过将历史动作与当前物体姿态预测相互条件化，形成紧密耦合的闭环，实现空间推理与动作生成的持续协同优化。该模块化设计可灵活嵌入各类视觉运动策略。在24项模拟和3项真实任务上的实验表明，X-Imitator显著超越了原始策略及采用显式姿态指导的先前方法。
