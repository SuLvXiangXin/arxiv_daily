Unleashing More Actions via Action Compositional Training for VLA Models

arXiv: 2607.00351 作者: Xiaojiang Peng Team 日期: 2026-07-01

📝 详细解读

研究背景与动机

当前，视觉-语言-动作模型通过在大规模、多样的示教数据上训练，在机器人操作任务中表现出色。然而，主流的模仿学习范式存在关键局限性：模型严重过拟合于训练数据中的特定行为模式，即使面对仅由已知子技能新组合构成的、分布外的场景，也无法泛化。虽然扩大数据集能缓解过拟合，但收集高质量机器人数据成本高昂。针对这一“组合泛化”的痛点，本文提出了新视角：利用VLA模型内部已编码的任务潜在表示，直接从现有任务中合成新颖、物理有效的演示数据，以扩充训练集，而非依赖额外人工遥操作。本文核心思路是，将推断阶段用于控制的行为组合合成技术（文本潜在插值），转化为一个离线的数据增强框架，从而让模型在训练中内化组合技能。

方法详解

ACT-VLA是一个离线数据增强框架，旨在利用预训练VLA模型中已有的组合结构，为原始数据集中不存在的新任务组合生成训练演示，无需额外人工数据收集。整体流程分为三个阶段。

图2：方法整体流程。我们的方法包含三个阶段：(1) 表征引导的轨迹合成，(2) 数据记录与处理，(3) 在增强数据集上训练。合成的演示在被纳入训练集前，由物理模拟器进行过滤。

核心模块与细节：

  1. 基于潜在插值的演示合成：这是方法的核心引擎。借鉴Text Latent Interpolation技术，通过计算两个基础任务各自文本潜在表示（Task-specific text latent，通过平均多个演示episode中文本token的隐藏状态得到）的线性插值，来引导模型生成连续的行为过渡。具体操作是在每个时间步i，修改文本隐藏状态h^T(i)：h^T(i) <- h^T(i) + (1-α)*T^1 + α*T^2 - [(1-α)*T^2 + α*T^1]，其中α = i/λ 随时间从0线性增长到1，从而在episode开始时强化任务1的行为，随时间推移平滑过渡到任务2的行为，生成一个组合轨迹。

  2. 从推断时干预到训练时数据合成的关键设计：本文的核心贡献并非插值操作本身，而是将其重新定位为系统化的数据生成引擎，并解决了由此带来的新挑战。主要包括三个设计维度：

    • 指令设计：为使合成的轨迹可用于训练，需要为其生成一个贯穿所有时间步、准确描述组合任务的自然语言指令ℓ。本文通过拆分和重组基础任务指令的文本组成部分（例如，将任务A的物体与任务B的目标位置配对）来推导ℓ。
    • 质量控制：引入双重过滤策略。首先，利用物理模拟器进行严格的“任务完成验证”，只保留完全成功完成组合任务的rollout。其次，设定“步数预算约束”，只保留在预定步数内完成任务的轨迹，以排除冗长或冗余的片段，确保合成数据高质量。
    • 训练动态：在套件层面保持原始数据与合成数据的规模均衡，以防止合成数据分布淹没原始任务分布，导致灾难性遗忘。每个OOD套件合成约300-400个成功演示。

  3. 数据记录与处理：将成功的合成轨迹记录为标准训练格式，包括RGB观测、机器人本体感知状态、执行的动作以及组合任务指令。

  4. 增强策略训练：使用与基线VLA模型完全相同的损失函数和超参数，在由原始数据和合成数据共同组成的增强数据集上进行标准的行为克隆训练，无需修改模型架构。

创新点：与现有方法相比，本文的主要创新在于系统性地将推断时用于控制的潜在插值技术，转化为一个离线的、注重质量的训练数据生成流程，使VLA模型能够通过数据暴露直接在权重中内化组合转换能力，无需在部署时依赖任何外部规划器或额外的推断时计算。

实验与结果

实验设置：方法在LIBERO模拟基准测试中进行评估，主要关注两个新构建的组合泛化评估套件：LIBERO-Spatial-OOD和LIBERO-Goal-OOD，它们包含了原始训练集中未见但可分解为已知子技能的新任务组合。

对比基线：包括在原始数据上训练的主流VLA模型（UniVLA， OpenVLA-OFT， GR00T-N1， π0.5），以及应用了推断时文本潜在插值的π0模型，作为与本文训练时合成方法的直接对比。

关键实验结果：
如表I所示，在π0.5骨干网络上应用本文方法后，在LIBERO-Spatial-OOD上的成功率从35.5%提升至88.2%，在LIBERO-Goal-OOD上从46.6%提升至95.6%，绝对增益分别达到52.7和49.0个百分点。这表明从现有数据集中生成组合演示是提升模型对新任务组合泛化能力的有效途径。

与推断时应用TLI的π0相比，本文方法取得了更高的OOD成功率（Spatial-OOD：88.2% vs 81.0%； Goal-OOD：95.6% vs 85.0%），且无需任何部署时干预，证明了训练时合成策略比推断时潜在引导更有效、更实用。在所有六个评估套件的平均成功率上，本文方法也优于所有基线。

总结与启发

核心贡献：

  1. 首次系统性地提出并解决了为视觉-语言-动作模型生成组合演示数据的问题。
  2. 提出了ACT-VLA，一个即插即用的离线数据增强框架，通过重新利用文本潜在插值进行自动化的组合演示合成。
  3. 在LIBERO-Spatial-OOD和LIBERO-Goal-OOD数据集上取得了最先进的结果，显著提升了VLA模型的组合泛化能力。

论文提到的局限性：

  1. 验证范围局限于桌面环境下的顺序两技能组合。虽然理论上可扩展到更长的技能链，但递归组织和过滤多技能轨迹会引入指数级复杂度的优化挑战。
  2. 合成质量依赖于预训练VLA骨干网络的语义解纠缠能力。在较弱的基础模型上部署本方法可能成为性能瓶颈。
  3. 所有实验均在仿真中进行。尽管采用了双重过滤策略确保物理有效性以缓解分布偏移，但迁移到实体硬件上的“仿真到现实”差距仍有待未来工作评估。

对后续研究的启示：
本文展示了数据为中心的方法在解锁模型组合能力方面的强大潜力。未来工作可以探索如何将本方法与更强的基础表示学习结合，以提升合成质量和鲁棒性；研究扩展到更复杂的多阶段、长序列组合任务的可行性；以及最终在真实机器人平台上验证该框架的有效性，推动VLA模型向更通用、更灵巧的机器人控制发展。

💡 一句话总结

这篇论文针对VLA模型在机器人操作中因过拟合特定行为而泛化能力差的问题：模型难以处理已学子技能的新组合，且高质量数据收集成本高昂。为此，作者提出ACT-VLA框架，通过利用模型潜在任务表示从现有任务中合成物理有效的演示数据，实现离线数据增强，从而自动扩展训练分布。实验在模拟操作任务中进行，结果显示，基线VLA模型因分布过拟合泛化不佳，而使用合成数据训练的策略取得了显著更高的成功率，验证了该方法的有效性。
