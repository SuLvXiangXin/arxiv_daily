From Technical Metrics to User Perception: A User Study of a Multimodal Human-Robot Interaction System for Object Detection and Grasping

arXiv: 2607.00530 作者: Shen Guanting Team 日期: 2026-07-01

📝 详细解读

研究背景与动机

当前，人机交互（HRI）领域越来越多地结合大型语言模型和视觉-语言模型等多模态方法，旨在构建能够理解人类意图、适应环境并自然交互的系统。然而，技术指标的提升（如任务成功率、延迟降低）并不一定意味着用户在实际交互中能够感知到这些改进。尤其是在任务简短、场景受限、机器人行为本身已相对稳定的情况下，技术层面的差异可能并不明显。

本研究的核心痛点在于弥合技术改进与用户感知之间的鸿沟。具体而言，作者在先前工作中构建了一个多模态物体抓取系统（基线系统，任务成功率75%），并通过消融实验找到了一个更优的模块组合（改进系统，任务成功率90%）。本文并非提出新架构，而是聚焦于一个“以人为中心”的评估问题：这15个百分点的技术性能提升，是否足以让真实用户在实时交互中一致地感知到差异？本文的核心思路是通过一个严谨的、被试内的用户研究，直接比较基线系统与改进系统，探究用户在感知速度、可靠性及整体流畅度等主观维度上的评价是否与技术指标相符。

方法详解

本研究并非提出新的技术方法，而是对两个既有系统配置（基线 vs. 改进）进行用户侧评估。因此，其“方法”是用户研究的设计与执行。

整体流程：研究采用被试内设计。24名参与者依次与两个系统进行交互。每次交互包含两次完整的物体抓取任务试运行。在每次与一个系统交互后，参与者立即填写一份感知问卷。两个系统的呈现顺序在参与者间随机平衡，以抵消学习效应和顺序效应。整个流程是现场与物理机器人交互，而非基于视频的评估。

图1：两种系统配置共有的完整多模态操作流程硬件与数据流。展示了从语音捕获、转录、语言理解、视觉感知到运动控制的完整信息流。此硬件平台和顶层架构在基线系统和改进系统中保持一致。

核心模块（即比较的两个系统）：

  1. 基线系统：集成了Whisper（语音识别）、Florence-2（开放式词汇物体检测）、LLaMA 3.1（动作意图提取）和区间二型模糊逻辑控制器。
  2. 改进系统：在相同架构下，将语言理解和视觉感知模块分别替换为在先前消融实验中表现最优的Qwen 3.5 9B和Grounding DINO + SAM组合，同时保留相同的模糊逻辑控制器。

研究设计与测量：

  • 任务：固定的桌面物体抓取任务，参与者发出自然语言指令（如“拿起苹果”），机器人需理解并执行。
  • 问卷：针对三个感知构念，每个构念使用两个7点李克特量表题项进行测量：
    • 感知速度：评估系统响应和完成任务的速度。
    • 感知可靠性：评估系统正确执行指令的可能性。
    • 感知能力与流畅度：评估整体执行是否顺畅、能力强。
  • 最终偏好：在体验两个系统后，参与者被强制选择更喜欢哪一个系统。

统计分析：

  • 使用配对样本t检验（数据符合正态分布）比较三个感知构念的得分差异，并进行Holm校正以控制多重比较错误率。
  • 使用精确二项检验分析最终偏好选择是否显著偏离随机水平（50%）。
  • 报告效应量（Cohens d_z）以量化差异大小。

创新点：
本研究的创新性不在于机器人系统架构本身，而在于其评估视角。它将评估重点从纯粹模块级的技术指标（成功率、延迟）转向了用户对性能差异的主观感知和偏好，强调了在评估机器人操作流水线时，需要将技术基准与以用户为中心的證據相结合。

实验与结果

实验设置：

  • 平台与任务：使用Dobot Magician机械臂、Intel RealSense D435i RGB-D相机，在固定的桌面场景中进行开放式词汇物体抓取任务。
  • 参与者：24名成年人（平均年龄24.6岁，37.5%为女性）。
  • 对比系统：如上所述的基线系统（75%成功率）与改进系统（90%成功率）。

关键实验结果：

  1. 系统偏好：24名参与者中，17人（70.83%）更偏好改进系统。精确二项检验结果显示此偏好显著（p = 0.043），效应量中等（Cohen‘s h = 0.43）。这表明用户能够以高于随机水平的概率区分出更好的系统。
  2. 感知速度（H1）：改进系统（M=5.69， SD=0.61）在感知速度上的评分显著高于基线系统（M=4.61， SD=0.55），平均差异1.08个量表点（p_adj < 0.001），效应量非常大（d_z = 1.85）。
  3. 感知可靠性（H2）：改进系统（M=4.89， SD=0.59）在可靠性上的评分也显著高于基线系统（M=3.95， SD=0.63），平均差异0.94个量表点（p_adj < 0.001），效应量大（d_z = 1.54）。
  4. 感知能力与流畅度（H3）：在此构念上观察到的差异最大。改进系统（M=5.01， SD=0.64）的评分显著高于基线系统（M=3.76， SD=0.59），平均差异1.25个量表点（p_adj < 0.001），效应量非常大（d_z = 2.03）。

结果总结：
所有三个研究假设（H1， H2， H3）均得到数据支持。改进系统在主观感知的所有维度上都获得了显著更高的评分，且效应量从“大”到“非常大”。基线系统的评分均值在可靠性与整体能力构念上低于量表的中点（4分），表明用户确实感知到了其不足；而改进系统的评分均值均高于中点，但未达到天花板，这与它90%而非100%的成功率相吻合。这些结果证实，消融实验所确定的技术改进（成功率提升15个百分点）确实转化为了用户可感知且更优的交互体验。

总结与启发

核心贡献：

  1. 实证验证：通过严谨的用户研究证明，在特定任务（桌面物体抓取）中，将端到端任务成功率从75%提升至90%的特定技术改进，能够被用户显著感知，并带来更快的速度感、更高的可靠性评价和更佳的流畅度体验。
  2. 方法论倡导：强调了评估HRI系统时，除了技术基准测试外，补充用户中心证据的重要性。技术指标的优越性并不自动等同于优越的用户体验，需要进行专门的感知研究来验证。
  3. 量化洞察：提供了关于“多大技术改进可能引发用户感知差异”的初步量化证据（在本研究中约为15个百分点的成功率提升），并展示了如何通过效应量来解读感知差异的幅度。

局限性：
论文自身指出的局限性包括：研究样本量较小（N=24），且参与者群体相对同质（年轻成人）；实验场景为受控的桌面环境，任务相对简单；研究结论可能无法直接推广到更复杂、长期或开放世界的交互任务中。

后续启示：

  1. 评估范式：未来的机器人系统研究，尤其是在涉及人类用户的交互式任务中，应考虑将主观用户评价作为与客观技术指标并列的评估维度。
  2. 改进阈值：可以探索在不同任务复杂性、交互时长和用户群体下，技术性能需要提升多少才能达到用户可感知的“最小可觉差”。
  3. 多维感知：本研究验证了速度、可靠性、流畅度等基础感知构念。未来工作可以探索更丰富的感知维度，如信任度、拟人性或协作感，以更全面地理解技术选择对用户体验的影响。

💡 一句话总结

本文研究人机交互系统技术指标提升（端到端任务成功率从75%增至90%）是否转化为用户可感知的体验差异。基线系统集成Whisper（语音识别）、Florence-2（开放词汇检测）、LLaMA 3.1（动作提取）及模糊逻辑控制器；改进配置以Grounding DINO+SAM（感知）和Qwen 3.5 9B（语言）替换相应模块。对24名用户的实验表明，70.83%参与者显著偏好改进系统（p=0.043），且在速度、可靠性、流畅性上评分显著更高（p<0.001），证实15个百分点的技术提升能被用户直接感知。
