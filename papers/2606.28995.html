HJ-SafeDMP: Hamilton-Jacobi Reachability-Guided Dynamic Movement Primitives for Provably Safe Robot Motion

arXiv: 2606.28995 作者: Ravi Prakash Team 日期: 2026-06-27

📝 详细解读

研究背景与动机

机器人运行在安全关键环境（如人机交互场景）中时，必须同时满足鲁棒性和安全性两大关键需求。当前，动态运动原语（Dynamic Movement Primitives, DMPs）因其固有的稳定性、时间灵活性以及从单次演示中高效泛化轨迹的能力，成为生成机器人运动的主流方法之一。然而，DMPs本质上缺乏强制执行安全性的理论机制，通常与人工势场（Artificial Potential Fields, APFs）等启发式反应式方法结合，这些方法易陷入局部极小值且无法提供形式化的安全保证。另一方面，哈密顿-雅可比（Hamilton-Jacobi, HJ）可达性分析为计算最坏情况安全边界和前向不变安全集提供了理论基础，但传统的基于网格的计算方法受维度诅咒限制，难以用于实时控制。

本文针对的核心痛点是：如何将DMP的计算效率和鲁棒性与HJ可达性的形式化安全保证相结合，同时避免在线优化（如CBF-QP）带来的高计算开销。本文提出了一个新的视角：从离线演示数据中学习一个基于HJ可达性的控制屏障值函数（Control Barrier Value Function, CBVF），并将其作为一个闭式（closed-form）的安全调制层，实时调整DMP的输出，从而实现可证明安全、鲁棒且计算高效的运动生成。其核心思路可以概括为：通过离线数据学习一个编码了未来安全信息的CBVF，并在在线执行时利用该CBVF的梯度对DMP轨迹进行直接的、无需在线优化求解的安全调制。

方法详解

HJ-SafeDMP的整体框架分为两个阶段：1) 从离线演示数据中学习安全值函数（CBVF）；2) 将该CBVF作为安全调制器与DMP集成，进行在线安全运动生成。

图1：HJ-SafeDMP框架流程图。(a) 记录演示并编码为DMP。(b) 通过基于期望回归的有限差分HJ递归，从演示数据中离线学习CBVF。(c) 在线执行时，学习到的CBVF以闭式形式调制DMP输出，在保持目标收敛的同时强制执行安全性。

核心模块1：离线学习控制屏障值函数（CBVF）
该模块的目标是从离线数据集 𝒟 = { (x_t, u_t, x_{t+1}) } 中学习一个安全值函数 B_θ(x)。关键技术细节包括：

  • 有限差分CBVF递归：借鉴HJ可达性理论，采用离散化递归来逼近连续时间的HJB方程：B_Target^𝒟 = (1-γ)ℓ(x) + γ min{ℓ(x), B_ψ(x')}。其中ℓ(x)是当前状态到障碍物的符号距离（安全规格），γ是折扣因子，B_ψ是参数化的CBVF网络。这个递归将未来的安全信息（最坏情况）反向传播。
  • 期望回归学习目标：为了解决离线学习中无法对所有可能动作进行最大化的问题，采用τ-期望回归损失 ℒ_τ (τ>0.5) 来训练CBVF网络。该损失函数会赋予正向残差更高的权重，使学习到的B_θ(x)逼近数据集支持的动作所能达到的“最佳”安全值（上包络），而不是平均行为策略的安全值，从而避免了查询分布外（OOD）动作。
  • 保形预测校准：由于有限数据导致的近似误差，学习到的CBVF的零值边界可能不够准确。为此，引入一个保形预测校准步骤，在一组校准状态上计算一个校正边界δ，使得校准后的安全集 𝒮_δ = {x: B_θ(x) ≥ δ*} 能以一定的概率（1-β_s）提供有限样本的安全覆盖。

核心模块2：闭式安全调制DMP（HJ-SafeDMP）
该模块将学习到的CBVF集成到DMP框架中，实现实时安全控制。

  • DMP作为名义运动：名义轨迹由标准的二阶吸引子动力学系统（公式1）生成，提供鲁棒性和目标收敛性。
  • CBVF梯度安全调制：这是本文的关键创新点。不同于传统的CBF-QP方法需要在线求解二次规划，HJ-SafeDMP设计了一个基于CBVF梯度的附加项f_HJ，直接调制DMP的加速度输出（公式13）。具体调制律如公式14所示：当B_θ(x)低于激活阈值时，施加一个与梯度∇_x B_θ(x)同方向的力，其大小与1/ξ(B_θ(x))成正比，其中ξ(b) = max(b - δ*, ε_min)。这意味着当状态接近安全边界（B_θ → δ*）时，调制力会急剧增大，将状态“推”回安全区域内部；当状态远离边界时，调制力为零，DMP自由执行。
  • 动态障碍物处理与自适应时间缩放：对于动态障碍物，在线更新安全规格ℓ(x,t)并重新评估B_θ(x)，由于是神经网络前向传播，计算开销极小。此外，引入自适应时间缩放机制（公式17-18），当安全调制导致轨迹偏离较大时，自动放缓执行速度（增大时间常数τ），为恢复留出更多时间。

与现有方法的创新点对比

  1. 安全保证与计算效率的结合：相比依赖在线QP求解的CBF方法（如NODE-CLF-CBF），HJ-SafeDMP通过闭式梯度调制实现了形式化安全保证，计算复杂度降低数个数量级。
  2. 从被动反应到主动预防：相比反应式的APF方法，学习到的CBVF编码了未来轨迹的安全性信息，能够提前预警并采取平滑的规避动作，避免了APF的局部极小值和震荡问题。
  3. 与手工设计边界的对比：相比同样闭式安全的SafeDMPs（使用手工设计的时空管），HJ-SafeDMP的CBVF边界是通过数据驱动的HJ递归学习得到的，理论上能编码更精确、更全局化的安全信息。

实验与结果

实验设置：

  • 平台与数据：在7自由度Franka Emika Panda机械臂仿真环境中进行实验。使用LASA手写数据集生成3D演示轨迹，并 augmented 了探索性 rollout 以构建包含75K个转移的离线数据集。
  • Baseline方法：
    • NODE–CLF–CBF：基于神经ODE学习动力学，并通过在线求解CBF-QP保证安全。
    • DMP–APF：标准DMP结合人工势场进行避障。
    • SafeDMPs：DMP结合手工设计的时空管（Spatio-Temporal Tubes）实现闭式安全。
  • 评估指标：包括执行时间（计算效率）、平均绝对误差（轨迹复现精度）、碰撞率（安全性）、最小净空距离以及受到扰动或规避障碍后的收敛时间（鲁棒性）。

关键实验结果：
根据论文中的TABLE I（量化对比表），关键数据如下：

  • 计算效率：HJ-SafeDMP每控制步的执行时间约为1.2e-4秒，与SafeDMPs (1.03e-4s)和DMP-APF (6.7e-4s)同属微秒级别，而NODE–CLF–CBF需要0.3207秒，HJ-SafeDMP快了三个数量级以上。
  • 安全性：HJ-SafeDMP、NODE–CLF–CBF和SafeDMPs在100次试验中的碰撞率均为0%（提供形式化保证），而DMP-APF的碰撞率为14%。
  • 鲁棒性与性能：
    • 在名义轨迹复现精度（MAE Nom.) 上，HJ-SafeDMP (0.0098m) 略优于SafeDMPs (0.0113m)，显著优于其他方法。
    • 在抗扰动能力（MAE Pert.）上，HJ-SafeDMP (0.0187m) 表现最佳。
    • 在障碍物规避后的收敛时间（Conv. T OA）上，HJ-SafeDMP (0.287s) 远短于SafeDMPs (0.633s) 和NODE–CLF–CBF (0.411s)，这表明其CBVF引导的规避动作更加高效平滑。

文字说明：上述数据综合表明，HJ-SafeDMP在严格保证零碰撞率（安全性）的前提下，实现了与最轻量级方法相当的计算效率，同时在轨迹复现精度、抗干扰恢复和规避效率（鲁棒性）方面均表现出优势，验证了其将DMP效率、鲁棒性与HJ可达性安全保证有效结合的设计理念。

总结与启发

核心贡献：

  1. 提出了HJ-SafeDMP框架：首次将动态运动原语（DMPs）与基于数据驱动学习的哈密顿-雅可比可达性安全值函数（CBVF）相结合，实现了无需在线优化的、可证明安全的机器人运动生成。
  2. 设计了一种高效的闭式安全调制律：利用学习到的CBVF梯度直接调整DMP输出，用单次神经网络前向和反向传播取代了昂贵的在线二次规划求解，在保持形式化安全的同时，极大提升了计算效率。
  3. 构建了完整的离线学习流程：引入了基于有限差分HJ递归、期望回归和保形预测校准的CBVF学习方法，能够从有限的演示数据中学习到可靠的安全证书，并处理分布外动作和有限样本的校准问题。

局限性：
论文本身未明确阐述局限性，但根据方法描述可推断：框架的性能高度依赖于离线数据集的质量和覆盖度；保形预测提供的安全保证是概率性的（在给定置信水平下）；对于极为复杂或高度动态的环境，仅基于当前状态梯度调制的策略可能需要更复杂的预测与规划。

后续研究启示：

  1. 扩展到更复杂模型与场景：可将该方法应用于更复杂的机器人系统（如足式机器人）或考虑更丰富的环境不确定性（如传感器噪声、模型误差）。
  2. 与高级规划器结合：将HJ-SafeDMP作为低层安全控制器，与高层任务规划或运动规划器结合，构建分层安全架构。
  3. 硬件部署与验证：在实际机器人硬件平台进行部署，进一步验证其在真实物理交互中的安全性、鲁棒性和实时性。

💡 一句话总结

本文针对机器人运动中安全性与效率的矛盾问题，提出HJ-SafeDMP框架。该方法将动态运动原语（DMP）与学习的哈密尔顿-雅可比可达性安全值函数结合：离线训练控制障碍值函数作为实时安全滤波器，通过闭式控制律调制DMP输出，避免在线二次规划求解，引入期望学习和共形预测校准增强安全性。实验表明，在7自由度机器人上该方法实现了正式安全保证，执行速度比基于优化的基线快数个数量级，同时保持了DMP的鲁棒性和人机交互适应性。
