A Multi-View 3D Telepresence System for XR Robot Teleoperation

arXiv: 2604.03730 作者: Gerhard Neumann Team 日期: 2026-04-04

📝 详细解读

研究背景与动机

机器人遥操作在远程维护、搜索救援和机器人学习数据收集中至关重要。有效的遥操作需要直观的3D视觉和可靠的深度线索，而传统的基于屏幕的界面通常无法提供。目前，基于虚拟现实（XR）的遥操作系统主要采用两种可视化策略：一种是依赖多个RGB相机流，能提供高分辨率细节但缺乏明确的深度感知；另一种是使用点云，能提供3D空间结构但往往缺乏精细的纹理细节。因此，操作员经常面临全局场景理解与高分辨率局部细节之间的权衡。此外，不同可视化策略如何影响VR遥操作性能尚缺乏系统性比较。本文针对这一痛点，旨在研究不同可视化模态对VR遥操作性能、工作负荷和用户体验的影响，并提出了一种结合全局点云与局部高分辨率RGB流的混合系统，以同时提供3D空间结构和局部细节。

本文的核心思路是：通过融合三个静态RGB-D相机的几何信息生成GPU加速渲染的实时点云，提供全局3D场景理解；同时，在末端执行器附近集成一个腕部安装的RGB流，在点云细节有限的区域提供高分辨率局部细节，从而提升遥操作的临场感和操作性能。

方法详解

本文提出的多视图3D临场感系统整体框架是一个“领导者-跟随者”遥操作设置，包含感知、处理和呈现三个主要阶段。

图1：领导者-跟随者遥操作系统。一个Panda机械臂作为领导者，在重力补偿模式下被物理引导；第二个机械臂作为跟随者在任务工作空间中执行动作。工作空间由三个静态RGB-D相机（左、右、上方）和一个腕部安装的RGB-D相机观察。参与者佩戴Meta Quest 3头显，体验四种可视化条件之一。

系统硬件与数据流：系统使用两个相同的Franka Emika Panda机械臂。操作员通过物理引导处于重力补偿模式的“领导者”臂来直接控制“跟随者”臂进行镜像运动。工作空间由三个静态安装的Intel RealSense D415 RGB-D相机（左、右、上方）和一个安装在机器人腕部的Intel RealSense D435 RGB-D相机覆盖。一台桌面PC收集所有四个相机的同步数据流，运行感知管道生成融合的过滤点云，并通过WiFi将点云数据包发送到Meta Quest 3头显。头显上的Unity应用程序使用GPU着色器和实例化渲染进行实时点云重建与呈现。

点云生成与融合核心模块：这是系统的核心创新之一。对于每一帧，系统同步捕获三个静态相机的RGB和深度图像。首先，每个RGB图像通过一个在自定义数据集上训练的YOLOv11分割模型进行处理，以检测和分割机器人、夹爪、腕部相机支架和桌子，生成这些类别的像素级掩码。然后，仅对未被掩码的像素，通过相机内参反投影深度图像生成3D点，并为每个点分配对应的RGB颜色。这种语义过滤有两个目的：1）机器人本体和夹爪已在Unity中通过URDF模型精确渲染，避免点云冗余并节省有限的点预算；2）移除桌子和机器人结构减少了视觉杂乱，使剩余的点能聚焦于任务相关的物体、边缘和接触区域。接着，每个相机的点云使用预先估计的外参标定矩阵变换到机器人基坐标系下，并合并成一个全局点云。该点云随后被一个轴对齐的3D边界框裁剪，仅保留桌面和任务物体区域内的点。最后，为了满足Meta Quest 3的渲染约束，应用了体素网格下采样和统计离群点去除滤波。该管道在配备NVIDIA RTX 3060 GPU的PC上运行，最终生成包含约75,000个彩色点的过滤点云，更新频率为10 Hz。与先前工作相比，这种基于设备端GPU的渲染使得在相同帧率限制下能够可视化更密集的点云。

可视化模态：系统支持并比较了四种不同的可视化模态。

图2：VR遥操作研究中评估的可视化模态，以杯子插入任务为例展示。从左到右：(a) RGBs：四个虚拟屏幕显示左、右、顶部和腕部RGB流；(b) PC：语义过滤的融合点云与领导者臂模型一起渲染；(c) PC+RGB：相同的融合点云，并附加了一个刚体连接到末端执行器的腕部RGB视图。洋红色插图显示了该腕部RGB流的放大裁剪区域，突出了可用的高分辨率局部细节；(d) OT：基于OpenTeleVision设置的以自我为中心的立体视图。

  1. 四路RGB流：用户在VR中看到四个高分辨率RGB流（左、右、顶部、腕部）以虚拟浮动屏幕形式排列。它提供多角度的清晰纹理和边缘线索，但仅提供单目深度线索，没有明确的3D场景结构。
  2. 融合点云：仅渲染来自三个RGB-D相机的语义过滤点云，在VR中与物理工作空间对齐。机器人和夹爪显示为URDF模型。该视图提供了连贯的3D结构，便于从任意角度评估空间关系，但深度感知噪声、有限的点预算和下采样会降低精细纹理细节和边缘清晰度。
  3. 点云加腕部RGB：将融合点云的全局空间上下文与腕部RGB流的精细细节相结合。在虚拟末端执行器附近的一个浮动窗口显示腕部安装的RGB视图。这种混合设置同时支持全局3D理解和局部高分辨率感知。
  4. OpenTeleVision：基于OpenTeleVision，显示一个安装在跟随机器人上方的ZED Mini立体相机提供的立体RGB视图。用户从跟随者的视角看到沉浸式的第一人称视频，但缺乏对自己手臂的直接视觉反馈或明确的3D结构。

与现有方法相比，本文的创新点具体体现在：1）提出了一种结合全局（多视图融合点云）与局部（腕部RGB）信息的混合可视化策略；2）实现了基于GPU加速的实时点云渲染，在独立VR头显上达到了约75k点的渲染密度；3）首次在控制接口固定的前提下，系统性地比较了四种主流可视化模态（RGBs、PC、PC+RGB、OT）在多种操作任务中的性能。

实验与结果

实验设置：研究在一个统一的实验框架下进行，使用了三个具有代表性的遥操作任务：杯子插入、T形块堆叠和线环放置。实验平台包括两个Franka Emika Panda机械臂、四个Intel RealSense RGB-D相机和Meta Quest 3 VR头显。

对比方法：系统比较了四种可视化模态：四路RGB流、融合点云、点云加腕部RGB以及OpenTeleVision。

关键实验结果：
研究对31名参与者进行了受试者内实验，测量了任务成功率、完成时间、感知工作负荷和系统可用性。

图5：四种可视化条件下NASA-TLX六个维度的箱线图。更高的值表示更高的主观工作负荷。星号表示统计显著性水平。结果显示，所有NASA-TLX维度在不同可视化条件间均存在显著差异。RGBs通常引发更高的精神和时间需求，而PC和PC+RGB往往产生较低的努力和挫败感评分。

图6：四种可视化条件下VR可用性评分（有效性、效率、满意度）的箱线图。星号表示基于校正后的Wilcoxon检验的显著成对差异。分析显示，可视化条件对所有三个可用性维度均有显著影响。PC和PC+RGB在效率和满意度上通常评分高于RGBs和OT。

图7：参与者对四种可视化方法在所有偏好等级上的主观偏好排名分布。PC+RGB最常被选为第一偏好，其次是PC，OT被少数参与者选为最不喜欢的选项。

图8：不同可视化条件下的任务性能。左图：每个任务的平均完成时间。右图：每个任务的成功率。星号表示显著的成对差异。PC+RGB实现了最高的成功率（接近100%），并获得了最快的平均完成时间。纯点云也表现优异。RGBs的成功率最低，且完成时间显著慢于基于深度的条件。

结果总结：在所有指标上，基于点云的条件（PC和PC+RGB）明显优于纯RGB界面。PC+RGB在性能（成功率和完成时间）和主观体验（工作负荷、可用性、用户偏好）上均表现最佳。纯点云紧随其后。RGBs和OT则表现较差。这表明，结合全局3D结构和局部高分辨率细节能显著提升VR遥操作的临场感和操作性能。

总结与启发

核心贡献：

  1. 提出并实现了一个GPU加速的多视图3D临场感系统，该系统创新性地融合了来自多个静态相机的语义过滤点云（提供全局3D结构）与腕部安装的高分辨率RGB流（提供局部精细细节）。
  2. 设计并执行了一个系统的受试者内研究，在相同的遥操作设置下，首次直接比较了四种主要的可视化模态（RGBs、PC、PC+RGB、OT）在三种不同操作任务中的表现。
  3. 提供了全面的实证证据，表明结合动觉教学式的视觉-运动共定位与明确的3D场景表示（如点云）能显著降低操作员工作负荷、提高任务成功率和系统可用性，而单纯的沉浸式RGB视图（即使是立体的）或分散的多屏视图则效果不佳。

局限性：
论文自身提到的局限性包括：点云质量受限于传感和处理管道（依赖于特定型号的RealSense相机、YOLOv11分割精度以及在Meta Quest 3上的严格点预算）；系统对网络延迟敏感，所有处理均在本地网络进行，未测试广域网性能；实验任务虽然具有代表性，但仅限于桌面操作场景，未涵盖更复杂的移动操作或动态环境。

对后续研究的启示：
本研究为下一代机器人遥操作系统的可视化设计提供了明确指导：应优先考虑提供稳定、连贯的3D空间表示，并辅以焦点区域的高分辨率细节。未来的工作可以探索更先进的场景表示（如神经辐射场）在实时性约束下的应用，研究动态环境或移动基座下的可视化策略，以及进一步量化不同可视化元素（如点密度、颜色信息、局部视图的呈现方式）对操作性能的具体影响。

💡 一句话总结

本文针对XR机器人遥操作中传统界面缺乏可靠深度线索、全局场景理解与局部高分辨率细节难以兼顾的核心问题，提出一种多视图VR远程呈现系统。关键技术包括融合三个摄像头几何信息实现GPU加速的点云实时渲染，并集成手腕RGB流以补充局部精细视觉。在31名参与者的实验中，该系统在多项遥操作任务中取得最佳整体性能，证实结合全局3D结构与局部高分辨率细节能显著提升操作员的感知与操纵效果。
