IMPACT-HOI: Supervisory Control for Onset-Anchored Partial HOI Event Construction

arXiv: 2605.01666 作者: Rainer Stiefelhagen Team 日期: 2026-05-03

📝 详细解读

研究背景与动机

当前，从人类演示中学习机器人操作依赖于对视频中人与物体交互（HOI）进行高质量、结构化的标注。现有主流方法存在明显局限：端到端的HOI检测器（如[12, 28, 13]）假设输入输出都是完整的，无法处理部分指定的事件状态，也缺乏人工监督的整合；而通用视频标注平台（如CVAT[3]和VIA[7]）则未优先处理未解析的字段，也无法保护已确认的决策不被后续自动化修改。核心挑战在于，HOI事件记录包含相互依赖的字段（如时间边界、语义动词、工具角色、目标角色），其解析成本和验证风险各不相同。顺序标注在密集的双手交互中效率低下且脆弱，一个字段的错误确认可能导致错误在整个事件中传播。

本文针对结构化HOI标注中人机协同构建的痛点，提出了一个新视角：将标注任务重新定义为在部分可观测和不对称权威下的可控人机协同构建问题，而非单纯的识别问题。核心思路是设计一个混合主动的监督控制框架（IMPACT-HOI），它将标注视为对一个部分指定的、以起始点为锚点的事件状态进行增量解析，并通过信任校准的控制器和风险有界的执行协议，在提升效率的同时确保人工确认决策的安全性。

方法详解

IMPACT-HOI的整体框架是一个闭环的人机监督循环。系统从一个部分指定的事件状态和视频证据开始，通过锁感知部分事件完成（LPEC）模块解析开放字段，该模块联合预测起始点和语义信息，并利用统计引导的协同优化（SCR）确保跨字段一致性，同时在人机确认的“锁”约束下进行解码。信任校准的监督控制器（TSC）根据经验校准的接受度和成本信号，对候选干预措施（直接查询、人工确认建议、保守自动完成）进行排序和选择。人类响应和记录的行为轨迹反馈到事件状态和控制器中，形成闭环。

图1：IMPACT-HOI方法整体框架。系统起始于一个部分事件状态和视频证据。锁感知部分事件完成（LPEC）模块通过联合起始点与语义预测来解析开放字段，并利用统计引导的协同优化（SCR）和在人工确认锁约束下的重新解码进行优化。信任校准的监督控制器（TSC）选择行动，要么引导人工响应，要么应用安全的自动更新。人工响应和记录的行为轨迹反馈到事件状态和控制器，形成一个闭环的标注循环。

核心模块包括：

  1. 问题形式化与部分事件状态：系统为每只手维护一个运行时状态 (x_h = (\tilde{e}_h, \sigma_h, \rho_h))，其中 (\tilde{e}_h) 存储当前事件字段值（起始时间 (t_s)、功能性接触起始点 (t_o)、结束时间 (t_e)、动词 (v)、名词 (n)），(\sigma_h) 存储每个字段的状态（空、建议、已确认），(\rho_h) 存储来源和锁元数据。LPEC的目标是仅解析仍开放的组件 (y_h = (t_o, v, b, n))（(b)为名词存在指示器），同时保留所有已确认的决策。

  2. 手引导的起始点先验（HOP）：该模块利用选定手部的轨迹信息，为当前事件区间生成一个结构化的时间先验，而非单一的运动峰值。它首先从无引导的视频摘要中推导出一个粗略的语义先验（动词假设 ( \hat{v}_h ) 及其相位族 ( g_h )），然后根据相位族模板在区间内搜索相位一致的起始点候选（如边界对齐起点、局部运动峰值、低运动接触谷值、稳定段起点）。每个候选 (c) 通过一个评分函数 (s_h(c)) 进行评估，该函数结合了相位兼容性、与模板位置 (t_h^\star) 的接近度、局部运动证据以及候选点前后的短时域支持。最终选出的候选 (c_h^\star) 及其可靠性评分 (\kappa_h) 构成起始点先验 (\pi_h = (\hat{t}_o, B_h, \kappa_h))，其中 (B_h) 是诱导出的起始点频带，用于约束下游完成模块的局部时间窗口。

  3. 事件局部起始点-语义完成模块：这是一个轻量级的适配器网络 (f_\theta)，它将部分事件状态特征 (r_h) 映射到起始点和语义的分数参数 ((μ_o, σ_o^2, ℓ_o, ℓ_v, ℓ_b, ℓ_n))。起始点和语义是从相同的部分状态表示中联合预测的，而非独立模块。

  4. 统计引导的协同优化（SCR）：这是一个确定性的后处理算子 (\mathcal{R})，它利用从交互历史中积累的统计信息包 (S)（包括动词条件/名词条件的起始点先验、动词-名词共现率、动词特定的无名词倾向），对适配器的原始输出分数 ((ℓ_o, ℓ_v, ℓ_b, ℓ_n)) 进行重新加权和混合，然后按依赖顺序（名词存在、名词、动词、起始点）进行归一化，得到优化后的分数 ((\tilde{ℓ}_o, \tilde{ℓ}_v, \tilde{ℓ}_b, \tilde{ℓ}_n))。随后，系统通过一个特征反馈重新解码步骤，将首次解码的假设 ( \hat{y}_h^{(1)} ) 写回特征中，并再次应用适配器，生成第二组分数用于二次解码 ( \hat{y}_h^{(2)} )，仅当后者能提高结构化联合分数时才被接受，以此实现一致性校正。

  5. 人工锁定的钳位与重新解码：为确保人工确认的字段在任何后续自动刷新中保持不变，解码过程被约束在一个可行集 (\mathcal{Y}_h) 内，该集合将所有锁定的变量钳位到其确认值，并强制满足本体论有效性（如动词-名词有效性）。解码目标是在 (\mathcal{Y}_h) 内最大化结构化联合评分 (\mathcal{J}_h(y))。

  6. 信任校准的监督控制器（TSC）：该控制器基于一个聚合了字段完成状态、证据缺口、建议来源、解码置信度摘要和覆盖风险上下文的控制状态 (c_h) 进行操作。它为每个候选干预措施 (\xi) 估算传播增益 (P(\xi; c_h))、交互成本 (C(\xi; c_h)) 和覆盖风险 (R(\xi; c_h))，并利用从先前交互历史收集的经验统计数据进行校准。候选干预根据评分函数 (S(\xi; c_h)) 进行排序，该函数权衡即时效用、校准后的传播增益、成本和风险。控制器最终从符合锁约束和当前权威策略的可执行集合 (\mathcal{Q}_{\mathrm{safe}}(c_h)) 中选择评分最高的干预 (\xi_h^\star) 执行，从而动态决定是直接询问、建议确认还是安全地自动完成。

与现有方法相比，IMPACT-HOI的创新点在于：1）将HOI标注重新定义为锁感知的部分事件完成（LPEC）问题，系统性地处理部分状态并保护已确认决策；2）提出了手引导的起始点先验（HOP）和事件局部联合完成模块，将语义与更精确的时间定位相结合；3）设计了信任校准的监督控制器（TSC），根据证据质量和历史行为动态分配机器权威级别（仅人工、人工确认、安全局部），实现人机责任的优化分配。

实验与结果

实验在从工业装配数据集中精选的以自我为中心的程序性HOI视频片段上进行。采用了9名参与者的受试者内用户研究，比较了手动标注（Manual）和全辅助模式（Full Assist）两种条件。主要对比了标注效率和最终事件质量，并深入分析了监督控制器的行为与安全性。

关键实验结果如下：

  • 效率与质量：全辅助模式将每个事件所需的人工操作从13.33次减少到11.53次（减少13.5%），表明系统将标注者从重复的低级编辑转向高级决策。虽然总标注时间从80.13秒略微增加到90.40秒，但完整事件匹配率从42.22%提升至46.67%。起始点误差从7.06帧略微增加到9.14帧，但事件级整体正确性的提升表明全局一致性的益处超过了微小的时间偏差。

**图2(a)**：展示了手动与全辅助模式在效率和最终事件质量上的对比。全辅助模式减少了每个事件的人工操作数，同时提高了完整事件匹配率。

  • 监督行为与安全性：在全辅助模式下，控制器生成了515条建议，其中95条被直接接受（接受率18.4%），172条建议在被接受后又被用户进一步细化（再加工率33.4%）。在总共616次操作中，436次（70.8%）以“人工确认”模式执行，180次（29.2%）为“仅人工”模式。最关键的是，在整个研究过程中记录了零次已确认字段违规，证明了其执行协议的安全性。

**图2(b)**：展示了监督控制器的行为与安全性结果，包括建议效用、权威分配以及零确认字段违规的安全记录。

  • 主观工作负荷：通过NASA-TLX量表评估，全辅助模式在六个维度（心理需求、体力需求、时间需求、表现、努力、挫折）上呈现出更平衡、更小面积的工作负荷轮廓，表明人机协作的工作流程减轻了用户的整体负担。

**图2(c)**：比较了手动与全辅助模式下用户的主观工作负荷。雷达图显示，全辅助模式在大多数维度上需求更低，封闭面积更小，表明协作工作流更均衡。

消融研究采用“顺序Oracle校正协议”进行评估。结果表明，当系统依次预测起始点、动词和名词，并在预测错误时由Oracle校正并锁定该字段后，系统重新解码剩余字段的完整事件匹配率达到68.89%，显著高于基线（无HOP和SCR）的53.33%和仅使用HOP的60.00%。这验证了HOP和SCR组件对于在部分状态约束下实现高质量完成的有效性。

总结与启发

本文的核心贡献包括：1）提出了一个以起始点为锚点的事件局部完成流程，通过手引导的起始点先验（HOP）和共享完成模块，从部分状态和视觉线索中联合解析起始点与事件语义；2）设计了统计引导的一致性优化（SCR），利用先验、共现统计和动词特定倾向来提升跨字段预测的一致性；3）开发了用于混合主动标注的信任校准监督控制器（TSC），能根据经验校准的信号对干预措施进行排序和权威分配，在研究的协议下实现了人工操作减少13.5%、事件匹配率46.67%且零确认字段违规。

论文自身提到的局限性在于，用户研究是在相对清晰、以单主动手交互为主的剪辑上进行的，在密集双手交互、模糊动作边界或存在大量遮挡的场景下，系统的表现和效率增益需要进一步验证。

这项工作对后续研究的启示在于：将结构化事件构建视为一个人机协同的监督控制问题而非单纯的感知问题，是一个富有前景的方向。其“锁感知”的解码和“风险有界”的执行协议为开发安全、可信的人机协作AI系统提供了关键机制。未来工作可以探索如何将该框架扩展到更复杂、动态的交互场景，并研究控制器在线从用户反馈中持续学习和校准的策略。

💡 一句话总结

本文提出IMPACT-HOI框架，旨在解决从自我中心视角视频中高效、准确构建结构化人-物交互事件标注的难题。核心方法是采用**锁定感知的部分事件完成**策略，通过一个**信任校准的控制器**动态选择直接询问、建议或自动补全，并利用**风险受限的执行协议**（含原子回滚）保护已确认的标注。实验表明，该方法在用户研究中减少了13.5%的手动操作，事件匹配率达46.67%，且实现了零确认字段违规。
