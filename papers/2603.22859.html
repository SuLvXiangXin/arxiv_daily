DecompGrind: A Decomposition Framework for Robotic Grinding via Cutting-Surface Planning and Contact-Force Adaptation

arXiv: 2603.22859 作者: Takamitsu Masubara Team 日期: 2026-03-24

📝 详细解读

研究背景与动机

机器人打磨在制造业中广泛用于工件成型，但实现高效自动化仍然困难。主要挑战在于去除阻力随局部接触条件（如工件形状、材料硬度、接触状态）变化，难以准确估计和建模。现有方法主要分为两类：基于几何的形状过渡建模方法和基于数据驱动的学习方法。几何方法能有效建模形状演变，但难以适应变化的接触条件和材料硬度下的力控制。数据驱动方法（如强化学习、模仿学习）虽能基于力反馈适应接触力，但通常需要大量训练数据来学习整个形状演变和长时程打磨动作，而在不可逆的材料去除过程中收集大量真实数据成本高昂。因此，降低学习复杂度是实现实用机器人打磨系统的关键。

本文针对上述“高效打磨需适应多样工件与材料，但联合学习形状过渡与力适应需要大量数据”的痛点，提出了一个分解问题的新视角：将打磨过程解耦为全局去除形状规划和局部接触力适应两个子问题。核心思路是：全局形状规划通过当前与目标形状的几何分析无学习地确定去除区域，而学习仅用于每个局部去除区域的接触力适应策略，从而将长时程成型问题转化为可从少量演示中学习的短时程力适应问题。

方法详解

DecompGrind框架的核心是将打磨任务分解为两个层次：在规划步k进行的全局切割面规划和在时间步t进行的局部接触力适应。

图4：DecompGrind框架总览。根据当前形状与目标形状规划切割面，机器人据此设定初始位置，然后使用学习到的LCFA策略打磨由GCSP定义的去除区域，直至接触面到达目标切割面。随后重新观察形状并规划下一个切割面，循环直至达到目标形状。

1. 全局切割面规划
GCSP模块负责根据当前形状O_k和目标形状O_target，确定一个最优切割面c_k*，该切割面几何地将当前形状分割为下一个（剩余）形状O_{k+1}和待去除形状r_{k+1}。其基础是几何切割模型：O_{k+1} = G_O(O_k, c_k), r_{k+1} = G_r(O_k, c_k)。G_O和G_r函数通过碰撞检测进行几何分割，无需学习。

图2：切割面模型示意图。切割面c_k作为几何边界，将当前形状O_k分割为下一个形状O_{k+1}和去除形状r_{k+1}。

GCSP采用模型预测控制框架，优化未来H步内的切割面序列，以最小化包含目标形状误差和去除形状成本的综合代价函数。确定切割面后，通过逆映射Γ_sur^{-1}(c_k)计算出对应的机器人初始状态x_init^f，引导机器人就位。

2. 局部接触力适应
LCFA模块负责在GCSP规划的单个去除形状r_{k+1}上进行打磨，其目标是控制机器人施加的法向力，以适应变化的去除阻力（主要表现为切向力）。打磨持续进行，直到工件与砂带的接触面c_t_con（由Γ_sur(x_t^f)计算）与目标切割面c_k*的距离小于阈值ε。

LCFA的策略通过双边控制模仿学习（BCIL）从少量演示中学习。BCIL框架包含三个阶段：

  • 演示：操作者操纵主端机器人，从端机器人通过双边控制执行任务，同时记录机器人状态（位置、速度、力）作为训练数据。双边控制的目标是实现主从端位置同步与力平衡（x_t^l - x_t^f = 0, F_t^l + F_t^f = 0），使操作者能感知触觉反馈。
  • 训练：使用收集的数据训练策略π_w，该策略根据从端当前接触状态z_t^f，预测下一时刻主端的接触状态z_{t+1}^l。
  • 执行：用学习到的策略π_w替代真实的主端操作者，与从端构成闭环，使机器人能复现演示者的接触力适应行为。

图3：双边控制模仿学习框架。演示阶段通过双边控制收集数据；训练阶段学习从从端状态预测主端状态的策略；执行阶段用学习到的策略替代主端，控制从端执行任务。

创新点：与需要为整个复杂任务学习长序列策略的现有BCIL方法不同，DecompGrind通过GCSP将任务分解为多个局部打磨子任务。LCFA只需学习这些局部子任务（时间跨度短、状态空间受限）的力适应策略，从而显著降低了对演示数据量的需求，实现了小样本学习。

实验与结果

实验设置：使用真实的机器人打磨系统（配备力/扭矩传感器和3D视觉传感器）和3D打印的工作件（PLA和ABS材料，硬度不同）进行实验。目标是将初始圆柱体工件打磨成目标形状（如长方体、斜面体）。

对比方法：

  1. **GCM (Geometric Cutting Model)**：仅使用几何切割模型进行路径规划，施加恒定的法向力。
  2. **BCIL (Bilateral Control-based Imitation Learning)**：标准的双边控制模仿学习，直接学习从初始形状到目标形状的完整打磨策略。
  3. Manual：熟练操作者手动完成打磨。
  4. **DecompGrind (Ours)**：本文提出的方法。

关键实验结果：

图5：不同方法在PLA材料工件上的打磨结果对比。DecompGrind在加工时间和最大法向力之间取得了最佳平衡，接近手动操作水平。

  • 加工效率与安全性：在PLA材料实验中，DecompGrind的加工时间（148.5秒）远低于GCM（210.8秒）和BCIL（193.2秒），接近手动操作（141.1秒）。同时，其最大法向力（10.6 N）显著低于GCM（18.7 N）和BCIL（14.8 N），与手动（10.4 N）相当，表明其在提升效率的同时保证了安全。
  • 形状精度：DecompGrind的最终形状误差（1.12 mm）小于GCM（1.31 mm）和BCIL（1.28 mm），略高于手动（0.98 mm）。
  • 泛化能力：在未训练过的ABS（更硬）材料工件上测试，DecompGrind仍能成功完成任务，加工时间（165.0秒）和最大法向力（12.3 N）均显著优于GCM（时间240.0秒，力22.5 N）和BCIL（时间210.0秒，力18.9 N），证明了其对不同材料硬度的适应性。

图6：消融实验结果。对比了完整DecompGrind与其变体（仅GCSP、仅LCFA）以及不同演示数据量下的性能。完整方法性能最优，且仅需5-10次演示即可达到良好性能。

消融实验：

  • 组件贡献：对比了完整DecompGrind、仅使用GCSP（恒力）、仅使用LCFA（无规划，在初始形状上学习）。结果表明，二者缺一不可。仅GCSP因恒力导致效率低下或力过大；仅LCFA无法完成全局形状塑造任务。
  • 数据效率：研究了LCFA策略学习所需演示数据量。结果显示，仅需5-10次在简单形状（如方块）上的演示，学得的策略就能有效泛化到更复杂的全局形状打磨中，验证了分解框架在小样本学习上的优势。

总结与启发

核心贡献：

  1. 提出了分解框架：将机器人打磨自动化分解为全局去除形状规划（GCSP）和局部接触力适应（LCFA）两个子问题，将长时程、高维度的学习问题转化为可从小样本数据中学习的局部力适应问题。
  2. 实现了方法集成：提出了DecompGrind，集成基于几何分析的GCSP和基于双边控制模仿学习的LCFA，实现了在有限训练数据下对不同形状和材料硬度工件的高效、安全打磨。
  3. 完成了实物验证：在真实机器人系统上验证了方法的有效性，展示了其优于纯几何或纯学习基线方法的性能。

局限性：论文指出，该方法性能依赖于特定的打磨条件（如砂带类型、速度）。若遇到阻力条件（如材料特性）差异极大的情况，可能需要进行额外的演示来重新训练或调整LCFA策略。

对后续研究的启示：

  1. 问题分解思路：为其他复杂的、涉及几何变化与物理交互的机器人操作任务（如抛光、去毛刺、装配）提供了一种通用的系统设计范式，即通过几何或解析方法处理全局状态演变，而仅对局部交互进行数据驱动学习。
  2. 小样本学习：证明了通过精心设计的问题分解，可以极大降低接触式操作任务中对大量、昂贵演示数据的依赖，提高了学习方法的实用性。
  3. 仿真到实物的迁移：当前方法仍需在真实系统上收集演示数据。未来可探索如何在仿真中生成有效的局部接触力适应演示，或利用仿真数据预训练，再通过少量真实数据微调，进一步降低部署成本。

💡 一句话总结

论文针对机器人研磨自动化中，因工件形状和材料硬度多样导致去除阻力变化、传统方法需大量训练数据的问题，提出分解框架DecompGrind。该框架将研磨分解为全局切割表面规划（GCSP）和局部接触力适应（LCFA）：GCSP通过几何分析当前与目标形状规划去除区域，无需学习；LCFA基于双边控制的模仿学习，从小样本演示中学习接触力适应策略。实验使用机器人研磨系统和3D打印工件，证明该方法能高效研磨不同形状和材料硬度的工件，同时保持安全的接触力水平。
