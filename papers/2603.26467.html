Addressing Ambiguity in Imitation Learning through Product of Experts based Negative Feedback

arXiv: 2603.26467 作者: Jihong Zhu Team 日期: 2026-03-27

📝 详细解读

研究背景与动机

模仿学习通过人类演示来训练机器人执行任务，但主流方法通常假设演示数据来自单一、高度专业的专家。然而，在家庭辅助机器人等实际应用中，演示者可能是非专业的用户，其演示数据往往是次优的甚至包含失败的尝试。现有方法在处理多专家数据时效果不佳，因为来自不同演示者的数据会引入任务执行的模糊性，导致学习到的策略平均化不同行为而产生失败。此外，传统的模仿学习系统通常将失败的运行轨迹丢弃，未能从中提取有价值的信息。本文针对模仿学习中由任务模糊性导致的策略失败问题，以及如何有效利用失败演示数据这一痛点，提出了一种基于专家乘积的负反馈学习新视角。其核心思路是：从失败的运行轨迹中学习“规避策略”，并通过专家乘积的方式将其与正向策略结合，从而系统性地抑制导致失败的行为区域，逐步提升任务成功率。

方法详解

本文提出的方法是一个迭代式的负反馈学习框架，旨在利用自身的失败经验来改进策略。其核心是利用专家乘积方法，将从失败轨迹中学到的局部规避策略与基础的正向策略相结合。

图1：模仿学习中的模糊性问题示意。两条蓝色线代表两种成功的演示（绕过障碍物），但通过简单平均学习到的绿色轨迹（中间）却会与障碍物碰撞，这说明了多专家数据带来的模糊性挑战。

整体流程如算法1所示：首先，收集一组正向演示 ( \underline{D} ) 并学习初始策略 ( \underline{\pi} )；然后，使用该策略生成一条轨迹 ( t_i )；如果 ( t_i ) 失败，则将其视为负向演示数据集 ( \underline{D}{Ni} )，并从中学习一个规避策略 ( \underline{\pi}{\alpha} )；接着，通过公式 ( \underline{\pi} = (U - \mu \cdot \underline{\pi}_{\alpha}) \cdot \underline{\pi} ) 更新策略，其中 ( U ) 是均匀分布，( \mu ) 是一个掩码；最后对更新后的策略进行归一化，并生成下一条轨迹。此过程循环直至成功。

该方法的核心创新在于两个关键模块：

  1. 基于专家乘积的负反馈融合：这是最主要的创新点。与常见的混合专家方法（加权求和）不同，本文采用乘积专家方法将规避策略 ( \pi_{\alpha} ) 与正向策略结合。其公式为 ( \pi^{*} \propto (U - \mu \cdot \pi_{\alpha}) \cdot \sum \pi_{m} )。乘积操作的优势在于，只要 ( \pi_{\alpha} ) 在某个行为区域赋予低概率（即希望规避），整个联合策略在该区域的概率就会被显著压低，从而实现对失败行为的精准抑制，而对其他区域影响最小。
  2. 基于共识的轨迹区域选择（掩码机制）：为了避免负反馈错误地抑制所有成功轨迹共有的必要行为（如起点和终点附近），算法引入了一个自动选择机制来构建掩码 ( \mu )。该机制将状态空间离散化，统计每个离散单元被成功演示轨迹穿过的次数 ( N_t )。如果 ( N_t ) 超过一个阈值 ( N_{threshold} )（例如50%的轨迹），则认为该区域是共识区域，将掩码值设为0以保护该区域不受负反馈影响；否则设为1，允许负反馈修改。

图2：针对障碍物规避任务构建的掩码 ( \mu ) 示意图。白色区域（值为0）是超过阈值数量的成功轨迹共同穿过的区域（如障碍物上方和下方的路径），受到保护；蓝色区域（值为1）是轨迹较分散的区域，允许施加负反馈；红色代表障碍物。

与现有方法相比，本文的创新具体体现在：1) 首次将乘积专家方法系统性地用于模仿学习的负反馈循环中，实现了高效且精准的行为抑制；2) 提出了一个自动化的、基于轨迹共识的掩码生成方法，防止负反馈破坏必要的任务结构；3) 整个框架是增量式的，每次只需从单次失败中学习一个轻量的规避策略，无需保存所有历史失败数据，提高了时间和内存效率。

实验与结果

实验在模拟环境和真实机器人平台上进行，使用了三个基准任务：1) 简单模糊任务：一个二维点到达任务，障碍物在中间，成功路径有“从上过”和“从下过”两种（模糊度A=2）。2) 绕桩任务：一个更复杂的二维导航任务，存在多条可行路径（最多25种组合，模糊度高）。3) 真实机器人拾放任务：使用Franka Emika机械臂在三维空间中进行拾放，障碍物阻挡直线路径，存在左、右、上三种绕行方式（A=3）。对比的基线方法包括：无负反馈的行为克隆、使用负权重的方法、以及使用混合专家进行负反馈融合的方法。

图4：简单模糊任务中，三种负反馈方法随反馈周期增加的成功率变化。本文提出的乘积专家方法（红线）成功率提升最快，最终达到接近100%，显著优于混合专家（蓝线）和负权重方法（绿线）。

图5：在简单任务上比较不同轨迹选择方法对负反馈效果的影响。“无选择”效果最差；“中心轨迹”法（丢弃首尾段）有提升；本文提出的掩码法（50%阈值）效果最佳，证明了基于共识的区域选择的重要性。

图7：在高模糊度的绕桩任务上，三种负反馈方法的成功率。乘积专家方法（红线）依然表现最好，在3次反馈后成功率从约10%提升至50%，但整体提升速度慢于简单任务，说明任务模糊性增加了学习难度。

图8：绕桩任务上不同掩码阈值的比较。50%阈值（橙色）的掩码方法依然表现最稳定和有效，优于25%、75%阈值以及中心轨迹法。

图10：在真实机器人拾放任务上，三种负反馈方法的表现。乘积专家方法（红线）同样展现出最快的成功率提升，例如在3次演示条件下，经过几次负反馈循环，成功率从30%提升至80%。

关键实验结果总结：在简单模糊任务中，本文方法相比无负反馈系统取得了90%的成功率提升（模拟数据）。在真实机器人实验中，取得了50%的成功率提升。在所有任务中，本文提出的乘积专家负反馈方法在提升速度和最终性能上均优于混合专家和负权重方法。消融实验表明，50%阈值的掩码机制是最有效的轨迹区域选择策略。实验还观察到，在绕桩任务中，系统有时能通过负反馈探索出从未被演示过的成功路径（如从中间缝隙穿过），展示了其从纯次优演示中学习的能力。

总结与启发

本文的核心贡献在于：1) 提出了一个基于专家乘积的负反馈学习框架，能够高效地从失败中学习，显著提升在模糊性任务上的成功率；2) 设计了一种基于成功轨迹共识的自动掩码机制，防止负反馈破坏任务的基本结构；3) 通过模拟和真实机器人实验验证了方法的有效性、数据效率和时效性。

论文自身提到的局限性包括：掩码阈值 ( N_{threshold} ) 需要根据任务先验进行选择；方法在非常高维的状态空间中的可扩展性尚未验证；对于效率优势（时间和内存）的理论分析尚未通过大规模实验充分验证。

这项工作对后续研究的启示包括：为从非专业、多来源的演示数据中学习提供了新思路，特别是在人机交互和辅助机器人场景下；将负反馈与乘积专家结合的思想可以扩展到其他需要从错误中学习的序列决策问题；如何自适应地确定掩码阈值或设计更智能的区域选择机制，是未来一个有价值的研究方向。

💡 一句话总结

本文针对模仿学习中因非最优演示数据导致的歧义性问题，提出基于Product of Experts的负反馈方法。该方法通过负反馈机制从自身失败中学习，优化策略以处理模糊任务。实验表明，在模拟任务中，相比无负反馈系统成功率提升90%；在真实机器人上，成功率提升50%，并展现出更高的效能、内存效率和时间效率。
