SoftMimicGen: A Data Generation System for Scalable Robot Learning in Deformable Object Manipulation

arXiv: 2603.25725 作者: Ajay Mandlekar Team 日期: 2026-03-26

📝 详细解读

研究背景与动机

当前机器人学习，特别是机器人基础模型的发展，严重依赖于大规模机器人操作数据集的支撑。这些数据集主要通过耗时费力的人工遥操作收集，成本高昂且难以扩展。仿真与合成数据生成已成为一种有前景的替代方案，能够大幅减少对真实世界数据的需求，并促进对未见场景的泛化。然而，这一范式主要局限于易于仿真的刚性物体操作任务。可变形物体（如布料、绳索、软体）操作在现实世界中占据很大比重，却因其仿真和数据生成的复杂性而成为该范式应用的关键缺口。本文针对可变形物体缺乏静态参考坐标系、难以直接套用现有基于刚体假设的数据生成方法（如MimicGen）这一具体痛点，提出利用非刚性配准技术来建立变形物体状态间的对应关系，从而自适应地变换源演示轨迹。其核心思路是：基于少量人类演示，通过非刚性配准计算源场景与目标场景中可变形物体几何形态之间的连续变形场，并利用该场对机器人末端轨迹进行空间变换，从而自动化生成大规模、多样化的演示数据。

方法详解

SoftMimicGen的整体流程是一个自动化的数据生成管道。输入是少量（1-10条）人类遥操作演示组成的源数据集，以及一个定义了更广初始状态分布的新任务场景。输出是成功执行并记录的大规模生成数据集。其核心在于如何为每个待执行的子任务，从源数据中选择合适的演示片段，并将其适配到当前可变形物体的新状态中。

图1：SoftMimicGen系统流程。（左）人类遥操作演示被分割成以物体为中心的子任务，形成源片段库。（右）给定一个新的目标场景，SoftMimicGen (i) 观察当前可变形物体状态，(ii) 执行非刚性配准以建立源与目标几何之间的对应关系和变形场，(iii) 选择配准成本最低的源片段，并将得到的变形场应用于末端执行器轨迹（浅色箭头为源轨迹，深色箭头为变形后轨迹），(iv) 在目标环境中执行变形后的轨迹。

核心模块与技术细节：

  1. 可变形物体表示：假设每个可变形物体由一组三维节点位置表示，即 $O = {\mathbf{n_i}}_{i=1}^{N_O}$，其中 $\mathbf{n_i} \in \mathbb{R}^3$。这本质上是物体的点云表示，刚性物体也可用此方式表示，使得方法具有通用性。
  2. 源演示选择：对于当前子任务，首先观察目标场景中相关物体的节点集合 $O_i'$。然后，将其与源数据集中每个对应子任务片段的初始物体状态 $O_i$ 进行非刚性配准。通过比较配准优化后的成本（如点间距离与平滑性正则项之和），选择成本最低的源片段。这替代了MimicGen中基于物体位姿距离的最近邻选择策略，以适应可变形物体的高维连续状态空间。
  3. 轨迹自适应（核心创新）：选定源片段 $\tau_i = (T_W^{C_0}, T_W^{C_1}, ..., T_W^{C_K})$ 后，关键步骤是利用非刚性配准计算出的连续变形场 $\mathbf{f}(\cdot): \mathbb{R}^3 \rightarrow \mathbb{R}^3$ 来变换轨迹。对于轨迹中的每个位姿 $T_t = (p_t, R_t)$（$p_t$为位置，$R_t$为旋转矩阵），变换规则如下：
    $p_t \rightarrow \mathbf{f}(p_t), \quad R_t \rightarrow \mathrm{orth}(\mathbf{J_f}(p_t)R_t)$
    其中 $\mathbf{J_f}(p_t)$ 是 $\mathbf{f}$ 在 $p_t$ 处的雅可比矩阵，$\mathrm{orth}(\cdot)$ 对结果矩阵进行正交化以得到有效的旋转矩阵。该变换保持了末端执行器与可变形物体局部空间关系随物体形变的一致性。与MimicGen类似，最后会在变形后的轨迹段前添加线性插值段，以实现从机器人当前位姿到变形轨迹起点的平滑过渡。

与现有方法的创新点：

  • 超越刚性假设：MimicGen依赖于物体存在静态参考坐标系，并利用相对该坐标系的SE(3)变换不变性。而SoftMimicGen放弃了这一假设，通过非刚性配准处理物体形态的任意变化，从而能够处理可变形物体。
  • 广义的轨迹变换：使用连续变形场（及其雅可比）对末端执行器位姿进行非刚性空间变换，取代了单一的刚性SE(3)变换。这使得方法能严格推广到刚性物体任务（此时变形场退化为刚性变换），甚至能处理与源演示几何形状差异较大的刚性物体。

实验与结果

实验设置：

  • 基准/数据集：研究构建了一个包含10个挑战性任务的高保真仿真套件（使用Isaac Lab），涵盖4种机器人形态（GR1人形机器人、Franka机械臂、dVRK手术机器人、双YAM机械臂）和多种可变形物体（毛绒玩具、绳索、纸巾、毛巾）及操作行为（高精度穿线、动态抽击、折叠、抓放）。
  • 实验平台：仿真在Isaac Lab中进行。源人类演示使用Apple Vision Pro通过运动重定向到不同机器人进行收集（每任务1-3条）。使用SoftMimicGen为每个任务生成1000条演示。
  • 对比方法：主要对比策略在仅使用源演示（少量人类数据）与使用SoftMimicGen生成数据上训练的性能差异。策略训练采用了两种模仿学习方法：BC-RNN-GMM和Diffusion Policy。

总结与启发

核心贡献：

  1. 提出了SoftMimicGen系统：首个面向可变形物体操作的自动化合成数据生成管道，通过引入非刚性配准技术，解决了可变形物体缺乏静态参考系导致现有基于刚体不变性的数据生成方法失效的关键问题。
  2. 构建了全面的仿真基准套件：发布了涵盖多种机器人形态、可变形物体和复杂操作任务的高保真仿真环境，为社区提供了评估可变形操作的数据集和策略的标准化平台。
  3. 实证验证了系统的有效性与通用性：通过大量实验表明，系统能高效生成高质量数据，显著提升策略性能，并成功实现从仿真到真实世界的零样本迁移，同时证明其可泛化至刚性物体任务。

局限性：
论文自身提到，方法依赖于对可变形物体节点级状态的观测或估计（Assumption A3）。在真实世界中，这可能需要通过额外的感知模块（如深度传感器与点云处理）来获取，增加了系统复杂性。

对后续研究的启示：

  1. 数据生成范式的扩展：证明了非刚性配准是连接不同可变形物体状态、实现演示泛化的有效工具，为处理更复杂、高维的非刚性物体交互数据生成开辟了新方向。
  2. 仿真到真实的可变形操作：展示了基于纯仿真生成数据训练的策略能够实现零样本真实世界迁移，这鼓励未来研究构建更逼真的可变形物体仿真模型，并探索更高效的域适应技术。
  3. 基础模型的数据引擎：SoftMimicGen可作为大规模可变形物体操作数据集的“引擎”，为训练专注于可变形物体操作的机器人基础模型提供急需的大规模、多样化数据，弥补当前数据集的不足。

💡 一句话总结

这篇论文针对机器人学习在可变形物体操作领域面临的大规模真实数据采集困难、成本高昂的问题，提出了SoftMimicGen数据生成系统。其核心技术是一个自动化的合成数据生成管道，包含一系列高保真仿真环境，覆盖毛绒玩具、绳索、纸巾等多种可变形物体以及穿线、甩动、折叠等多种操作任务，并适配单臂、双臂、人形和手术机器人等多种机器人形态。核心实验结论表明，该系统能够为可变形物体操作任务生成数据集，并基于此训练出高性能的策略，为解决该领域数据稀缺问题提供了可扩展的仿真方案。
