Safety-Guaranteed Imitation Learning from Nonlinear Model Predictive Control for Spacecraft Close Proximity Operations

arXiv: 2603.18910 作者: Alen Turnwald Team 日期: 2026-03-19

📝 详细解读

研究背景与动机

在轨服务任务中的航天器近距离操作是安全关键阶段。目前，非线性模型预测控制（NMPC）能够将安全区域、物理约束和系统非线性整合到一个约束最优控制问题中，展现出良好前景，但其在商用现货处理器上的计算负担较重。模仿学习（IL）作为一种运行时高效的替代方案受到关注，然而此类数据驱动控制器本身缺乏安全性和稳定性保证。现有研究尝试将学习控制器与后续的安全滤波器结合，但应用于航天器近距离操作的研究较少，且现有方法或未考虑禁入区，或仅通过软约束奖励函数纳入安全性，缺乏硬性安全保证，或仍需使用神经网络来热启动优化求解器，未能实现真正的轻量级在线部署。本文针对学习型控制器缺乏安全保证与在线计算效率难以兼得的痛点，提出了将安全作为统一设计原则的新视角，在数据生成、训练和部署的全流程中整合控制屏障函数（CBF）和控制李雅普诺夫函数（CLF）。本文核心思路是：首先利用强制执行CBF约束的NMPC专家生成安全参考轨迹；其次，使用一种新颖的CBF-CLF-informed损失函数和类似DAgger的课程加权滚动策略训练神经网络策略；最后，在部署时通过一个轻量级的一步CBF-CLF二次规划对学习到的控制输入进行最小调整，以满足硬安全约束并鼓励稳定性。

方法详解

整体框架是一个三阶段、安全保证的模仿学习流程，如图2所示。三个阶段分别为：1）数据生成：安全在数据收集阶段被整合，NMPC专家策略在最优控制问题中强制执行CBF约束；2）训练：定制的损失函数用CBF和CLF软约束增强传统模仿损失，将物理安全和稳定性先验融入学习过程；3）部署：在线部署期间，一个运行时高效的CBF-CLF-QP安全滤波器确保稳定性和硬约束满足。

图2：三阶段安全保证模仿学习框架概览。该框架在多个阶段整合了安全性考量。

核心模块一：CBF与CLF设计。针对航天器相对运动动力学（二阶系统），论文采用了考虑输入约束的CBF设计。对于相对度为2且$L_gh(\bm{x})=0$的约束函数$h(\bm{x})$，构造$H(\bm{x}) = h(\bm{x}) + \frac{|\dot{h}(\bm{x})|\dot{h}(\bm{x})}{2u_{\max}}$及其导数，并基于此定义输入约束CBF条件 $\sup_{u\in\mathcal{U}} [L_fH(\bm{x}) + L_gH(\bm{x})\bm{u} + \alpha(H(\bm{x}))] \geq 0$，这保证了在满足输入约束的同时，存在一个内层安全集$\mathcal{S}_H \subset \mathcal{S}$。具体为近距离操作场景设计了两个CBF：用于禁入区（KOZ）避障的球形CBF $h_1(\bm{x})=|\bm{p}-\bm{p}o|^2 - r{\text{KOZ}}^2 \geq 0$，以及用于接近走廊（AC）的锥形CBF $h_2(\bm{x})=\frac{\bm{p}^T \bm{d}}{\lVert\bm{p}\rVert \lVert\bm{d}\rVert} - \cos(\theta) \geq 0$。对于稳定性，设计了二次型CLF $V(\bm{x})=(\bm{x}-\bm{x}_g)^T\bm{P}(\bm{x}-\bm{x}g)$，并引入状态依赖的衰减率$\zeta(\bm{x})$（一个Sigmoid函数），将CLF条件改写为 $\inf{u\in\mathcal{U}} [L_fV(\bm{x}) + L_gV(\bm{x})\bm{u} + \zeta(\bm{x})V(\bm{x})] \leq 0$，从而在接近目标点时加强稳定性，而在远离时减少与CBF安全约束的冲突。

核心模块二：NMPC专家策略。用于生成专家数据。其最优控制问题在标准MPC成本函数和约束之外，额外加入了CBF约束 $L_fH(\bm{x}_k) + L_gH(\bm{x}_k)\bm{u}_k + \gamma H(\bm{x}_k) \geq \epsilon$ 以保证安全。求解该非线性规划问题计算量大。

核心模块三：CBF-CLF-informed损失函数与训练。这是核心创新点。为了在训练中融入安全与稳定性知识，并提高数据效率、减少部署时安全滤波器的干预，论文提出了新的损失函数。在初始使用纯模仿损失 $\mathcal{L}{\text{imit}}$ 训练后，采用DAgger-like策略进行滚动数据收集，并引入两个额外的损失项：CBF损失 $\mathcal{L}{\text{CBF}} = \mathbb{E}{\bm{x}\sim D}[\max(0, -\mathbb{H}(\bm{x}, \pi{\text{NN}}(\bm{x})))^2]$ 和CLF损失 $\mathcal{L}{\text{CLF}} = \mathbb{E}{\bm{x}\sim D}[\max(0, \mathbb{V}(\bm{x}, \pi_{\text{NN}}(\bm{x})))^2]$，它们仅在神经网络策略违反CBF或CLF条件时进行惩罚。总损失为 $\mathcal{L}{\text{total}} = \lambda{\text{imit}}\mathcal{L}{\text{imit}} + \lambda{\text{CBF}}\mathcal{L}{\text{CBF}} + \lambda{\text{CLF}}\mathcal{L}{\text{CLF}}$，并通过课程学习逐渐增加$\lambda{\text{CBF}}$和$\lambda_{\text{CLF}}$的权重。

核心模块四：安全滤波器设计。在部署时，使用一个轻量级的一步二次规划（QP）作为安全滤波器。该QP在目标函数中最小化滤波后输入$\bm{u}{\text{SF},k}$与神经网络原始输入$\bm{u}{\text{NN},k}$的偏差，同时服从CBF安全约束 $\mathbb{H}(\bm{x}, \bm{u}{\text{SF},k}) \geq \epsilon$、CLF稳定性约束 $\mathbb{V}(\bm{x}, \bm{u}{\text{SF},k}) \leq \delta_k$（引入松弛变量$\delta_k$以保证可行性）以及输入约束。该QP是凸的，计算成本低。

实验与结果

实验在包含轨道扰动和非线性动力学的高保真航天动力学模拟器Basilisk中进行。场景设定符合ESA安全CPO指南，包括一个半径为40m的接近区（AZ），一个半径为10m的球形禁入区（KOZ），以及一个半锥角为3°的锥形接近走廊（AC）。决策点分别设置在V-bar方向距目标质心15m和2.3m处。

对比方法：论文对比了五种控制策略：(i) 使用位置避障约束（公式(8)）而非CBF约束的NMPC；(ii) 结合安全滤波器的LQR；(iii) 集成CBF约束的专家NMPC（公式(14)）；(iv) 仅使用纯模仿损失（公式(15)）训练的传统行为克隆（BC）；(v) 本文提出的框架（CBF-CLF-informed IL + 安全滤波器）。

图3：仿真结果与控制器消融研究。(a) 闭环轨迹对比；(b) 控制输入及CBF-CLF分析。

关键实验结果：如图3(a)所示，策略(i)在同时满足KOZ约束和输入约束时变得不可行，凸显了相对度2 CBF约束的必要性。策略(ii)（LQR+滤波器）虽能保证安全，但轨迹沿安全集边界且滤波器干预频繁、输入抖动大。策略(iii)（专家NMPC）提供了安全且满足输入约束的最优轨迹。策略(iv)（传统BC）无法稳定收敛至决策点，并违反了AC约束。相比之下，策略(v)（本文方法）实现了对专家策略的安全、稳定模仿，其轨迹虽稍长，但计算效率大幅提升。如表I所示，专家NMPC的平均计算时间（14.3 ms）超过了采样时间（10 ms），而本文策略在PC上的平均时间仅为5.8 ms，在嵌入式ESP32处理器上为28.1 ms，证明了其在线部署的实时可行性。

消融实验分析：图4展示了训练过程中损失函数设计对部署时安全滤波器激活程度的影响。仅使用模仿损失进行DAgger训练，虽然CBF损失也有所下降（因为专家数据本身包含安全约束），但使用提出的CBF-CLF-informed损失函数进行精炼，能更有效地最小化CBF违反。这直接体现在部署时安全滤波器的干预幅度更低，表明所提策略更内化了安全要求，且训练数据效率更高。

总结与启发

核心贡献：1) 提出了一个将安全作为统一设计原则的、计算高效的航天器近距离操作学习控制框架，在数据生成、模仿学习训练和实时部署全流程整合了CBF约束。2) 提出了一种新颖的CBF-CLF-informed损失函数，将安全和稳定性要求融入数据高效的模仿学习中。3) 在包含真实轨道扰动的高保真仿真中，针对符合ESA指南的安全关键交会场景进行了鲁棒验证，并证明了在嵌入式COTS硬件上的实时可行性。

局限性：论文自身提到，所提方法在计算效率和安全保证之间进行了权衡（轨迹稍长）。此外，框架假设系统模型完全已知，且未考虑执行器故障等情况。

后续研究启示：该工作为学习型航天器控制提供了可验证的安全框架范式。后续研究可探索将CBF/CLF理论扩展到模型不确定或部分未知的系统；考虑更复杂的扰动和故障模式；以及研究如何将类似框架应用于其他安全关键的机器人或自主系统任务中。

💡 一句话总结

本文针对航天器近距离操作中模仿学习缺乏安全保证、非线性模型预测控制（NMPC）计算负担重的问题，提出一种安全保证的模仿学习框架。关键技术基于控制屏障函数（CBF）和控制李雅普诺夫函数（CLF）的统一设计：首先用NMPC专家生成安全轨迹；其次以CBF-CLF-informed损失和课程加权rollouts训练神经策略；部署时通过轻量级CBF-CLF二次规划微调控制输入以硬性保证安全。实验在Basilisk高保真模拟器中验证，该方法严格遵守安全约束，性能与NMPC相当，同时显著降低在线计算量，在商用处理器上实现实时运行。
