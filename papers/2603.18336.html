ManiDreams: An Open-Source Library for Robust Object Manipulation via Uncertainty-aware Task-specific Intuitive Physics

arXiv: 2603.18336 作者: Kaiyu Hang Team 日期: 2026-03-18

📝 详细解读

研究背景与动机

机器人操作领域长期依赖动力学模型，无论是物理模拟器还是学习型世界模型。当前主流方法，如GPU并行模拟器和在紧凑潜在空间中规划的学习世界模型，主要专注于最小化预测误差。然而，这些方法存在一个关键局限性：它们仅产生单状态预测，而没有将不确定性作为一等公民暴露给规划器。现实世界的操作本质上是充满不确定性的，这主要来源于三个方面：感知不确定性（来自噪声和延迟的观测）、参数不确定性（来自不准确的物理参数估计）以及结构不确定性（来自不完美的动力学模型）。现有流程大多将这些不确定性视为训练阶段的问题来处理，例如通过域随机化在训练中注入可变性，或让学习模型将不匹配吸收到潜在表示中。一旦策略部署，明确的不确定性结构就被丢弃了。近期研究发现，当这三种不确定性被独立处理时，其误差会在整个流程中累积。因此，鲁棒操作从根本上说是一个集成问题：不确定性必须在规划循环中被表示、传播和约束，而不仅仅是在训练中被抑制。

本文针对上述痛点，提出了一个新的视角：将“采样-预测-约束”这一反复出现的规划模式抽象为一个统一的、可组合的框架，以显式地处理和集成多种不确定性。核心思路是：1）通过分布式的状态表示（DRIS）捕获感知和参数不确定性；2）通过后端无关的前向动力学接口（TSIP）传播不确定性并容纳结构不确定性；3）通过声明式的笼约束限制不确定性的增长；最终通过一个求解器闭环选择满足约束的最佳动作。

方法详解

ManiDreams 的整体框架围绕四个可组合的抽象构建，直接对应“采样-预测-约束”范式：域随机化实例集（DRIS）用于分布状态表示，任务特定直觉物理（TSIP）用于前向动力学预测，笼约束用于限制不确定性，以及求解器用于动作选择。其设计遵循三个核心原则：分布优先（将一组可能状态作为推理的基本单元）、后端无关（所有依赖动力学的逻辑都隔离在一个统一的前向预测接口之后）以及最小侵入性（通过一个轻量级适配器包装任何与Gym兼容的环境）。

图2：ManiDreams的三层架构。第1层定义了四个核心抽象的接口；第2层提供了统一的、封装在单个环境类中的具体实现；第3层是用户界面，添加新任务只需填充此层。虚线箭头表示继承关系。

核心模块：

  1. 域随机化实例集（DRIS）：这是贯穿所有流程阶段的通用状态表示。它不是一个单一的点估计，而是一组状态-上下文对的集合：𝒟_t = { (s_t^(i), c^(i)) | c^(i) ∈ Ĉ }，其中 c^(i) 是从上下文空间（如质量、摩擦、几何形状）中采样的物理参数，s_t^(i) 是在该上下文下演化的实例状态。DRIS 对模态无关，观测字段可以是状态向量、RGB图像或点云。
  2. 任务特定直觉物理（TSIP）：提供了连接DRIS和约束层的前向预测接口。它将当前DRIS和候选动作作为输入，通过一个确定性的映射（无论是基于模拟还是基于学习模型）输出预测的下一个DRIS：𝒟_{t+1} = ℱ(𝒟_t, u_t)。该接口标准化了不同动力学后端（如ManiSkill3模拟器或扩散世界模型）的调用方式。
  3. 笼约束（Cage）：用于限制DRIS不确定性的增长，以维持任务级的安全，要求 𝒮_{t+1} ⊆ 𝒮_{cage}^{t+1}。每个约束暴露 evaluate()（连续成本）和 validate()（二元包含标志）方法。与处理单一配置的经典状态有效性检查器不同，笼约束对分布的扩散进行推理。
  4. 求解器（Solver）：通过结合一个采样器（提出N个候选动作）和一个优化器（通过笼约束对候选动作评分并返回最佳有效动作）来闭合“采样-预测-约束”循环。这可以在不重新训练的情况下，为现有策略添加安全过滤器。

图3：ManiDreams的运行时流水线。规划循环（黄色）：求解器生成候选动作，通过TSIP预测其DRIS结果，并选择满足笼约束的最佳动作；该循环可迭代以进行优化。执行循环（绿色）：选定的动作被追加到一个动作块中；完成后，该块被分派给真实机器人或模拟器执行，执行器观测结果并产生更新的DRIS，用于下一个规划周期。

运行流程：如图3和算法1所示，运行时包含嵌套的规划循环和执行循环。在规划循环中，给定当前DRIS，求解器执行以下步骤：1) 采样器提出N个候选动作；2) TSIP通过一次批处理调用，为每个候选动作预测其导致的DRIS；3) 笼约束对每个预测结果进行评分和过滤；4) 优化器返回最佳有效动作。执行循环则负责将规划好的动作块发送给机器人或模拟器执行，并基于新的观测更新DRIS，为下一次规划做准备。该框架支持在线模式（每控制步运行一次规划）和先规划后执行模式（为整个时域T进行规划）。

与现有方法相比，ManiDreams的创新点在于：1) 统一且显式的不确定性处理：将三种不确定性源头通过DRIS和TSIP集成到一个分布式的规划流程中；2) 模块化与可组合性：四个核心抽象相互独立，允许用户自由替换TSIP后端、笼约束类型、采样器和优化器；3) 对现有策略的即插即用增强：通过包装任何Gym兼容的环境和策略，可以无缝地为其增加不确定性感知的规划能力，而无需重新训练。

实验与结果

实验在ManiSkill3模拟平台和配备Finray软夹爪的Franka Panda真实机器人上进行。评估了五个方面：可运行示例、真实世界部署、不确定性下的鲁棒性基准测试、消融研究以及运行时开销分析。对比的基线是标准的PPO策略（在ManiDreams框架中配置为 num_samples=1 且无笼约束的直接执行模式）。

关键实验结果：
在三个ManiSkill默认任务（PushCube, PickCube, PushT）上，对感知噪声、观测延迟和物理参数扰动这三种不确定性进行了鲁棒性测试。如图9所示，ManiDreams在几乎所有九种任务-扰动组合中都优于PPO基线，在中等扰动水平下优势最为明显。例如，在观测噪声（σ=0.04米）下，PushCube任务中ManiDreams的成功率比基线高出约15个百分点；在观测延迟（4个模拟步）下，PickCube任务中ManiDreams的成功率比基线高出超过20个百分点。在极端扰动下，由于固定的DRIS配置无法完全覆盖不确定性，两种方法性能均下降。

图9：在三个ManiSkill任务（从上到下：PushCube, PickCube, PushT）中，随着扰动增加的成功率对比。左：观测噪声（σ，单位米）。中：观测延迟（模拟步数）。右：物理扰动严重程度。阴影区域表示10次运行的一个标准差。

可运行示例与真实部署：
图5、6、7展示了在随机物体推动、卡片拾取和动态球接住任务中，框架在不同TSIP后端、笼约束、求解器和采样器之间灵活组合的能力。图8展示了在杂乱场景中的零模拟到真实转移。机器人使用基于学习的TSIP和基于像素的DRIS（通过SAM2分割获得），成功完成了推动-抓取和利用墙角舀取扁平物体的任务，证明了执行器独立性带来的便利。

图8：真实机器人部署。左：杂乱的推动-抓取任务。右：利用墙角舀取扁平物体。两个任务都使用基于学习的TSIP和基于像素的DRIS（物体后的红色区域）为连续的动作块进行规划。

消融实验：
在PushCube任务上，对关键参数进行了消融研究（见表I）。结果表明：1) DRIS实例数 m：设置为1（退化为点估计）时性能最差（成功率65%），随着 m 增加性能提升，在 m=16 时达到峰值（89%），之后饱和。2) 求解器样本数 N：设置为1（退化为直接策略执行）时性能较低（74%），增加 N 能持续提升性能至 N=16（89%），之后回报递减。3) DRIS物理分布宽度：过窄（低估变异性）或过宽（引入过度保守性）都会损害性能，中等宽度（[0.5, 2]倍默认参数）效果最佳（~89%）。

总结与启发

本文的核心贡献包括：1) 一个可组合的开源框架：通过基于插件的抽象实现了“采样-预测-约束”范式，为不确定性感知的操作规划提供了一个模块化工具库。2) 统一的分布动力学表示：通过DRIS、TSIP和笼约束，以标准化接口实现不确定性的表示、传播和约束。3) 全面的评估：涵盖了从可运行示例、多种不确定性下的基准测试、运行时分析到真实机器人部署的广泛实验。

论文自身提到的局限性在于：在极端扰动下，固定的DRIS配置无法完全覆盖不确定性，性能会下降，这表明需要自适应的DRIS配置机制。此外，框架的效能在一定程度上依赖于手动配置的参数（如 m, N, 分布宽度）。

本工作对后续研究的重要启示在于：首先，它证明了将不确定性作为规划中的一等公民进行显式、统一处理的可行性与有效性。其次，其高度模块化的设计为社区提供了一个可扩展的基础，研究者可以轻松集成新的动力学模型、约束形式或优化算法。最后，它启发了“规划时不确定性管理”这一新范式，与传统的“训练时不确定性吸收”范式形成互补，为在动态、不确定的真实世界中实现更鲁棒的机器人操作开辟了道路。

💡 一句话总结

本文针对机器人操作中感知、参数和结构不确定性累积的难题，提出了开源框架ManiDreams。其核心是通过“采样-预测-约束”循环，集成分布状态表示、后端无关的动态预测与声明式约束优化，实现不确定性在规划中的统一表征与传播。实验表明，该框架在多种扰动下能保持鲁棒性能，而基线RL方法性能显著下降，验证了其在推动、抓取等任务中的有效性。
