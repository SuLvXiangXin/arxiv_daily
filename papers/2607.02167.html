Influence of Radial Basis Activation Functions on Intelligent Controller for Robotic Manipulators

arXiv: 2607.02167 作者: Wallace Moreira Bessa Team 日期: 2026-07-02

📝 详细解读

研究背景与动机

机器人机械臂的轨迹跟踪通常采用基于模型的非线性控制方法，如反馈线性化。这些方法在已知系统动力学下能有效抵消非线性，实现精确跟踪。然而在实际中，参数不确定性、摩擦、未建模动态和外部扰动会降低跟踪精度。为增强鲁棒性，通常结合自适应或学习方法来扩展这些基于模型的控制。其中，神经网络由于具有万能近似能力，常被用于补偿复杂的非线性扰动，而径向基函数神经网络尤为常用。尽管基于Lyapunov的稳定性分析对一大类有界激活函数都保证闭环稳定性，但激活函数的形态会显著影响暂态响应、稳态精度和控制平滑性等性能。本文针对RBF网络中激活函数选择这一具体设计参数进行研究，旨在探究其对闭环行为的影响。本文的核心思路是：将反馈线性化与基于RBF神经网络的在线扰动估计器相结合，在保证Lyapunov稳定的前提下，系统性地比较高斯核、拉普拉斯核和逆多元二次核三种不同激活函数在相同控制器参数下的跟踪性能差异。

方法详解

论文提出的智能控制器整体框架结合了基于模型的反馈线性化和RBF神经网络扰动估计器。输入为期望轨迹 q_d 及其导数，以及实际关节位置 q 与速度 q_dot，输出为控制力矩 u。控制目标是使实际轨迹跟踪期望轨迹。

核心控制器基于反馈线性化设计。考虑n自由度机械臂动力学方程 M(q)q_ddot + k(q, q_dot) = h(q, q_dot) + u。控制律设计为 u = M_hat(-f_hat - d_hat + q_d_ddot - Λ q_tilde_dot - Λ s)，其中 M_hat 和 f_hat 为模型估计项，d_hat 为RBF网络估计的集总扰动，Λ 为正定对角增益矩阵，s = q_tilde_dot + Λ q_tilde 为综合误差（q_tilde = q - q_d 为跟踪误差）。该控制律将系统闭环误差动态简化为 s_dot + Λ s = d - d_hat。理想情况下，若扰动估计完全准确 (d = d_hat)，则综合误差 s 和跟踪误差 q_tilde 将指数收敛至零。

RBF神经网络是核心的扰动估计模块。对于第i个自由度，扰动估计 d_hat_i 由RBF网络输出：
d_hat_i = w_i^T φ_i(s_i)。
其中 w_i 为权重向量，φ_i 为激活函数向量。网络输入为归一化的综合误差 s_bar_i。每个神经元的激活值 φ_i,j 由激活核函数 κ(ρ_i,j) 计算，ρ_i,j = (s_bar_i - c_i,j) / σ_i，c_i,j为中心，σ_i为宽度。

图2：RBF神经网络架构。输入为综合误差s_i，通过RBF层（激活函数φ）映射，与权重w_i线性组合后输出扰动估计d_hat_i。

权重更新律基于Lyapunov稳定性分析设计，并引入投影算法以保证权重有界。定义Lyapunov函数候选 V_i(t) = (1/2) s_i^2 + (1/(2η_i)) δ_i^T δ_i，其中 δ_i = w_i - w_i^* (w_i^*为最优权重)，η_i为正的学习率。通过推导，选择权重更新律 w_i_dot = η_i s_i φ_i 可使 V_i_dot 负定，从而保证跟踪误差收敛到一个紧集。为确保权重有界，采用了投影算法，将权重限制在凸集 W_i = {w_i ∈ R^n: w_i^T w_i ≤ μ_i^2} 内。

本文的创新点在于将RBF网络的激活函数视为一个关键的设计参数，并在完全相同的控制器结构、增益参数、网络规模（神经元数量、中心、宽度）和实验条件下，系统比较三种不同的径向基核函数：

  1. 高斯核（基线）：κ_G(ρ) = exp(-ρ^2)
  2. 逆多元二次核：κ_IMQ(ρ) = 1 / sqrt(1 + ρ^2)
  3. 拉普拉斯核：κ_L(ρ) = exp(-|ρ|)
    高斯核和拉普拉斯核具有局部支撑和衰减特性，而逆多元二次核具有全局支撑。论文旨在探究这些核函数特性（局部性、平滑性、支撑）如何影响自适应动态和实际跟踪性能。

实验与结果

实验在Quanser QArm机械臂的数字孪生（Quanser Interactive Labs环境）中进行，仿真时长为62秒，采样频率500Hz。被控对象为单自由度机械臂，参数已知。控制器参数固定为：λ_i = 30, η_i = 10, μ_i = 100, 神经元数量 n_i = 6。中心在归一化输入区间[-1, 1]上均匀分布，宽度参数γ固定。

对比方法包括：

  1. 基线控制器：无神经网络扰动的常规反馈线性化控制器 (η=0)。
  2. 智能控制器：分别使用高斯、拉普拉斯、逆多元二次核的RBF神经网络扰动估计器。

评估了三种参考轨迹：正弦波、方波和三角波。性能指标包括跟踪误差的均方根值（RMS_e）、绝对误差积分（IAE）、控制努力（PWM信号的RMS值），对方波参考还额外评估了超调量和调节时间。

图3：正弦参考轨迹下的跟踪性能对比。图表展示了不同控制器下的跟踪误差，直观显示使用RBF网络（特别是IMQ核）能显著减小稳态误差。

图4：方波参考轨迹下的跟踪性能对比。结果显示，RBF网络的引入改善了IAE，但带来了瞬态超调并增加了调节时间，其中IMQ核的超调最大。

图5：三角波参考轨迹下的跟踪性能对比。与正弦波类似，IMQ核在平滑的斜坡状运动中也表现出最低的跟踪误差。

关键定量结果总结如下：

  • 正弦参考：IMQ核性能最优，RMS_e为0.223度，相比基线（0.464度）提升了51.9%。拉普拉斯核（0.282度）和高斯基（0.341度）次之。
  • 方波参考：所有RBF核均改善了IAE（例如高斯基改善了15.0%），但引入了超调（IMQ核达6.86%）并延长了调节时间（高斯基为2.567秒，基线为1.277秒）。RMS_e略有增加。
  • 三角参考：IMQ核性能最优，RMS_e为0.203度，相比基线（0.398度）提升了49.0%。

消融实验：本文的核心实验设计本身即构成一个系统性的消融研究，唯一变量是激活函数。结果表明，核函数的选择直接导致了性能差异。对于平滑轨迹（正弦、三角），具有全局支撑的IMQ核因能提供更全面的扰动近似而表现出最优的稳态精度。对于非连续方波指令，局部性更强的高斯核和拉普拉斯核导致了更尖锐的自适应和更大的瞬态攻击性（超调）。

总结与启发

本文的核心贡献在于：1）提出了一个结合反馈线性化和RBF神经网络在线扰动估计的智能控制框架，并通过Lyapunov分析和投影算法严格保证了闭环信号的有界性及跟踪误差的收敛性。2）首次通过系统的实验对比，揭示了在保证稳定的前提下，RBF激活函数的选择（高斯、拉普拉斯、逆多元二次核）会显著影响控制器的暂态和稳态性能，因此应将其视为一个重要的结构性设计参数。

论文自身提及的局限性在于目前的研究集中在单自由度配置上。这为后续研究提供了明确的启示：未来工作可以扩展到多自由度机械臂，并研究系统性的核函数调优策略，以在近似能力和瞬态鲁棒性之间取得平衡。此外，本文的实验结论为控制器设计者提供了实用指南：若追求最优稳态精度（尤其是在平滑轨迹下），可优先选择IMQ等全局支撑核；若关注瞬态响应，希望避免超调（如阶跃响应），则局部核或传统的无神经网络控制器可能更合适。

💡 一句话总结

这篇论文研究了RBF神经网络中**激活函数的选择**对机器人智能控制器性能的影响。核心是结合**基于模型的非线性控制（反馈线性化）** 与**在线自适应RBF神经网络**来估计并补偿扰动，其权重通过**基于Lyapunov的自适应律**更新，以保证稳定性。实验结果表明，尽管不同激活函数均能保证系统稳定，但其**具体选择会显著影响系统的自适应动态过程**和**实际的轨迹跟踪性能**。
