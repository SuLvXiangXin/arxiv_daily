Learning Action Priors for Cross-embodiment Robot Manipulation

arXiv: 2606.26095 作者: Mingyu Ding Team 日期: 2026-06-24

📝 详细解读

研究背景与动机

当前，视觉-语言-动作（VLA）模型已成为机器人操作的主流范式。这些模型通常在视觉-语言模型（VLM）主干上附加一个动作模块，并对整个策略进行联合优化。这种设计继承了VLM强大的视觉和语言先验，但动作模块却几乎需要从零开始学习物理运动。因此，策略缺乏明确的运动先验，迫使早期优化必须同时发现时间动作动态和跨模态对齐，这一挑战在动作分布异构的跨具身设置中更为显著。

本文针对VLA训练中动作先验缺失这一结构性瓶颈，提出了在跨模态对齐之前预训练动作模块以学习运动先验的新视角。核心思路是引入一个两阶段训练框架：第一阶段，仅使用动作轨迹训练一个轻量级的编码器-解码器动作模块，以高效学习跨具身的时间运动结构；第二阶段，将习得的先验通过解码器重用、潜在知识蒸馏和历史压缩等方式转移到VLA训练中。

方法详解

整体框架是一个两阶段流程。在第一阶段，输入是纯粹的无条件动作轨迹（包括交错的状态-动作序列），目标是让动作模块学习动作的分布和结构抽象，输出是重构的动作块。在第二阶段，输入是视觉观测、语言指令和历史上下文，输出是预测的未来动作块。核心创新点在于将动作先验学习与跨模态对齐解耦，提升了策略的稳定性、收敛速度和性能。

图2：本文提出的两阶段框架架构。左侧为第一阶段：编码器处理交错的状态-动作序列和数据集特定的软提示标记，生成潜在动作嵌入 z；基于流匹配的解码器以 z 为条件重建原始动作。右侧为第二阶段：VLM处理观测、指令、查询标记和历史压缩标记，预测动作潜在嵌入 z'；预测的 z' 通过逐渐衰减的蒸馏损失与编码器产生的 z 对齐，并输入到第一阶段初始化的解码器中生成动作；同一个编码器还将历史轨迹压缩为单个上下文标记 z_hist 供VLM使用。

核心模块1：编码器-解码器动作模块。该模块用于第一阶段学习动作先验。

  • 动作编码器：一个Transformer编码器，输入为交错的状态-动作序列 τ = [s_t, a_t, s_t+1, a_t+1, ...] 以及用于区分不同具身的可学习数据集嵌入 p_k。它通过在序列前添加一个可学习的汇总（cls）标记，并将该标记的归一化输出作为潜在动作嵌入 z，以此来捕捉整个动作块的全局时间结构和宏观运动语义。
  • 基于流匹配的动作解码器：一个Transformer解码器，以潜在嵌入 z 和噪声破坏的动作 x_r 为输入。x_r 是干净动作 a 与高斯噪声 ε 在流匹配时间步 r ∈ [0,1] 上的线性插值。解码器被训练去预测将噪声推向干净动作的速度场 v_r = a - ε，重建损失为 L_recon = ||D(x_r, r, z) - v_r||^2。这种方法为连续且可能多模态的动作分布提供了灵活的生成目标。

核心模块2：带动作先验蒸馏的VLA训练。这是第二阶段，将先验知识转移到VLA策略。

  • 解码器重用：第一阶段训练好的解码器直接初始化为VLA的动作头，并在第二阶段继续参与优化。它基于VLM预测的潜在嵌入 z' 生成动作。
  • 潜在对齐蒸馏：第一阶段的编码器为VLM预测的 z' 提供了一个结构化的教师目标。给定真实轨迹，编码器产生潜在嵌入 z。通过对齐损失 L_align = ||z' - sg(z)||^2（sg 为停止梯度操作）和保留的重建损失 L_recon，在早期训练中将VLM快速锚定到已习得的动作潜在空间。
  • 早期步数蒸馏策略：为了不限制VLM后期的表征灵活性，总损失 L = L_pred + λ(k)(L_align + L_recon) 中的蒸馏权重 λ(k) 随训练步数 k 增加而单调衰减至0，使得模型后期过渡到标准的端到端VLA优化。

核心模块3：基于动作编码器的时间上下文压缩。

  • 为了给策略提供历史信息，重用第一阶段训练好的编码器作为历史压缩器。将过去的状态-动作轨迹 τ_hist 输入编码器，得到单个历史潜在标记 z_hist，然后将其作为额外条件输入VLM（z' = f_θ(p_k, o_t, l_t, z_hist, q)）。
  • 这种方式以紧凑且语义结构化的形式注入历史信息，将原始的低级数值序列转化为运动动态的抽象表示，以近乎零的计算开销扩大了策略的时间视野。训练时采用带历史条件和不带历史条件的损失平均，以鼓励利用上下文同时避免过度依赖。

图1：方法动机示意图。策略应先学会移动，再学会观察和行动。(a) 第一阶段，动作模块仅在动作轨迹上训练，高效获取通用动作先验。(b) 第二阶段，先验被转移到VLA训练，使模型能够在一个已经“知道如何移动”的动作模块上进行感知和遵循指令。有先验时策略产生平滑轨迹，无先验时轨迹不稳定。(c) 动作先验加速了VLA训练并提升了性能。

实验与结果

实验设置：在涵盖13个任务的跨具身设置上进行评估，包括两个模拟基准（LIBERO、RoboCasa）和一个真实世界弗兰卡平台（如图3所示）。所有模型都在异构具身上进行联合训练，且无需针对特定环境进行微调。

图3：13个跨具身任务概览，覆盖LIBERO、RoboCasa GR1和真实世界弗兰卡操作。这套任务集涵盖了异构的具身类型、动作-状态空间、场景和任务分布。

对比方法：主要与没有动作先验的VLA训练（即从头开始训练标准VLA）进行对比，同时也与APT、OpenVLA等基线方法进行比较。

关键结果总结：

  1. 更快收敛与更高成功率：与从头训练相比，本文方法在训练早期显著加速了成功率的提升，并在所有13个任务上取得了更高的平均成功率。
  2. 在数据稀缺的真实任务上提升显著：在仅有少量演示的真实世界长尾任务中，动作先验使策略行为更稳定、更果断，有效缓解了模拟任务主导而真实行为欠拟合的不均衡收敛问题。
  3. 动作数据规模化的良性效应：增加第一阶段使用的无条件动作数据量，可以学习到更通用的动作先验，并能直接提升下游VLA性能。
  4. 历史压缩带来巨大增益：对于长视野任务，通过历史压缩注入时间上下文带来了巨大的性能提升，因为它有效地扩大了策略的动作感受野。

图4：跨所有13个任务的最终性能对比。我们的方法（红色）相比从头开始训练的VLA（蓝色）和其他基线，在平均成功率上取得了显著提升（具体数值：我们的方法57.9%，无先验46.3%，APT 52.8%，OpenVLA 38.2%）。

图5：训练曲线对比。我们的方法（红色）在训练初期迅速提升成功率并更快收敛，而无动作先验的方法（蓝色）初期学习缓慢。这验证了动作先验加速收敛的假说。

图6：动作数据规模化研究。随着第一阶段使用的动作数据量增加（从10%到100%），下游VLA策略在测试任务上的成功率几乎单调提升，证明了动作先验的可扩展性。

图7：消融实验。依次移除“蒸馏”、“历史压缩”和整个“第一阶段”（即无动作先验），性能逐级下降。其中历史压缩对长视野任务（LIBERO-LM）的贡献最大（提升约15%），蒸馏则对加速早期收敛至关重要。

图8：在6个真实世界长尾任务上的性能。我们的方法（红色）相比无先验方法（蓝色）在所有任务上都取得了更高的成功率，尤其是在数据稀缺的任务上优势更明显，证明了其对长尾稳定性的改进。

消融实验总结：消融实验（图7）表明，潜在对齐蒸馏、历史压缩和第一阶段先验学习这三个组件都对最终性能有贡献。移除蒸馏会减缓早期收敛；移除历史压缩会显著损害长视野任务的性能；完全移除第一阶段（即无动作先验）则导致整体性能最低、收敛最慢。

总结与启发

核心贡献：

  1. 指出了当前VLA训练中动作先验缺失的结构性瓶颈，并提出一个两阶段框架，在跨模态策略对齐之前先高效地学习以动作为中心的机器人运动先验。
  2. 引入了一个基于流匹配的编码器-解码器动作模块，用于学习紧凑的运动感知嵌入，并将其作为动作先验转移到VLA训练中。该结构还产生了一个历史上下文标记，用于高效的历史感知决策。
  3. 在仿真和真实世界的13个跨具身任务上验证了方法的有效性，展示了更快的收敛速度、更高的成功率、改进的长尾稳定性以及更多动作数据带来的良性扩展。

局限性：论文提到，当前工作专注于动作建模，尚未扩展到包含视觉预测的世界模型。未来的工作可以探索如何将视觉世界模型的动力学先验与本文的动作先验相结合。

对后续研究的启示：

  • 解耦学习路径的有效性：验证了“先学会移动，再学会观察和行动”这一解耦学习路径的有效性，为机器人策略学习提供了新的训练范式。
  • 动作先验作为基础模块：学习到的动作先验可以作为一个独立、可复用的模块，用于初始化、对齐和提供历史记忆，表明动作先验可以像视觉/语言基础模型一样成为机器人学习的基石。
  • 数据的价值：研究表明，扩展无条件动作数据可以直接改善下游VLA性能，这强调了收集大规模、跨具身机器人动作轨迹数据的重要性。

💡 一句话总结

本论文针对跨具身机器人操作中，视觉-语言-动作（VLA）模型因动作模块缺乏运动先验而导致的优化困难问题，提出一种两阶段训练框架。关键技术包括：第一阶段使用基于流匹配的编码器-解码器，仅从动作轨迹中学习时间运动结构；第二阶段通过解码器重用和早期潜在蒸馏，将动作先验转移到VLA训练中，并利用编码器压缩历史状态。在13个跨具身任务上的实验表明，相比无动作先验的VLA训练，该方法收敛更快、成功率更高，尤其在数据稀缺的真实任务中性能显著提升。
